# 阿瓦隆操作与身份保密

中心信息改用世界坐标的高度偏移，展示变换的 translation 为零。文字仍朝向阅读者，但位置不会随视角绕桌移动。

私人身份与阵营名单在本人 actionbar 持续显示。队长选人、确认队伍和刺客选择目标使用对话框；身份牌按 Q 可重新打开。投票与任务表决仍使用红绿染料。

组队投票发放绿、红染料，分别表示同意、反对；任务阶段仅参加任务的人收到绿、红染料，分别表示成功、失败。好坏阵营都收到相同工具，好人提交失败会被拒绝。Q 丢出提交后同时回收两枚染料。道具绑定本桌和阶段，提交按丢出者校验，无距离限制。

开局需要清空快捷栏 1、2、8 格。发放过程中若第1、2格被玩家其他物品占用，改为给予背包，不覆盖物品。

统一牌背为 imagegen 生成的深蓝金边圆桌宝剑像素图案，导入为128×192。物品栏与第一人称可见自己的身份正面；第三人称主副手、掉落、展示框以及其他上下文均显示同一牌背。结算桌面翻牌使用独立双面模型，仍会公开真正身份。

本轮仅修改游戏内数据包及两个游戏资源包，测试确认后再同步 Git。
