# 任务特效与投票外观

每轮任务按实际结果仅播放一次：成功为桌中央的小型绿色金色烟花粒子和烟花声，失败为爆炸粒子和爆炸声。仅视觉与声音，无实体爆炸伤害或方块破坏。七人以上第四轮仍以两张失败票为失败，特效按该阈值判定；最终一轮也会播放。

紫色染料不再发放；重载和重新打开操作时回收旧道具。身份牌按Q打开操作对话框。开局仅要求清空快捷栏1、2、8格。

组队投票、任务投票均使用私有显示模型：本人背包和第一人称正常显示绿/红染料；其他玩家看到的主手、副手、丢出的物品与展示框统一显示绿色染料。投票道具内部的选项与本桌/本阶段校验保持不变。
