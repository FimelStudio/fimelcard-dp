# 谍报风云

3～8 人的密码推理游戏：加密者用三条提示向队友传递密码，队友负责解密，对手负责拦截。四座桌最多 4 人，5～8 人使用八座桌。

游戏编号 `6`，命名空间 `decrypto`。默认书模式无需 OP；切换文字对话框后，提交提示的加密者需要 OP。开局清空九格快捷栏，座位可不连续；安装和建桌见[README](../README.md)。

每队有编号 1～4 的四个秘密词语，整局不变。每次密码由三个不同数字组成，例如 `314`；加密者按顺序为 3、1、4 号词各写一条提示。对手只能看到提示，逐轮积累线索。

## 分队与流程

4～8 人分为两队，默认随机均分，奇数人数红队多一人；也可在设置选择固定组队：四座桌对座同队，八座桌北南一队、东西一队。每队须有 2～4 人，人数差不超过 1。

两人队每轮交换“加密兼拦截”和“解密”。加密者在两队提示公开后拦截对方密码。三人队轮换“加密、解密、拦截”。四人队增加一个轮空位。轮空者仍可查看本队词语及笔记，不能提交。每整轮结束才轮换职责。

一整轮按以下顺序进行：

1. 双方加密者同时填写三条提示，双方都提交后统一公开。
2. 两边同时拦截对方密码、解密己方密码；第一轮跳过拦截。
3. 本轮全部负责输入的玩家交齐答案后，统一公开、记录并结算两队。
4. 同时检查双方胜负，再轮换职责进入下一轮。

成功拦截要求三个数字及顺序全部正确，获得一枚绿色标记；猜错拦截无惩罚。己方解密失败获得一枚红色标记。先累计两枚绿色标记获胜，或累计两枚红色标记落败；系统在双方同轮结算后判定，同轮双方达到胜利条件时平局。若达到设置轮数上限仍未触发胜负，本局直接结束，不追加猜关键字决胜。

**三人模式**：随机一人整局担任截密者，其余两人合作并轮换加密、解密。第一轮不拦截；截密成功与合作队传讯失败合计达到两次，截密者获胜，否则五轮后合作队获胜。

## 玩家操作

大厅的“游戏设置”可选择提示输入方式：

- **书（默认）**：在书与笔第 1、2、3 页按密码顺序各写一条非空提示，必须恰好三页。点击“完成”，不要签名，再按 Q 丢出提交；无效书会退回供修改。
- **对话框**：加密者手持紫色染料按 Q，按窗口显示的数字顺序填写三条提示，每条 1～24 个字符，部分表情符号占两个字符。关闭不保留草稿；普通玩家使用书模式。

拦截者和解密者用紫色染料按 Q 打开当前行动窗口。每条提示下面有一行 1～4，点击后数字变绿，确认前可改选。选好三个不同数字后点击底部“确认提交”。双队局的解密者和拦截者是不同玩家，双方提示公开后可以同时操作。三人局使用同样的按钮，按阶段行动。猜码无需 OP。

桌心上方的“谍报战况”显示拦截成功和解密失败次数，实体丢失时会自动补回。物品栏上方提示当前行动，左上角显示敌方历轮已结算提示，按数字归类，长内容每 5 秒翻页；“密电记录”物品按 Q 可在聊天栏查询己方历史提示。每局从共享词库抽出八个不重复词语，重新开局才换词并清空笔记；三人局只使用合作队四词。词库维护见[pool.mcfunction](../data/decrypto/function/words/pool.mcfunction)。

提示须与关键字有实际语义联系，使用公开常识；不要直接使用关键字或翻译，不要用拼音、字数、位置、谐音或私人暗号。整场提示不重复，公布后不修改；加密者不参与队友猜码讨论。这些交流规则由玩家共同遵守。

## 设置

设置按桌保存，仅在大厅修改：

- 组队方式：随机（默认）或固定座位；仅用于 4～8 人局。
- 分队模式轮数：1～32 轮，默认 8 轮；三人模式固定五轮。
- 提示输入：书（默认）或对话框。

## 管理与中断

以下命令需要命令权限，操作同维度 8 格内最近一场本游戏，无需填写桌号；指定桌号和 Debug 见[主说明](../README.md)。

```mcfunction
# 查看本桌轮数
/scoreboard players get @e[type=minecraft:marker,tag=dc.controller,distance=..8,sort=nearest,limit=1] dc_round

# 中止附近最近一场谍报风云并返回大厅
/function decrypto:admin/abort
```

`/reload` 保留对局、词语、累计记录和设置；书模式的提示草稿保留，对话框模式可用染料重新打开。参与者离线时整桌暂停，原参与者全部重连后继续，也可用桌边“结束游戏”投票中止。

维护入口：[词库](../data/decrypto/function/words/pool.mcfunction)、[提示输入](../data/decrypto/function/input/)、[轮次与猜码](../data/decrypto/function/round/)。书页和表单内容是玩家文字，不应经未经转义的宏拼接；公开历史必须沿用本桌权限与已结算记录。

## 验收

运行 `node tools/check_decrypto_prompt.mjs`、`node tools/check_decrypto_teams.mjs`。多人复测三人模式、两队各职责轮换、首轮无拦截、书／对话框输入及 OP 边界；检查三页顺序、空项与引号、关闭／旧窗口、提示草稿恢复和两桌笔记保密。[通用验收](验收清单.md)列出重载与中止场景。


## 同步回合流程（2026-11-10）

4～8人双队局：双方加密者同时填写提示，全部提交后才公开双方三条提示。随后本轮解密者与拦截者同时通过紫色染料Q打开提交页面；解密和拦截由不同玩家分别提交；两人队的加密者负责拦截。第一轮只解密、不拦截。每次成功提交在本桌聊天栏公布提交者，不提前公开答案。所有本轮职责对应的答案齐备后，一次公布两队结果、计分并判胜；双方同轮达到胜利条件时判平局。轮空者无需提交。三人队和四人队的加密者交完提示后等待结算。

结束时按队伍逐行显示“编号：真实关键词 → 历轮所写提示”，与密电记录编号一致。三人局仍使用原合作／截密流程。旧存档中正在进行的串行回合保留，下一轮开始切换为同步流程。

同步提示、答案、完成状态和历史记录保存在本桌控制器；接收入口校验玩家桌号、当前阶段、职责和本轮令牌，重复或过期提交不生效。重连不重抽密码、不清空已提交内容，也不覆盖尚未提交的提示册草稿。

按钮界面在 data/decrypto/function/guess/，行动提示在 hint/，桌心战况显示在 marker/。
