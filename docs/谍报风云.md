# 谍报风云

3～8 人的密码推理游戏：加密者用三条提示向队友传递密码，队友负责解密，对手负责拦截。四座桌最多 4 人，5～8 人使用八座桌。

每队有编号 1～4 的四个秘密词语，整局不变。每次密码由三个不同数字组成，例如 `314`；加密者按顺序为 3、1、4 号词各写一条提示。对手只能看到提示，逐轮积累线索。

## 分队与流程

4～8 人分为两队，默认随机均分，奇数人数白队多一人；也可在设置选择固定组队：四座桌对座同队，八座桌北南一队、东西一队。每队须有 2～4 人，人数差不超过 1。

两人队轮换“加密、解密兼拦截”；三人队轮换“加密、解密、拦截”；四人队增加一个轮空位。轮空者仍可查看本队词语及笔记，不能提交。每整轮结束才轮换职责。

一整轮按以下顺序进行：

1. 白队加密者提交三条提示。
2. 黑队拦截者猜白队密码，白队解密者猜本队密码；第一轮跳过拦截。
3. 公开正确密码及双方猜测，记录提示与数字的对应关系，结算标记。
4. 交换两队，再进行一次；双方均结算后进入下一轮。

成功拦截获得一枚绿色标记，己方解密失败获得一枚红色标记。先累计两枚绿色标记获胜；累计两枚红色标记落败。若达到设置的轮数上限仍未触发胜负，本局直接结束。

**三人模式**：随机一人整局担任截密者，其余两人合作并轮换加密、解密。第一轮不拦截；截密成功与合作队传讯失败合计达到两次，截密者获胜，否则五轮后合作队获胜。

## 玩家操作

开局前清空九格快捷栏。大厅的“游戏设置”可选择提示输入方式：

- **书（默认）**：在书与笔第 1、2、3 页按密码顺序各写一条非空提示，必须恰好三页。点击“完成”，不要签名，再按 Q 丢出提交；无效书会退回供修改。
- **对话框**：加密者手持紫色染料按 Q，按窗口显示的数字顺序填写三条提示，每条 1～24 个字符。提交需要加密者有 OP 权限，关闭不保留草稿；普通玩家使用书模式。

拦截者和解密者使用紫色染料按 Q 打开选码窗口，依次选择三个不同数字。只有当前负责该阶段的人能够提交。

左上角显示敌方历轮已结算提示，按数字归类，长内容每 5 秒翻页；“密电记录”物品按 Q 可在聊天栏查询己方历史提示。每局从共享词库抽出八个不重复词语，重新开局才换词并清空笔记；三人局只使用合作队四词。词库维护见[pool.mcfunction](../data/decrypto/function/words/pool.mcfunction)。

提示须与关键字有实际语义联系，使用公开常识；不要直接使用关键字或翻译，不要用拼音、字数、位置、谐音或私人暗号。整场提示不重复，公布后不修改；加密者不参与队友猜码讨论。这些交流规则由玩家共同遵守。

## 设置

设置按桌保存，仅在大厅修改：

- 组队方式：随机（默认）或固定座位；仅用于 4～8 人局。
- 分队模式轮数：1～32 轮，默认 8 轮；三人模式固定五轮。
- 提示输入：书（默认）或对话框。

## 管理与中断

游戏编号 `6`，命名空间 `decrypto`。以下命令需要命令权限，操作同维度 8 格内最近一场本游戏，无需填写桌号；指定桌号、建桌、删除及 Debug 见[主说明](../README.md)。

```mcfunction
# 查看本桌轮数
/scoreboard players get @e[type=minecraft:marker,tag=dc.controller,distance=..8,sort=nearest,limit=1] dc_round

# 中止附近最近一场谍报风云并返回大厅
/function decrypto:admin/abort
```

`/reload` 保留对局、词语、累计记录和设置；书模式的提示草稿保留，对话框模式可用染料重新打开。参与者离线会中止本局，也可用桌边“结束游戏”投票。

联机检查见[验收清单](验收清单.md)。
