# 斗地主人机策略

出牌仍通过原规则判定和提交入口，每次行动约间隔1秒。叫分策略保持不变：无人叫分时叫1分，否则不叫。

选牌仅读取自己的牌面、桌面上一手以及对手公开剩余张数，不查看他人牌面。

1. 能合法一手出完时优先结束本局，包括完整复杂翅膀组合。
2. 领出支持全部常用牌型，比较出牌张数、主牌大小、拆分对子/三张/炸弹的代价，不再固定最小单张。
3. 跟牌比较可压候选，平时偏好小牌及保留炸弹、王炸。自己超过6张且所有对手都超过2张时，普通跟牌不出炸弹或王炸；没有其他合理应牌时主动不出。自身剩6张以内或对手报单/报双时解除限制，仍按评分比较；能一手出完始终优先。
4. 翅膀优先使用散单和完整对子，再考虑拆较大组合。
5. 农民不压农民队友，除非本手可直接出完。
6. 对手只剩1张时提高大单张优先级，剩2张时提高大对子优先级。

这是有界启发式策略，不是完整博弈搜索，也不保证最优胜率。候选集合不会穷举所有翅膀排列。普通阶段跟牌时也会放弃评分代价达到100的拆牌方案，避免为压一手而拆掉炸弹或王炸；这不是对炸后连续获胜的保证。领出不启用让牌限制。玩家手牌窗口的合法性探测不使用上述保牌策略，仍能选择合法炸弹。

验证：tools/check_doudizhu_bot.mjs执行真实选牌及牌型判定函数，覆盖整手顺子/连对/飞机、保炸、队友让牌、残局拦截、随机合法性和指令开销；连续多局由check_doudizhu_match.mjs覆盖。

主动领出时，A、2和王的单张／对子／三张等增加保留代价；候选出牌后每留下一个3至J的小散单，再增加代价，避免先空出大对子再甩小单。对手报单时尽量领出非单张。大牌拦截加分仅用于跟牌，不再用于主动领出。能一手出完仍覆盖所有保留代价；这是局部剩牌结构评估，不是多轮必胜搜索。
