# 斗地主人机策略

出牌仍通过原规则判定和提交入口，每次行动约间隔1秒。叫分策略保持不变：无人叫分时叫1分，否则不叫。

选牌仅读取自己的牌面、桌面上一手以及对手公开剩余张数，不查看他人牌面。

1. 能合法一手出完时优先结束本局，包括完整复杂翅膀组合。
2. 领出支持全部常用牌型，比较出牌张数、主牌大小、拆分对子/三张/炸弹的代价，不再固定最小单张。
3. 跟牌比较可压候选，平时偏好小牌及保留炸弹、王炸；无其他可压组合时仍可使用炸弹。
4. 翅膀优先使用散单和完整对子，再考虑拆较大组合。
5. 农民不压农民队友，除非本手可直接出完。
6. 对手只剩1张时提高大单张优先级，剩2张时提高大对子优先级。

这是有界启发式策略，不是完整博弈搜索，也不保证最优胜率。候选集合不会穷举所有翅膀排列。
