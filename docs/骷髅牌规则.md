一、游戏目标
核心胜利条件：成为首位累计挑战成功两次的玩家。或成为唯一未被淘汰的玩家（其他玩家均失去所有手牌）。
核心机制：通过心理博弈与记忆判断，在放置圆盘（花/骷髅）和叫号挑战中压制对手。

二、游戏准备
人数与配件人数：2~6人（最佳4~5人）。
配件分配：每位玩家获得：相同点数（A-6）不同花色的四张牌，其中包含：1张骷髅牌（牌顶标记为骷髅），3张花牌（牌顶标记为鲜花），其余卡牌面朝下作为胜利标记。
初始设置
玩家将自己的卡牌（3花+1骷髅）拿在手中，不可被他人查看。


三、核心流程（每轮三阶段）
阶段1：扣牌所有玩家同时选择一张手牌，面朝下放置在自己的面前。放置后，由起始玩家开始顺时针行动。

阶段2：加码或叫号
行动选项：
加码：再选一张手牌面朝下叠放在自己面前的卡牌上，仅限没有玩家选择叫号时可选
叫号宣告数字 N，表示自己能连续翻出 N 张花牌，而不翻出任何一张骷髅牌玩家放弃加码时必须执行
叫号后流程：
竞标：宣告更大数字
放弃：退出本轮挑战，将面前的卡牌推至中央。
后续玩家不可再加码，仅能选择；
当仅剩一人未放弃时，该玩家成为挑战者（宣告数字最大者）。

阶段3：挑战判定翻牌规则：挑战者必须先翻完自己面前的所有卡牌。再按任意顺序翻其他玩家的卡牌，但必须从上至下逐层翻（不可跳过上层直接翻下层）。
胜负判定：挑战成功连续翻出 N 张花牌且无骷髅获得一张胜利标记代表1次胜利
挑战失败翻出骷髅牌（无论何时）所有玩家将自己卡牌收回手中；挑战失败的玩家随机弃置一张手牌（秘密执行）

弃牌规则：若从他人牌堆翻出骷髅 → 从挑战者手牌中随机弃置一张。若从自己牌堆翻出骷髅 → 挑战者自行秘密弃置一张。
淘汰：玩家失去最后一张手牌时出局，移出牌托。

四、胜负判定与关键规则
全局胜负条件
条件1：任意玩家获胜两次（拥有2张胜利标记）。
条件2：仅剩一名玩家拥有手牌（其他人均淘汰）。
特殊规则起始玩家轮换：每轮结束后，挑战者成为下一轮起始玩家。弃牌保密：被弃置的牌仅挑战者知晓内容，移出游戏不再使用。
