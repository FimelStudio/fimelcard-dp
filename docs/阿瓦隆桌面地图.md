# 阿瓦隆桌面路线图

八人牌桌上的阿瓦隆在开局展示羊皮纸路线地图，尺寸与八人桌国际象棋棋盘一致。路线的 1–5 号圆圈对应五轮任务；未完成时显示编号，任务成功覆盖绿色勾章，失败覆盖红色叉章。组队投票否决不会消耗任务节点。七人及以上第四轮仍按两张失败票才失败的规则标色。

地图从本桌 `data.avalon.results` 恢复，切换阶段或 reload 不会丢失。每个展示实体有本桌 av_id，正常结算后保留五秒，再走原有清理与恢复牌桌流程；投票中止和离线中止立即清理。

纹理位于资源包 assets/card/textures/avalon/map；使用程序绘制的地图图案，11 张 512×512 PNG（底图及五轮各两种透明覆盖标记）。没有强制亮度覆盖。

验证时请检查：开局五个编号、成功/失败的对应位置、否决不推进、保护轮、刺杀阶段保留任务结果、结算五秒后恢复、并行两桌不互相清理、reload 后保留颜色。

## 结算身份翻牌

正常胜负结算时，按 UNO 八人桌的八个座位位置，在实际玩家面前摆出身份牌。先显示统一牌背，随后抬牌、翻至身份正面并落回桌面。角色与座位在清理快捷栏身份牌之前复制到展示实体，因此不会因玩家身份分数被重置而放错牌。空座位不生成牌。所有身份牌在五秒结算展示结束时按本桌 av_id 清理；中途投票结束或离线中止不公开身份。
