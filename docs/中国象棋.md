# 中国象棋

Minecraft Java 26.2，游戏编号 **13**，命名空间 `xiangqi`。支持 **1～2 人**，四人桌、八人桌均可使用；普通玩家游玩无需 OP。一人开始会自动加入电脑对手，两人开始则正常对弈。

## 开始与操作

1. 入座后，在牌桌中央选择「中国象棋」，棋盘和棋子立即出现。
2. 开始前腾空快捷栏最后一格，在「游戏设置」调整配色、方向、红黑方分配、人机难度、提示与计时，点击选项立即生效。
3. 开始后自动坐到己方棋盘一侧，**红方始终先行**。右键自己的棋子选中，再右键落点或对方棋子行棋、吃子；再次选择另一枚己方棋子会转移选择。非法行棋取消选择。
4. 选中处显示金色框，合法落点显示绿色框；吃掉的棋子排列在**吃子者右手边**。行棋与吃子均有动画，聊天栏记录走法，actionbar 显示选中棋子名称。
5. 手持快捷栏最后一格的「中国象棋 · 对局菜单」按 **Q**，打开悔棋、和棋、认输菜单。双人悔棋与和棋须对方同意；人机自动同意，悔棋退回到自己上次行棋之前，连同电脑应手一起撤回。自己尚未行棋时不能悔棋；认输需要确认。

正常结束 5 秒后返回大厅，保留终局棋面与吃子区；重新开局或切换游戏后才重摆。`/reload` 保留进行中的棋局、阵营与时钟，并恢复座位，旧菜单失效后按 Q 重开。玩家离线、结束投票通过或管理员中止会立即返回大厅，同样保留当前棋面。

## 规则

棋子位于 **9 路、10 横线的交点**。红黑双方各 16 枚棋子，轮流走一着；不能使自己的帅／将受攻击，也不能让将帅在无阻挡的同一路上照面。

| 棋子 | 走法 |
| --- | --- |
| 车 | 沿直线任意距离，不能越子 |
| 马 | 走「日」，马腿有子则该方向不能走 |
| 相／象 | 走「田」，象眼有子不能走，不能过河 |
| 仕／士 | 九宫内斜走一格 |
| 帅／将 | 九宫内横走或直走一格 |
| 炮 | 不吃子时同车；吃子须隔恰好一枚棋子作炮架 |
| 兵／卒 | 每次前进一格，过河后也可横走一格，不能后退 |

将死、**困毙（无合法着法）**、对手超时或认输即获胜。不会直接吃掉帅／将。双方同意和棋，或双方均只剩帅／将、仕／士、相／象等非进攻子力时和棋。基础走法可参阅 [Xiangqi.com 棋子说明](https://www.xiangqi.com/help/pieces-and-moves)。

重复局面与自然限着采用本包的休闲简化规则：同一局面、同一行棋方第三次出现时，若只有一方在重复过程中持续将军，该方判负；其他情况和棋。连续 **120 着（双方合计）未吃子**也判和，兵卒移动不会重置计数。尚不裁定长捉、一将一捉等复杂棋例，也不扣除正式自然限着规则中的特定将军次数；比赛请另行约定裁判规则。正式规则背景见 [Xiangqi.com 行棋限制](https://www.xiangqi.com/help/limits)。

## 设置

| 项目 | 选项 |
| --- | --- |
| 棋盘配色 | 经典、木色 |
| 棋子配色 | 经典红黑、木色 |
| 棋盘方向 | 南北向（红方南侧）、东西向（红方西侧） |
| 红黑方分配 | 按座位自行选边、随机分配；默认随机，开局自动换到对应座位 |
| 每人计时 | 无限制、5／10／15／20／25／30 分钟；默认 10 分钟 |
| 单人人机难度 | 简单随机合法行棋、普通子力与位置评估、困难增加对方应手搜索；默认普通 |
| 可走点提示 | 开／关，默认开启 |

设置仅作用于本桌，开局后锁定。倒计时显示在棋盘上方，只扣当前行棋方时间，移动动画期间暂停，无加秒；按游戏刻计时，服务器卡顿时实际耗时会变长。人机搜索分散到多个游戏刻执行，属于本包内置的休闲练习对手。

按座位自行选边时，入座位置决定红黑方；双人须两侧各一人，单人可选任一侧，由电脑执另一方。从侧面入座不能直接开始自行选边模式，可换座或改用随机分配。

| 桌型与方向 | 红方座位 | 黑方座位 |
| --- | --- | --- |
| 四人桌，南北向 | 3 | 1 |
| 四人桌，东西向 | 4 | 2 |
| 八人桌，南北向 | 5／6 | 1／2 |
| 八人桌，东西向 | 7／8 | 3／4 |

## 管理与调试

以下命令需要命令权限。在桌旁中止最近一场中国象棋，无需填写桌号：

```mcfunction
/function xiangqi:admin/abort
```

精确指定桌子时，将 `1` 换成实际桌号，在该桌所在维度执行：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=13,ct_state=1},limit=1] at @s run function xiangqi:game/abort

# 查看自己的桌号；接收／停止接收调试日志
/scoreboard players get @s ct_id
/tag @s add ct.debug
/tag @s remove ct.debug
```

管理中止会清理参与者状态并返回大厅。圆形棋子及棋盘为本项目制作，可编辑模型与生成脚本保存在资源包 `.source/xiangqi/`；移动、吃子与开局／结束音使用 [Xiangqi.com 公开提供的音效](https://www.xiangqi.com/help/sounds)，原文件、来源及哈希随资源包保留。未增加额外前置数据包。
