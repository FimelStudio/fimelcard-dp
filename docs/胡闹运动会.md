# 胡闹运动会

编号 **23**，命名空间 `magical_athlete`。2～6 名真人，无需 OP；四座桌最多 4 人，5～6 人使用八座桌，座位可不连续。

为队伍招募拥有奇妙能力的选手，进行四场投骰竞速。选手可能推拉别人、交换位置、绊倒对手，或蹭着其他能力一起前进。每场只争前两名，四场累计积分最高者获胜，平分共同获胜。

本游戏根据 CMYK《Magical Athlete》现代版基础规则制作，36 名选手；不包含旧版拍卖选角或扩展包。角色中文名为本包译名，美术为本项目重绘。

## 入座与操作

安装配套资源包，腾空**快捷栏九格**。选择“胡闹运动会”，调整设置后开始。右键桌面候选角色选中，再次右键招募，左键取消；手持角色物品也可按 **Q 两次**确认。角色名字后附能力说明。

秘密出场同样手持角色按Q两次提交。第1～6格显示当前候选或技能选项，第7格翻页，第8格骰子按Q，第9格取消选中；取消不会跳过规则要求的必选能力。二选一技能、预测数字、目标选手和跳过选项改为手持按 **Q 一次**生效；指定选手和落点也可直接右键棋子或赛道格子两次。骰子只在本人能够投骰时发放，等待别人或需要先回应其他技能时收回。双胞胎的大量候选能力可用“查看全部候选能力”物品主动打开单页窗口，其余日常流程不弹窗。

已招募角色常驻主物品栏，标注“未使用／本场已提交／已使用”，按Q随时查看能力；秘密出场时未使用角色也可直接按Q两次提交。两人局每次秘密提交后会私下告知本人是第几位选手。快捷栏的临时选项与主物品栏队伍卡相互独立，请为队伍卡留出4格（两人局8格）。

未轮到自己招募时，右键候选牌可查看能力；比赛中右键棋子也可查看选手能力。只有本人正在处理选手目标技能时，该点击才用于选中／确认目标；查看不会替别人行动，也不会误选预测数字或二选一技能。

BetterTitle左右两侧显示玩家名字、总积分和本场积分，中间居中提示当前阶段和待回应玩家；操作失败的具体原因保留数秒。角色物品使用各不相同的立体模型；仅本人GUI／第一人称显示具体角色，第三人称、掉落和其他展示方式显示通用问号棋子。丢出后回收并恢复，库存和选择仍以服务器规则状态为准。

比赛棋子上方以 vertical 精灵图文本显示所属玩家的皮肤头像（含帽子层），朝向观察者并跟随棋子移动；同格拥挤时缩小头像，淘汰时一同隐藏。棋盘上方公开信息显示玩家名字、棋子名字、总分和本场分数；当前行动玩家名字右侧标有 `▶`，秘密阵容在揭晓前不公开。聊天中的移动按实际位移显示“前进”“后退”或“原地停留”；对目标发动能力时同时写出双方玩家名和棋子名。

移动采用相邻格心之间的连续插值，转弯沿赛道走。结算刷新复用棋盘、骰子、选手、名字和公开信息实体；招募时保留仍在候选池里的棋子，防止整盘删除重建造成闪现。维护入口为 `tools/build_magical_athlete_scene.py`，由直接交互生成器自动调用。

公开选角、每人尚未使用的队伍及积分可以查看；每场上场选择在全员提交前保密。两人局需选两名，全部选好后一起公开。角色已使用就不能再上场。

掷骰时先确定本次结果，再播放骰子翻滚与移动；动画期间不能重复提交。角色能力由实际拥有者决定，不能替别人操作。没有待处理能力时按屏幕提示投骰或等候；小场结算展示六秒后自动进入下一场，保留秘密出场流程。

## 招募与赛程

默认蛇形招募：

1. 投骰决定起选玩家，出现并列最高时按规则寻找下一位单独最高者，全部并列则重投。
2. 亮出人数两倍的角色，从起选玩家顺时针各选一次，再从末位逆时针各选一次。
3. 从原起选玩家的左邻开始，亮出新的一组，再进行一次顺序、逆序选角。每人得到 4 名选手。

设置中也可选择随机发队，适合第一次游玩或快速开局。

共四场，默认赛道为**普通 → 狂野 → 普通 → 狂野**。每场全员秘密选择一名未使用选手，全部确认后公开并放到起点。第一场重新投骰决定先行动者；之后通常由上一场最落后或最早被淘汰的选手所属玩家开始。

| 场次 | 冠军 | 亚军 |
| --- | ---: | ---: |
| 第一场 | 3 分 | 1 分 |
| 第二场 | 4 分 | 2 分 |
| 第三场 | 5 分 | 3 分 |
| 第四场 | 6 分 | 4 分 |

角色能力和狂野赛道还可能发放或扣除积分。一旦第二名冲线，该场立即结束，未完成的其他行动不再继续。冠军、亚军已退出赛道，通常不再触发能力；角色规则有明确例外时按角色处理。

### 两人玩法

每人招募 **8 名**选手，每场各选两名，同时有四名选手参赛。两次各亮 8 张，按 `ABBAABBA`、`BAABBAAB` 招募；随机发队时仍每人 8 名。

按 2026 年 8 月更新，**每场选择参赛选手的先后确定本场固定行动顺序**，不是每轮临时换序。先完整结算一名选手，再进入下一名；插队、额外回合仍按角色能力处理。能力中的“其他选手”包括自己的另一名选手。第二场起由上场得分较少的玩家先行动，平分则投骰决定。

## 移动、能力与狂野赛道

**主移动**是自己回合投骰后进行的那次移动。能力造成的额外移动单独结算，不算主移动；“主移动掷出某点数”的能力只看最终采用的骰值。重投前的结果不触发以骰值为条件的能力，重投动作本身仍可能触发能力。

- **经过**：一次移动开始时在某选手后面，结束时到其前面；途中同格不算停在一起。
- **同格**：完成移动或传送后停在同一格。共同到达的选手之间不互相触发同格能力，按 2026 年 8 月规则更新处理。
- **传送**：直接换到目标格，不算移动或经过；到达后仍可触发适用的停格效果。
- **绊倒**：完成当前移动，再跳过下一次主移动。不会取消本次已进行的移动，期间被动能力和额外移动仍可发生。
- **零格**：移动 0 格不算移动；起点算格子，不能退到起点后面。

先完成当前移动，再按**赛道 → 当前行动选手 → 其余选手顺序**处理同时发生的效果。可选能力由本人使用物品选项或桌面目标选择，其余能力自动生效。重复形成同一闭环时只走完一个循环；因能力导致无人能完成比赛时按规则结束该场，不补发剩余名次积分。

狂野赛道上的星星提供 1 分；绊倒格跳过下一次主移动，箭头格按方向再移动指定格数。箭头引起的移动独立于原主移动，也可能继续触发其他效果。界面会展示当前选手的能力和待决定事项，无需记住全部角色。

## 设置与展示

游戏设置沿用公共单页文本选项：点击即生效，仅大厅可改；牌桌皮肤下面可调整椅子数量。提供招募方式、赛道安排、棋盘方向、动画速度和背景音乐开关。设置只作用于本桌。

普通／狂野赛道使用同一套格心数据驱动棋盘贴图和棋子位置，四座、八座桌按桌面缩放；棋子同格时错开放置。骰子展示最终点数，选手移动、能力、绊倒及颁奖配合动画、粒子和音效，音乐可单独关闭。

任一本局玩家离线，整桌暂停，骰子、能力、移动和音乐一起暂停；原名单全部回来后继续。退出椅子不代表退出对局。游戏中止或结束后，离线玩家稍后重进会清理旧局操作物与身份；不会清理普通物品。

## 管理命令

在该桌所在维度执行，需要命令权限。

```mcfunction
# 中止8格内最近一场胡闹运动会，保留牌桌
/function magical_athlete:admin/abort

# 查看自己的桌号
/scoreboard players get @s ct_id

# 将1替换为实际桌号，精确中止
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=23,ct_state=1},limit=1] at @s run function magical_athlete:game/abort

# 接收／关闭牌桌调试日志
/tag @s add ct.debug
/tag @s remove ct.debug

# 查看8格内最近一桌的公开阶段、骰值和待答玩家
/function magical_athlete:debug/state
```

### 立体棋子与行动提示

36 个角色均使用不同几何的完整立体模型：半人马、飞艇、香蕉、野兔等按身份分别设计；招募、比赛和手持不再使用圆饼徽章。脚底统一为模型 Y=8，招募和比赛分别定位在控制器上方 1.055／1.052 格，覆盖四／八座桌及两个方向。手持使用独立缩小姿态；秘密阵容在其他玩家的第三人称中显示问号棋子。

聊天记录招募、阵容提交与揭晓、轮次、技能、骰值、移动、绊倒、起身、出局、到达和得分。subtitle 提醒本人接手、技能回应、状态变化或获胜；actionbar 持续说明当前操作和失败原因。bettertitle 显示各队累计／本场分数，以及本场角色、所在格和绊倒／到达／出局状态。

招募角色和待投骰骰子有少量提示粒子，技能的合法角色目标／落点有金色提示点；实际选中后沿用青色发光。秘密阵容在全员完成前不公开角色。

比赛事件不再在棋盘中央生成传送、摔倒、奖牌、金币等短暂徽章，避免被误认为旧圆饼棋子。事件文字、音效、粒子及得分结算照常进行；刷新和事件开始时按桌清理旧版本遗留的临时道具。
