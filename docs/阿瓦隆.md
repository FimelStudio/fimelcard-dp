# 阿瓦隆

隐藏身份的阵营推理游戏：好人争取完成三次任务，坏人混入队伍破坏任务，刺客尝试找出梅林。

游戏编号 **16**，命名空间 `avalon`。仅支持**八人桌、5～8 名真人**，正常游玩无需 OP。以下为本包实际玩法，包含提前刺杀和连续否决后的强制组队。

## 开始与操作

1. 所有人腾空快捷栏**第 1、2、8 格**，入座选择阿瓦隆并开始。身份和初始队长随机分配。
2. 第 8 格是自己的身份牌，手持按 **Q** 打开当前操作。私人身份情报显示在本人 actionbar；关闭窗口后可再次按 Q。
3. 队长在对话框中选择队员，组织讨论后确认队伍。全员使用第 1、2 格的绿／红染料，按 **Q** 提交同意／反对。
4. 队伍通过后，仅队员收到任务染料：绿为成功、红为失败，按 Q 提交。好人提交失败会被拒绝；双方收到相同外观的工具。
5. 刺客通过身份牌菜单提前翻牌或在强制刺杀阶段选择目标，确认后结算整场。

当前没有独立玩法参数，设置页可调整牌桌皮肤。游戏中下马仍保留身份；结束投票或玩家离线会中止本场。`/reload` 保留身份、阶段、已投的秘密票和任务结果，旧窗口失效后按 Q 重开。

## 角色与任务人数

| 人数 | 好人 | 坏人 | 第1～5轮任务人数 |
| --- | --- | --- | --- |
| 5 | 梅林、派西维尔、忠臣 | 莫甘娜、刺客 | 2／3／2／3／3 |
| 6 | 梅林、派西维尔、忠臣×2 | 莫甘娜、刺客 | 2／3／4／3／4 |
| 7 | 梅林、派西维尔、忠臣×2 | 莫甘娜、刺客、奥伯伦 | 2／3／3／4／4 |
| 8 | 梅林、派西维尔、忠臣×3 | 莫甘娜、刺客、爪牙 | 3／4／4／5／5 |

- **梅林**知道全部坏人，包括奥伯伦；须避免被刺客认出。
- **派西维尔**看到梅林与莫甘娜两名候选人，无法直接区分。
- **莫甘娜、刺客、爪牙**互认队友，不知道奥伯伦是谁。
- **奥伯伦**与其他坏人互不相认；**忠臣**没有额外情报。

本包未接入莫德雷德、兰斯洛特或湖中仙女。

## 流程与胜负

- **组队表决：**同意票严格过半才通过，平票否决。否决后轮换队长，不推进任务。人数为 n 时，连续 n−1 次否决后，第 n 次队伍强制通过；通过后清零否决次数。任务完成后也轮换队长。
- **秘密任务：**所有队员提交后，洗牌公开任务票，不显示票与玩家的对应关系。组队表决则在全员提交后公开每人的同意／反对。
- **任务结果：**通常有一张失败票即失败；仅 **7、8 人局第 4 轮**须至少两张失败票。成功给好人 1 分，失败给坏人 1 分。
- **整场结束：**坏人先得 3 分直接获胜；好人先得 3 分进入强制刺杀。刺客也可在此前提前翻牌刺杀，须二次确认。刺中梅林坏人胜，否则好人胜；刺杀后整场结束。

桌面路线图显示五轮任务，成功为绿色勾、失败为红色叉；否决不消耗节点。任务特效只产生粒子与声音，不破坏方块。正常结束公开身份，并在各玩家桌边翻牌展示，5 秒后回大厅；中止不公开身份。

身份牌仅在本人背包和第一人称显示正面，其他手持、掉落及展示上下文使用统一牌背。表决工具对其他玩家使用统一外观；任务票不通过持物外观或公开消息泄露。

## 管理与资源

以下需要命令权限。中止同维度 8 格内最近一场阿瓦隆：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_game=16,ct_state=1},distance=..8,sort=nearest,limit=1] at @s run function avalon:game/abort
```

指定桌号时，将 `12` 换成实际值，在目标维度执行：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=12,ct_game=16,ct_state=1},limit=1] at @s run function avalon:game/abort
```

当前没有 `avalon:admin/abort` 玩家包装入口。通用建桌、删桌与 Debug 见[项目 README](../README.md)。

七种角色牌、统一牌背及路线图已在配套资源包 `assets/card/` 中，结算翻牌使用独立双面模型。任务地图从本桌 `data.avalon.results` 恢复，不因重载重算结果。路线参考图保留于[阿瓦隆路线图](阿瓦隆路线图.png)。

## 验收

`python tools/check_avalon.py` 检查函数引用、阶段与窗口校验、角色配置、任务人数和投票边界，属于静态／规则检查。真人联机仍须复测 5～8 人配置、私人情报、表决外观、保护轮、提前／强制刺杀、结算翻牌、重载和双桌隔离，见[统一验收清单](验收清单.md)。
