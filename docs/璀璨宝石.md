# 璀璨宝石

游戏编号 **22**，命名空间 `splendor`。Minecraft Java 26.2，支持四人桌、八人桌，**2～4名真人**，默认无需 OP；暂不提供人机。

你是经营宝石生意的商人。收集筹码，购买提供永久折扣的开发卡，吸引贵族来访，用更高的声望赢下对局。本实现采用经典基础版，不含对决版及扩展。

## 开局与操作

腾空快捷栏最后一格，入座后选择「璀璨宝石」。游戏开始后，最后一格的「璀璨宝石 · 市场」按 **Q** 使用。

- **查看开发卡**：点击牌面，查看声望、原价和永久折扣后的费用；选择购买或预约。
- **拿取宝石**：用加减选择数量，点击确认才实际领取。
- **我的预约牌**：只有自己可见，点击后购买。盲抽预约从指定级别的牌堆顶抽取。
- **玩家资产／查看贵族**：查看公开的筹码、永久折扣、声望、已购数量及贵族要求。
- **退回筹码／选择来访贵族**：出现待办时由当前玩家完成，不能跳过。

回合外也可打开菜单查看公开市场与自己的预约牌。筹码和已购卡信息公开，预约牌身份仅向本人显示；桌面和聊天不会暴露盲抽内容。菜单用一次性窗口、局面版本、桌号及重载代号校验，旧窗口须重新打开。

## 规则

### 开局摆放

共有90张开发卡：一级40张、二级30张、三级20张。三级分别洗牌，各翻开4张，旁边放置各级剩余牌堆。10位贵族随机展示「人数＋1」位。

| 真人数量 | 每色普通宝石 | 黄金 | 展示贵族 |
| --- | ---: | ---: | ---: |
| 2 | 4 | 5 | 3 |
| 3 | 5 | 5 | 4 |
| 4 | 7 | 5 | 5 |

普通宝石依次为钻石（白）、蓝宝石（蓝）、祖母绿（绿）、红宝石（红）、缟玛瑙（黑）；黄金为万能筹码。

### 每回合一次主行动

1. **拿异色**：拿3颗颜色不同的普通宝石。银行只剩1／2种颜色时，拿剩余全部种类，每色1颗。不能空拿或直接拿黄金。
2. **拿同色**：拿2颗同色普通宝石；拿之前，银行该色至少有4颗。
3. **预约开发卡**：拿走市场上的1张明牌，或某级牌堆顶牌；库存有黄金时同时领取1颗，没有黄金仍可预约。最多预约3张，预约后不能丢弃，只能购买。
4. **购买开发卡**：购买市场明牌或自己的预约牌，准确支付折扣后的费用。花掉的普通宝石和黄金都返回银行。

明牌被购买或预约后，立即补同级牌。对应牌堆已空时，空位不再补充。

### 永久折扣与黄金

每张已购开发卡提供1枚对应颜色的永久折扣，之后买牌都可使用，不会消耗；折扣足够时可以免费购买。开发卡自身还可能提供声望分。

例如一张卡原价为蓝3、绿2，你已有蓝2、绿1永久折扣，则只需蓝1、绿1。可以支付这两颗，也可以减少普通宝石、用等量黄金代替。界面默认优先普通宝石，可手动调整；不允许多付、漏付或使用尚未购买的预约牌折扣。

### 筹码上限

包括黄金在内，每回合结束时最多持有10颗筹码。主行动后超出时，需要自己选定退回哪些，恰好退到10颗；可以退本次刚拿到的筹码。不能多退，也不能在不超限时主动退珠。永久折扣不占筹码上限。

### 贵族来访

贵族只检查永久折扣，不检查手持筹码。达到要求后不能拒绝来访，不花费筹码，也不占主行动；每位贵族提供3分。每回合最多来访一位，同时符合多位时由本人选择，其余留在市场。

### 结束与平局

有人在自己的回合末达到 **15分**，标记为最后一轮，继续至本轮最后一人完成回合，使所有玩家行动次数相同。触发者不一定获胜。

先比较声望，高者胜；声望相同则已购开发卡更少者胜。两项仍相同，相关玩家共享胜利。未买的预约牌不计分、不提供折扣，也不计入已购张数。

## 游戏设置与表现

设置为单页可点击文字，点击立即生效；皮肤和椅子数量沿用公共菜单。

| 选项 | 可选值 | 默认 |
| --- | --- | --- |
| 行动顺序 | 按座位／随机 | 按座位 |
| 背景音乐 | 关闭／开启 | 开启 |

按座位时从最小实际座号开始，跳过空座，依次行动。随机顺序仅开局抽签，不更改玩家座位，重载不重新分配。

两种桌型按比例摆放公开市场、三级牌堆、贵族和银行。拿珠、退珠、购买、预约及贵族来访有短动画和音效；盲预约使用中性牌背／宝石袋表现。胜者使用内置 SK Firework。背景音乐使用「唱片机／音符盒」音量，音效使用「方块」音量；局内也能切换音乐。

掉线采用公共暂停：停止操作、表现进度和音乐，等原参与者全部返回后继续；可投票结束或由管理员中止。`/reload` 保留牌堆、预约、筹码、折扣、贵族和当前待办，不重复随机或扣费。结束后保留公开终局，重新开局、切换游戏或删桌时清理；离线成员在旧局结束后上线时清理旧道具与标签。

## 管理命令

有命令权限的玩家可在同维度8格内直接中止最近一场璀璨宝石，无需桌号：

```mcfunction
/function splendor:admin/abort
```

精确指定桌号时，将 `1` 替换为目标桌号：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=22,ct_state=1},limit=1] at @s run function splendor:game/abort
/tag @s add ct.debug
/tag @s remove ct.debug
```

正常游玩通过操作物与 trigger 完成，无需为全员授予 OP。结束投票、中止与删除牌桌不会删除方块桌面或其他桌的内容。

## 资源与重建

规则参考 [Space Cowboys／Asmodee 基础版规则书](https://cdn.svc.asmodee.net/production-unboxnowcom/uploads/2022/02/Splendor-EN.pdf)。开发卡与贵族的数据、颜色和来源见 `tools/splendor_cards.json`；模型、牌面和宝石图标为本项目原创几何／像素画，未使用原版插图。

音效复用已内置的 Kenney《Casino Audio》《Impact Sounds》，音乐使用 RandomMind《The Old Tower Inn》循环曲，均为 CC0。原始文件、许可、来源及引用哈希保留在资源包 `.source/catan/audio/` 与 `.source/splendor/audio/`，不重复打包声音。

在数据包根目录执行 `python tools/build_splendor.py` 重建规则、资源、界面和注册。可编辑模型及预览位于资源包 `.source/splendor/`。规则窗口正文只维护在 `tools/game_rules.json`，构建仅更新本游戏手册，不重写其他游戏窗口。
