# 《谍报风云 Decrypto》（截码战）完整整理规则
## 游戏总览
2‑4位玩家，分成两支队伍对抗（另有3人特殊规则）。

## 核心概念名词
1. **关键字**：每队4张，只有本队成员可以看见，对应数字1‑4。密码就是从1‑4里选出3个数字。
2. **加密者**：每轮队内负责看密码卡、创作3条提示的人。
3. **拦截指示物**：猜对对手完整密码获得，2个直接赢。
4. **错误传讯指示物**：队友猜不出自家密码获得，2个直接输。
5. **笔记纸**：两面；白色记录白队提示，黑色记录黑队提示；底部记录提示‑数字对应关系，用于推理对手关键字。

**目标**：向队友传递密码，队友可以读懂提示，但对手要无法读懂；同时尝试拦截破译对手队伍的密码。
1. 成功**拦截对手密码2次**，队伍直接胜利。
2. 自己队伍解密失败**2次**，队伍直接失败。

> 每队拥有4个仅队内可见的**关键字**，密码是3位数字，分别对应4个关键字里的3个。加密者给出3条提示，队友需要猜出3位数字密码；对手同时根据提示尝试猜密码拦截。

## 胜利与失败条件
1. **胜利**：队伍累计获得**2枚拦截指示物**，立刻获胜；拦截指示物来自猜对对手完整3位密码（数字、顺序全部正确）。
2. **失败**：队伍累计获得**2枚错误传讯指示物**，立刻落败；错误传讯指示物来自队友没能解出己方加密者给出的密码。
3. **平局处理**，出现以下任意一种情况进入平局判定：
    - 一队同时拿到2拦截、2错误指示物
    - 一轮结束两队都2枚拦截指示物
    - 一轮结束两队都2枚错误传讯指示物
    - 总共8轮结束仍然没有分出胜负
    - 平局计分：拦截指示物+1分，错误传讯‑1分；分数高的队伍胜利。分数仍相同：两队轮流猜测对手4个关键字，猜对更多队伍获胜；依旧相同则双方共同胜利。

## 提示的强制规则（非常重要）
加密者每轮必须给出3条提示，所有人（包括对手）都会听见全部提示。
✅允许：词语、短句、哼唱、跳舞、表演等任意形式。
✅提示必须和对应关键字**有语义实质关联**。
✅提示必须使用公开常识信息。
✅被别人提问时，你必须解释每条提示和关键字的关联逻辑。
❌禁止：
1. 不可以使用关键字本身，不可以使用关键字翻译/其他语言版本。
2. 禁止拼音、字数、位置、读音这类间接线索。
3. **整场游戏，提示不能重复使用**，已经说过的词不能再次拿来当提示。
4. 不能拿只有你私人知道的生活私事作为提示。
5. 提示一旦公布，不能修改、撤回、补充。

## 标准回合完整流程（4‑P 两队模式）
每轮两队各选出一名**加密者**，角色轮流担任。
> 第一轮：**不允许拦截对手密码**，缺少信息。

1. **抽取密码卡**：两队加密者秘密抽取本队密码卡，查看3位数字密码，不给其他人看。
2. **书写提示**：加密者在笔记纸写下对应3个数字密码的3条提示。沙漏机制：一方写完提示，翻转沙漏；另一方必须沙漏走完前写完3条提示。
3. **宣读提示**：白队加密者读出自己3条提示；两队所有人记录这组提示。
4. **队内讨论**：两队分开讨论，分别写下自己猜测的密码。**加密者不参与队友讨论，不能做任何暗示。**
5. **黑队先拦截**：黑队大声念出猜测白队的3位密码（第一轮跳过此步）。
6. **白队解密**：白队念出自己猜测的己方密码。
7. **公布密码结算指示物**：白队加密者公开真实密码。
    - 如果黑队猜测**完全正确（数字+顺序）**：黑队获得1枚拦截指示物。猜错无惩罚。
    - 如果白队自己猜的密码错误：白队获得1枚错误传讯指示物。猜对己方密码无奖励。
8. **交换队伍**：重复步骤3‑7，换成黑队加密者宣读提示，白队尝试拦截，黑队解密，结算指示物。
9. **一轮结束**：
    - 检查胜负条件，达成则游戏结束。
    - 未结束：密码卡洗回牌堆洗牌；更换下一轮加密者，开启新回合。
> 笔记纸记录：把每一组提示‑对应数字记录下来，用来推理对手的4个关键字。

## 三人模式规则
1位玩家单独扮演**截密者**，另外2位玩家组成一支队伍对抗截密者。
- 队伍方流程和原版一致，每轮队伍选出加密者给出3条提示。
- 截密者目标：**5轮之内错误传讯指示物+拦截指示物>=2即可获胜**。
- 截密者成功猜对队伍密码，获得拦截指示物；队伍方传讯失败则获得错误传讯指示物。
- 第一轮依旧不能拦截。截密者自己不需要抽取密码卡，不用解密自己密码。
- 如果5轮结束错误传讯指示物+拦截指示物<2，则双人队伍获胜。



## 游戏小要点
1. 提示既要让队友懂，又要迷惑对手；提示太简单对手直接拦截，提示太晦涩队友解不开给自己加错误指示物。
2. 猜出对手关键字是巨大优势，但**不需要猜出关键字也可以拦截密码获胜**。
3. 提示不能复用，随着轮次增加，可用提示词会越来越少，难度上升。
