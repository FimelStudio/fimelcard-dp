# Fast Card

固定 **4 人**的传牌抢按游戏。轮流传递手牌，凑出指定组合后抢按桌心按钮，按设置完成多局后比较累计积分。

游戏编号 `1`，命名空间 `fast_card`。

## 开局与操作

1. 入座后在大厅选择 Fast Card，按需调整“游戏设置”，点击“开始游戏”。开局前所有玩家须清空九个快捷栏槽位。
2. 共 17 张牌：10、J、Q、K 各四张，加一张小丑牌。随机一人拿 5 张，其余各拿 4 张。
3. 持有 5 张牌的人选择一张按 **Q**，传给下一座位；收到牌的人接着传。未轮到时丢出的游戏牌会返还。
4. 凑出下表中的有效牌型即可抢按桌心按钮。其他人看到有人抢按后，也须尽快按下。

| 抢按者的牌型 | 抢按者得分 | 其他人得分 |
| --- | --- | --- |
| 四张同点数牌 | +1 | 最慢一人 −1 |
| 三张同点数牌＋小丑牌 | +2 | 最慢两人各 −1 |
| 四张同点数牌＋小丑牌 | +3 | 其余三人各 −1 |

每小局结算后显示排行榜并自动进入下一局。桌边“规则介绍”可随时查看规则，窗口不会暂停游戏；“结束游戏”累计 3 票后提前结束本场。任意玩家离线会结束本场并返回大厅；游戏中下马仍保留参与身份。

## 游戏设置

设置只在大厅保存，属于当前牌桌；切换游戏后仍会保留。

| 设置 | 可选项 |
| --- | --- |
| 本场小局数 | 界面可选 1～32 局，默认 5 局 |
| 无有效牌型乱按时立即判负 | 默认关闭：忽略无效抢按；开启后：乱按者 −1，并结束本小局 |

## 管理员与维护

在牌桌 8 格内执行，开始前先在大厅选好 Fast Card：

```mcfunction
# 开始最近一张处于大厅的牌桌（按该桌当前选择的游戏开局）
/function fast_card:admin/start

# 中止最近一场 Fast Card，保留牌桌并返回大厅
/function fast_card:admin/abort
```

游戏操作使用手牌和桌心按钮，无需手动提交局内 trigger。`/reload` 会尝试恢复当前牌局。
