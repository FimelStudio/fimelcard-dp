# 掼蛋测试人机

1～4名真人可开始，不足四方自动补齐测试人机，单人会补3名。随机分队会安排真人到不同方向；按座位模式每侧最多一名真人，八人桌同侧不可坐两名参与者。人机以独立gd.part实体参加发牌、排名、贡还与升级，不会收到私人手牌HUD或操作物品。掉线检测只统计本局真人。

人机分刻搜索338类候选，包括单张、对子、三张、三带二、顺子、三连对、钢板、同点炸弹、四王，以及逢人配补缺；每个候选都调用同一掼蛋牌型识别与压牌校验，最后通过正常出牌提交执行动画和结算。普通组合优先，保留炸弹，能一次出完优先；搭档领牌时通常让牌。不是穷举所有实卡组合的竞技AI，可能漏掉更优配牌或同花顺，适合单人测试。

贡还阶段自动为需要操作的人机选择合法牌，不替真人抢先选择。人机思考分刻进行，最多每刻三个候选；不受真人操作时限干扰。游戏结束按本桌正常清理参与者实体。重新加载保留已发牌与贡还状态。

HUD保持斗地主式上家/自己左侧、队友/下家右侧，每区显示公开出牌；私有手牌仍在下方。对话框保留相同点牌、多选、金边、清空选择和返回保留选择的方式，百搭多解释、贡还确认仍是掼蛋特有流程。
