# 国际象棋

白方先行，以将死对方的王获胜。四座、八座牌桌都支持 **1～2 名真人**：单人开始自动对战人机，两人开始为双人对局。正常游玩无需 OP。

## 开局与设置

安装数据包及配套资源包，更新后执行 `/reload`、`F3+T`。一人或两人入座，选择「国际象棋」即显示棋盘和棋子。腾空快捷栏最后一格（第 9 格，`hotbar.8`），设置后开始游戏。

| 设置       | 选项                                             |
| ---------- | ------------------------------------------------ |
| 棋盘配色   | 经典黑白、清新绿、胡桃木、海洋蓝、薰衣草紫       |
| 棋子配色   | 黑白、木色、冰蓝、翡翠玉                         |
| 方向       | 南北向：白方底线在南；东西向：白方底线在西       |
| 黑白方分配 | 随机分配（默认），或按座位自行选边；始终白方先行 |
| 每人计时   | 无限制、5、10、15、20、25、30 分钟               |
| 人机难度   | 简单、普通（默认）、困难；仅单人对局使用         |
| 可走格提示 | 开启（默认）／关闭                               |

全部选项在同一设置窗口中，点击后立即生效，当前选项以金色标出，无需保存。设置只影响本桌，大厅可调，开局锁定；修改配色或方向立即更新预览。白方视角下，字母从左到右为 `abcdefgh`，数字从近到远为 `12345678`，王在 `e` 列、后在 `d` 列。

自行选边时，坐白方一侧即执白、坐黑方一侧即执黑；双人须两侧各一人，坐在侧边时会提示重新入座。随机模式由系统分配黑白，开局自动调整玩家座位，保证白方面对第一横行、黑方面对第八横行；已坐在正确一侧的玩家优先保留原座。单人局的人机执另一方，若人机执白便先走。

| 棋盘方向 | 四座：白方／黑方     | 八座：白方／黑方           |
| -------- | -------------------- | -------------------------- |
| 南北向   | 南侧 3 号／北侧 1 号 | 南侧 5～6 号／北侧 1～2 号 |
| 东西向   | 西侧 4 号／东侧 2 号 | 西侧 7～8 号／东侧 3～4 号 |

计时在同页点选无限制或每人 5～30 分钟，默认 10 分钟，无加秒。原中央游戏名称位置显示双方时钟，当前方为绿色。只扣当前行棋方的时间；升变等待计时，8 刻走子／吃子动画暂停双方计时。计时按游戏刻运行，服务器卡顿时实际耗时会变长。

人机的思考时间也计入它自己的时钟。简单难度从合法走法中随机选择；普通难度考虑吃子、发展与落点安全；困难难度再比较部分候选走法的对手应对。三档均遵守同一套完整规则，人机升变自动选后。搜索分散到多刻处理，不需要额外模组或前置。

## 操作

- 右键己方棋子选中，选中格以金色高亮，actionbar 显示棋种；开启提示时，合法目标格另以绿色高亮。再次右键另一枚己方棋子，直接切换选择。
- 再右键目标格或对方棋子；合法则移动／吃子并播放动画，聊天栏显示阵营、棋种、起止坐标及吃子／升变信息；非法则取消选择，请重新选子。
- 王车易位：选王后点王最终到达的格子。吃过路兵：点击斜前方空格。
- 升变：选择后、车、象或马。关闭选择窗口后，手持操作物按 Q 可重开。

走子动画落位时播放 Chess.com 默认音效，移动、吃子、王车易位和将军各有区别；另有开局与结束提示，非法走法只提醒操作者。音效仅向本桌玩家播放，使用 Minecraft 的「方块」音量；更新资源包后按 `F3+T`。

| 快捷栏               | 操作物   | 按 Q 后                              |
| -------------------- | -------- | ------------------------------------ |
| 第 9 格 `hotbar.8` | 对局菜单 | 打开悔棋、和棋、认输；认输需再次确认 |

悔棋、协议和棋都须对手同意，不能接受自己的申请。等待回应期间继续计时；有新走子后旧申请失效。悔棋**撤回最后一步，即一个半回合**，恢复该步提交前的棋面、吃子区、行棋方、王车易位权、过路兵、重复局面历史及双方时钟；升变思考已经消耗的时间不退回。该快照只能使用一次；下一步合法走子后才产生新的可悔步骤。结算后不能悔棋。

单人人机局用于练习，人机自动同意悔棋与协议和棋。单人悔棋回到**玩家上次走子之前**，如人机已经应手则一起撤回，恢复到玩家回合；玩家尚未走过棋时没有可悔步骤。

走格提示通过完整规则检查，包含王车易位、吃过路兵与升变的目标格，排除被牵制或无法解除将军的走法；关闭提示仍保留选中棋子的金色框。换选、走子、非法尝试、升变等待和结束会清理旧目标提示。

被吃的棋子保留原色，缩小后摆在**吃子者面向棋盘的右手边**。两种桌型分别适配棋盘大小，在坐标边框与桌沿之间预留吃子区；开局按阵营安排到相对两侧，双方使用各自的右侧边槽。

## 规则与结束

采用常见走法：兵首步可走两格，马可跳子，象／车／后不能穿子；王不能走入被攻击的格子。走子不能令己方王仍被将军，不能直接吃王。

- **王车易位**：王和对应车未移动过，路径无子，王当前、经过和到达的格子均不受攻击。王／车离开后再回来也不恢复权利；初始格的车被吃会失去该侧权利。
- **吃过路兵**：仅限对方兵刚走两格后的下一步；会暴露己方王时不合法。
- **升变**：兵到最后一横行可升后、车、象、马，不受已被吃掉棋子的限制。
- **将死**：王受攻击且没有合法走法，该方负。
- **逼和**：轮到的一方没有任何合法走法，且王未被将军，自动和棋。
- **常见子力不足**：王对王、单马／单象对王、仅有同色格象等能确定无法将死的局面自动和棋；双马对王不直接判和。
- **重复局面**：三次重复可由当前行棋方认领；五次自动和棋。比较棋面、行棋方、易位权与实际可用的过路兵权。
- **五十／七十五回合**：连续 100 个半回合未动兵或吃子，可由当前行棋方认领和棋；150 个半回合自动和棋。最后一步将死优先于七十五回合判和。
- **超时／认输**：通常对方获胜；若根据现有子力可确定对手不可能将死，则和棋。协议和棋须双方同意。

参考 [FIDE 国际象棋规则](https://handbook.fide.com/chapter/E012023)。本包三次重复、五十回合只支持**当前局面**认领，不提供“声明下一步后认领”的流程；封闭兵链等少见死局暂不自动识别，可通过双方协议和棋处理。

结算五秒后返回大厅，中央恢复牌桌菜单，桌面继续保留终局棋面及吃子区，直到切换游戏或再次开局；重载、打开设置与调整配色不重置棋面。桌边结束投票、管理员中止或参与者离线会提前结束本场。重载进行中的棋局会保留局面、时钟、吃子记录及悔棋快照；旧窗口失效，按 Q 重开。

## 管理命令

以下需要命令权限，普通游玩无需输入。

```mcfunction
# 中止同维度 8 格内最近一场正在进行的国际象棋
/function chess:admin/abort
# 查询桌号
/scoreboard players get @s ct_id
# 精确中止，将 1 换成实际桌号
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=12},limit=1] at @s run function chess:game/abort
# 开启／关闭调试消息
/tag @s add ct.debug
/tag @s remove ct.debug
# 查看状态（0预览、1行棋、2动画、3升变、4结算）与最后一步
/scoreboard players get @e[type=minecraft:marker,tag=ch.controller,scores={ct_id=1},limit=1] ch_state
/data get entity @e[type=minecraft:marker,tag=ch.controller,scores={ct_id=1},limit=1] data.chess.last
```

## 制作与接口

编号 **12**，命名空间 `chess`，标签／目标前缀 `ch.`／`ch_`，通过 `ct_id` 隔离牌桌。64 个 `ch.square` marker 保存逻辑棋面，`a1=0`、`h8=63`；`ch_piece` 白正黑负，兵／马／象／车／后／王依次为 1／2／3／4／5／6。`ch.board` 是本次调用的棋格上下文，棋盘展示使用独立的 `ch.board_display`。

棋盘展示以右旋 Y 180° 抵消原版物品展示渲染的固定旋转，使贴图坐标与逻辑格、命中区及走子位置一致。统一 `visual/man_rotation` 中王额外水平旋转 90°、马额外旋转 180°，所有配色、黑白双方及移动／重建共用该变换。重载现有对局时会刷新展示，无需重开棋局。

控制器 `ch_turn` 为白 1／黑 -1；`ch_wtime`／`ch_btime` 单位为刻。`ch_first` 为 0 随机黑白、1 按入座侧选边，旧版指定座号 2～8 迁为随机。阵营确定后同步公共 `ct_seat`、玩家 `ch_seat` 和控制器 `ch_white`／`ch_black`，再统一上座，避免互换位置时占座。`data.chess.history`、`captured`、`undo` 保存历史、吃子展示及悔棋快照。`/reload` 只重建展示与输入，并按已分配的阵营恢复座位，不重新抽签或初始化进行中的棋局。

`ch_level=1/2/3` 为人机难度，`ch_hints=0/1` 为目标格提示；单局 `ch_bot=0` 为双人，`1/-1` 为人机执白／执黑，不生成假玩家。人机搜索进度保存在本桌，重载或悔棋后丢弃旧搜索并从现有局面重算；设置与棋局仍保留。版本 3 迁移为旧双人局补齐这些目标及缺省值。

主要接口：`game/init_table`、`start`、`end_vote`、`abort`、`remove`，以及 `player/clear_state`。切换游戏、删除牌桌额外执行 `game/remove` 清除大厅预览。`engine/try_move` 以控制器执行，输入 `#from`／`#to`（0～63）、`#promo`（0／2／3／4／5），输出 `#legal`：0 非法、1 已提交、2 等待升变。提交后回调 `game/after_move`，最后一步位于 `data.chess.last`；`engine/evaluate` 检查将死、逼和与自动和棋。

大厅复盘标记为 `data.chess.review:1b`。`game/cleanup` 只恢复大厅、清除计时和操作物，保留棋格与展示；`game/review` 只按当前局面重建外观。新开局消费该标记并重置棋面，切换游戏则由 `game/remove` 清除全部相关实体。

生成器为 `tools/build_chess_{engine,game,ui,visual}.py`，修改后运行对应脚本；游戏生成器同时调用 `build_chess_ai.py`，视觉生成器调用 `build_chess_hints.py`，UI 生成器调用 `build_chess_settings.py`。公共接入由 `tools/register_chess.py` 维护，设置与规则分发置于缺少界面的兜底提示之前。资源生成需要 Pillow。棋子几何来自 **16bit 制作组 NyaaWorks 喵工坊 r2.2**，已内置所用模型，无需玩家另装上游包；原始副本、SHA-256 与材质说明见资源包 `.source/chess/README.md`。棋盘与配色为脚本绘制，未复制 Chess.com 纹理。

人机每刻最多探测 16 个候选；困难档对启发式最好的四个候选继续检查对手合法应手，比较回吃、升变与将死／逼和。搜索只改分数缓存，提交前重新验证走法；各桌的候选队列和进度保存在 `data.chess.ai`，以 epoch 废弃旧结果。提示也只读规则缓存，`ch.hint` 展示实体按桌号清理，模型为 `card:chess/hint`。

游戏生成器同时调用 `tools/build_chess_sound.py`，统一维护 `sound/` 路由及七类音效入口；落位按将军、易位、吃子、移动的优先级播放一个提示，终局只播放结束音。吃过路兵按实际被吃棋子判定，升变等确认后才播放。每次播放重新绑定控制器上下文并核对玩家桌号；重载、预览、悔棋、中止与清理不重播。资源包 `.source/chess/export_sounds.py` 将 Chess.com 默认原音效转为单声道 Vorbis，事件为 `card:chess.*`；原文件、来源地址和 SHA-256 见 `.source/chess/sounds/source_manifest.json`，不新增前置。
