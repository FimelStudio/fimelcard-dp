# 飞行棋

Minecraft Java 26.2，游戏编号 **15**，命名空间 `aeroplane_chess`。支持 **1～4 名真人、2～4 方参赛**，每方四架飞机；四人桌、八人桌均可使用，普通玩家无需 OP。默认单人开始会加入一个电脑对手，也可补满四方，或在设置中**关闭电脑补位**；关闭时至少需要两名真人。

## 开始与操作

1. 入座后选择「飞行棋」，棋盘、飞机和骰子立即出现。腾空快捷栏**第 1 格与最后一格**，开始前调整规则和电脑补位。
2. 轮到自己时，第 1 格出现「飞行棋 · 投骰」；**右键桌面骰子**，或手持操作物按 **Q**。骰子翻滚、弹跳后停稳，上方面为本次点数；动画期间不能重复投骰。回合结束收起操作物，最后一格菜单始终保留。手持骰子缩小显示，桌面骰子及投骰动画大小不变。
3. 右键本次可行动的飞机；也可手持最后一格「飞行棋 · 对局菜单」按 Q，按飞机编号选择。多架飞机叠放时可用菜单准确选机。没有合法行动则自动跳过。
4. 飞机逐格移动，起飞、跳格、飞跃、撞机返航和到达终点均有对应动画与音效。移动期间锁定行动；聊天记录投骰和公开行棋。

Q 菜单也提供认输，须本人确认；本游戏不提供悔棋或重投。正常结束 5 秒后回到大厅并保留终局，新开局或切换游戏后重摆。`/reload` 保留本次已经确定的骰值、行棋进度与回合；玩家离线、结束投票通过或管理员中止会返回大厅。

## 本包规则

采用常见四色飞行棋的休闲玩法，地方规则差异可通过下方设置调整。棋盘仅保留一张经典四色款，采用折角跑道、四角机场和中央箭头终点；飞机、落点与点击区域同步适配四／八人桌及两种方向。

- **回合：**红、蓝、绿、黄依次行动，跳过未参赛、已完成或认输的一方；首位可随机或指定。
- **起飞：**默认掷到 6 可将一架飞机从机场移到起飞格，该点数不再同时前进六格；也可选择移动已起飞的飞机。掷到 6 后追加一次投骰。
- **跳格与飞跃：**落在本色格向前跳四格，落在本方航线入口飞跃十二格。两种效果可连锁，每种每次行动最多触发一次；同一落点同时满足两种效果时，先飞跃再检查跳格。
- **撞机：**普通移动的最终落点、跳格落点、飞跃落点均会将该格所有敌机送回机场；途经格不撞机。同色飞机可以同格停放，每次仅移动选中的一架。
- **终点：**进入本色终点通道后，默认准确到达终点；点数超出时反弹。四架飞机全部到达的一方获胜，默认首名产生即结束；也可继续排完名次。
- **连续三个 6：**默认无处罚。开启处罚时，第三个 6 不行动并结束本回合，前两次已经完成的行棋保留。

## 设置

设置在一个对话框中，点击立即生效；开局后锁定，仅影响本桌。棋盘固定使用经典四色配色。

| 项目 | 选项与默认值 |
| --- | --- |
| 起飞点数 | 6、5～6、任意点数；默认 6 |
| 六点追加投骰 | 开／关；默认开启 |
| 连续三个六 | 无处罚、第三次失效并结束回合；默认无处罚 |
| 同色跳格／航线飞跃 | 可分别开关，默认开启 |
| 终点超出 | 反弹、该次无法移动；默认反弹 |
| 棋盘方向 | 红方南侧、红方西侧；默认南侧 |
| 首位行动 | 随机、红、蓝、绿、黄；默认随机，指定颜色未参赛时顺延 |
| 动画速度 | 标准、快速；默认标准 |
| 可移动飞机提示 | 开／关；默认开启 |
| 电脑补位 | 关闭、单人补一位、补满四方；默认单人补一位，关闭时至少两名真人 |
| 结束方式 | 首名产生即结束、继续排名；默认首名结束 |
| 玩家颜色 | 按座位选色、随机分配；默认按座位 |

按座位选色会优先使用所坐一侧对应的颜色；同侧已有玩家时，顺延到空闲颜色。开局自动换到自己颜色的一侧。默认方向下，红在南、蓝在西、绿在北、黄在东；改变棋盘方向时，颜色与座位一起旋转。八座桌仍最多四名真人，每人控制一种颜色。

## 管理与资源

需要命令权限的玩家在桌旁执行，结束同维度 8 格内最近一场飞行棋：

```mcfunction
/function aeroplane_chess:admin/abort
```

精确中止某桌时，将 `1` 换成桌号；须在该桌所在维度、区块已加载时执行：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=15,ct_state=1},limit=1] at @s run function aeroplane_chess:game/abort

/scoreboard players get @s ct_id
/tag @s add ct.debug
/tag @s remove ct.debug
```

棋盘、飞机与六面骰由本项目绘制、建模，设计参考与可编辑 Blockbench 模型见资源包 `.source/aeroplane_chess/`；原创音效及无损源文件见 `.source/boardgames/`。获胜一方所在桌边播放内置 SK Firework 烟花，电脑获胜同样会播放，无需新装前置。
