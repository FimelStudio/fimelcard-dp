# 斗地主叫地主模式

在游戏设置中选择，默认叫分制；仅大厅可保存，按牌桌保留，整场各局使用同一模式。

- 叫分制：原规则不变，依次不叫或叫更高的1～3分，3分立即确定地主。
- 叫抢制：每局随机一人开始。第一轮每人选一次，首次叫地主不翻倍，其后每抢一次翻倍。第一轮不叫或不要的人没有第二轮资格。第二轮从最早叫地主的人开始，按座位顺序跳过无资格者，有资格者依次选择。任何人选择抢地主便立即成为地主并翻倍，后面的人不再选择；最早叫地主的人也遵循此规则。若前面的人均不要，最后一人自动成为地主，不再询问且不额外翻倍。只有一人有资格时直接确定该人为地主。全员第一轮不叫则重发，不消耗比赛局数。
- 手速制：全部三人都获得操作道具，可同时按Q打开手牌并叫地主。服务器最先处理的有效提交获选；同一刻多个提交以服务器处理顺序为准。人机等3秒后随机选一名本桌人机叫地主，真人也可不等人机立即叫。

叫抢制、手速制基础分为1；抢地主倍数与炸弹、王炸、春天/反春天累计相乘。叫抢时显示当前倍数。已有人被确定为地主后，迟到的抢叫提交无效。

重载保留叫抢轮次、资格、候选与倍数。每次新局或重发清空上一局的叫抢状态。输入方式、音乐开关、累计得分与三人补位人机保持兼容。

检查：tools/check_doudizhu_bidding.mjs覆盖81条叫抢路径、三人抢先提交、旧叫分与权限；tools/check_doudizhu_match.mjs验证结算与1536组设置提交。仍需Minecraft联机实测。

手速制成功叫地主后，立即关闭本桌所有真人当前的叫地主对话框；不影响其他牌桌。地主进入出牌阶段后可按Q重新打开出牌面板。

手速制从发牌完成开始计时：0–40刻（含2秒）为4倍，41–100刻（含5秒）为2倍，101–300刻（含15秒）为1倍。进入第301刻仍无人叫则关闭本桌对话框并重发，不计分、不增加完成局数。倍数以服务器处理提交时的计时为准，之后仍与炸弹、春天等倍数相乘。重载保留计时。
