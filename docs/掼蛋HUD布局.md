# 掼蛋HUD布局

左上第一行：上家；右上第一行：队友。左侧第二行：自己；右侧第二行：下家。各区包含姓名、受设置控制的余牌数、行动标记和本轮最近出牌图片。依据四方gd_order及逆时针行动顺序计算，与实际椅子编号和空座无关。只读取公开last_play，不读取其他人的手牌。

修复牌面透明边缘使字形advance变短而固定回退过多的问题：手牌每张补齐43像素，叠牌切片补齐42像素；列间留3像素，取消多列时负间距压缩。正常、选中、级牌、选中级牌全部共用固定列宽。新生成器build_guandan_layout.py已接入UI/HUD生成入口。

已检查1296个切片的占位宽度、4个观察方向及函数引用；游戏内不同GUI缩放仍需实测。本次未同步Git。

## 出牌后整块HUD消失修复
游戏日志出现 `Failed to parse component` / `List must have contents`。牌型说明的最终文本组件含 `extra:[]`，一旦有人出牌就被加入总面板，造成整块面板解析失败。删除该可选空字段；构建过程中仍可用空列表暂存，但提交显示的叶子文本不能带空 extra。

座位文字改为固定朝向、平放桌沿，保留姓名、队伍、剩余张数和回合箭头；重复的桌面牌型文字移至HUD。中心信息高度从1.92降至1.45，缩小显示比例。四人桌、八人桌均生成独立定位参数。/reload会重建现有文字并刷新HUD，不重开游戏。

已检查最终牌型组件、座位宏参数及生成器语法；需要游戏内确认最终位置。
