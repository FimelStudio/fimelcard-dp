# 私人情报与操作界面

私人情报每10刻仅向本人刷新 actionbar。梅林看到全部坏人（含奥伯伦）；派西维尔看到无法区分的梅林与莫甘娜；莫甘娜、刺客、爪牙看到其他互认坏人，不显示自己或奥伯伦；忠臣和奥伯伦显示其信息限制。名单按本桌隔离，派西维尔的两名候选人不按角色分别列出。结算或中止时清空 actionbar。

带队选人、确认出征、刺客提前翻牌确认、选择和确认刺杀目标恢复为对话框。组队时仅队长自动打开；刺杀时仅刺客自动打开。其他玩家等待或投票时不自动弹窗，可随时Q丢身份牌主动打开本轮操作。

红绿染料表决继续保留，关闭对话框后Q丢出提交。私人身份名单不再加入聊天或对话框正文。身份牌正反面保护和固定中心文字保持不变。
