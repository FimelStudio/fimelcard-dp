# 斗地主显示与自动过牌

游戏设置新增“显示剩余牌数”，默认显示，按牌桌保存。隐藏时，上家、自己、下家的HUD均不显示剩余数字，并关闭首次剩1至2张的聊天提醒。牌面、地主底牌、音乐开关及音乐切换条件不变；此选项隐藏数字，不是隐藏所有可推测的手牌信息。人机仍使用已有公开信息策略。

真人轮到跟牌时自动检查是否存在合法应牌，不依赖打开窗口。没有应牌则提示并启动100游戏刻（正常20TPS时5秒）的计时；到期再校验当前回合和合法性，关闭当前玩家窗口并提交不出。玩家可提前手动过牌。领出者或存在合法应牌者不会自动过牌；判断排除人机主动保炸、让队友策略。人机维持原有行动节奏。

回合切换重置计时；重载保留已有计时。旧对局第一次检查时初始化。每回合只在开始和到期各进行一次完整合法性探测。

验证：check_doudizhu_autopass.mjs覆盖计时边界、不能提前过牌、回合切换、到期复验、跨桌身份和隐藏入口；check_doudizhu_match.mjs覆盖设置及累计计分；check_doudizhu_bot.mjs验证实际合法性探测。
