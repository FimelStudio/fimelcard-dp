# 五子棋

Minecraft Java 26.2，游戏编号 **14**，命名空间 `gomoku`。支持 **1～2 人**，四人桌、八人桌均可使用；普通玩家游玩无需 OP。一人开始自动对战电脑，两人开始则双人对弈。

## 开始与操作

1. 入座后选择「五子棋」，棋盘立即出现。腾空快捷栏最后一格，开始前在「游戏设置」选择大小、黑白方分配与计时。
2. **黑方始终先行**。右键空交点落子；开启「同点两次确认」后，第一次右键预选，再点同一点落子，改点则转移预选。
3. 手持最后一格「五子棋 · 对局菜单」按 **Q**，可按行、列精确选点，也可申请悔棋、和棋或认输。19 路交点较密时可用坐标落子。
4. 双人悔棋、和棋须对方同意；人机练习自动同意。人机悔棋退回自己上一次落子前，连同电脑应手撤回，并恢复当时的时钟；自己尚未落子时不能悔棋。认输须本人确认。

落子有下降动画，聊天记录落子坐标；最新一手显示小十字，获胜连线显示绿色框。正常结束 5 秒后返回大厅并保留终局；新开局、切换游戏或改变棋盘大小时清空。`/reload` 保留棋局、阵营和时钟，旧菜单按 Q 重开。玩家离线、结束投票通过或管理员中止会立即返回大厅。

## 规则

采用**自由五子棋，无禁手**。双方轮流在空交点放一枚棋子；横、竖或任一斜线连续 **五枚及以上**同色棋子即获胜，长连算胜，三三、四四也允许。

棋盘填满仍无人获胜，或双方同意和棋，则和棋；对手认输或用尽时间则获胜。落子动画期间暂停计时并锁定输入。

## 设置

全部设置在同一个对话框，点击选项立即生效；开局后锁定，仅影响本桌。

| 项目 | 选项与默认值 |
| --- | --- |
| 棋盘大小 | 13×13、15×15、19×19；默认 15×15 |
| 棋盘配色 | 经典、木色；棋子固定黑白 |
| 棋盘方向 | 南北向（黑方南侧）、东西向（黑方西侧） |
| 黑白方分配 | 随机分配、按座位自行选边；默认随机，开局自动换座 |
| 每人计时 | 无限制、5／10／15／20／25／30 分钟；默认 10 分钟，无加秒 |
| 单人人机难度 | 简单、普通、困难；默认普通 |
| 最后一手标记／坐标显示 | 可分别开关，默认开启 |
| 右键落子确认 | 一次落子、同点两次确认；默认一次落子 |

按座位选边时，两人须分别坐在黑、白方所在侧；单人可选任一方。侧面座位不能开始自行选边模式，可换座或改用随机分配。

| 桌型与方向 | 黑方座位 | 白方座位 |
| --- | --- | --- |
| 四人桌，南北向 | 3 | 1 |
| 四人桌，东西向 | 4 | 2 |
| 八人桌，南北向 | 5／6 | 1／2 |
| 八人桌，东西向 | 7／8 | 3／4 |

三档人机均会优先成五、阻挡对方下一手成五；普通档增加棋形评估，困难档增加候选应手搜索，定位为休闲练习对手。计时按游戏刻计算，服务器卡顿时实际耗时会变长。

## 管理与资源

需要命令权限的玩家在桌旁执行，结束同维度 8 格内最近一场五子棋：

```mcfunction
/function gomoku:admin/abort
```

精确中止某桌时，将 `1` 换成桌号；须在该桌所在维度、区块已加载时执行：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=14,ct_state=1},limit=1] at @s run function gomoku:game/abort

/scoreboard players get @s ct_id
/tag @s add ct.debug
/tag @s remove ct.debug
```

每桌交互实体由最多 361 个减少到 **1 个**，只在点击时定位交点，不逐刻投射视线；空交点不生成展示模型，逻辑 marker 仅在服务端存在，不向客户端同步。每枚圆盘棋子由 **192 面减至 80 面**，棋盘与棋子展示距离设为约 **32 格**（`view_range:0.5`），减少远处展示开销；实际帧率仍需客户端测试。

棋盘与棋子为本项目原创，可编辑模型见资源包 `.source/gomoku/`；原创短音效见 `.source/boardgames/`，胜利烟花使用已内置的 SK Firework，无需新装前置。

客户端待测：19 路点击精度、Q 菜单、两桌型／方向、落子与收回动画、音量及真人联机，见[统一验收清单](验收清单.md)。
