# 八人牌桌验收

## 使用

1. 在当前世界执行 `/reload`。
2. 在空地执行 `/function cardtable:admin/create8`：桌面4×4，方块展示实体座椅每边两张，总占地6×6；每把中心偏离该边中线1格，两把中心相距2格、净空1格。
3. 桌心对齐执行位置所在方块的西北角交界点，Y为桌面方块层。与其他桌至少间隔9格。
4. 右键白桦木座椅入座。菜单提供Fast Card（固定4人）、赌命德州扑克（2至8人）、花火（2至5人）、出包魔法师（2至5人）、瞎掰王（3至8人）、谍报风云（3至8人）、问非所答（2至8人）、临界点（3至6人）和骷髅牌（2至6人）。
5. 原四座桌及创建入口保留。现有同布局桌面可在中央交界点站立执行 `/function cardtable:admin/create8_safe`，不改方块。

- `node tools/check_wenfei.mjs`：2至8人稀疏座位轮换、600种计分排列、秘密问题边界、答案面板及类别选择。
- `node tools/check_wenfei_form.mjs`：保留书和对话框输入。

自动检查不等于Minecraft服务器命令加载或联机实测。

## 待游戏内验收

- 同时放一张旧四座桌和新八座桌，检查各自菜单、人数显示及桌边按钮均可点击。
- 对旧八人桌执行`/reload`：原八块默认白桦楼梯消失，出现八把实体椅子；座位及已入座玩家同步移位，再次重载不重复生成。规则文字和点击区在桌面最外侧一格的外立面、靠近桌角，实际可见、可点，且不触发入座。
- 八名玩家依次坐满，每人面向桌心；占座不可抢，游戏中离座后只能回到本人原座。
- 用1、8号座进行问非所答两人局；用1、5、8号及满八人测试空座跳过。
- 八人问非所答：七人交书后再公开，所有名字与答案可通过分页看到；0至4分染料按Q工作；每人默认猜两次，共16轮，结算正常。
- 八人瞎掰王：仅老实人知道初始身份；阅读后关闭答案；选人窗口有本桌另外七人的真实名字，5至8号可质疑与指认；每人一次大聪明，共8轮。
- 两桌同时玩瞎掰王，核对质疑标记、加减分、道具回收和结算消息只影响本桌。
- 2人2票、3至4人3票、5人3票、6至7人4票、8人5票；重复投票不加票。
- 两个游戏在各阶段执行reload，桌型、座位、轮数、当前输入均保持；恢复后的交互可用。
- 游戏中有人离线，应结束该桌游戏并回大厅；其他桌不受影响。
- 移除八人桌时清理全部八座、菜单、规则及投票实体，清理八把实体椅子，保留桌面方块。

## 新接入游戏的联机验收

- 四人桌和八人桌右键“切换游戏”均打开九个游戏按钮，直接选择后更新中央名称；关闭不改变游戏，重复选择当前游戏不重置设置。使用无OP玩家验证；离座、开局、其他玩家切换游戏或reload后，旧窗口不能继续修改桌子。
- 花火、出包魔法师测试2人和5人开局，再测试6人拒绝开局；分别使用1、8号座和1、3、5、7、8号座检查空座跳过。
- 德州扑克八人：每人两张手牌，无重复牌；每人都换一次牌后仍有7张牌未被使用；全押、跟随、弃牌和下一轮庄家轮换包含所有高号座。
- 德州扑克逐人摊牌统一在桌心单列显示；牌图与文字缩放保持四人桌的0.22，行距0.55格，第五至八人向上接续，最终排名固定在桌心Y+1.05、第一行手牌下方，不随人数抬高。四个方向观察均居中，高处实体能正常绑定桌号和清理，回合结束后上空无残留；reload清除已结束牌局的旧高行，进行中的排名下移但手牌和进度不变。摊牌中reload，旧实体立即修正且不重播、不改变名次或计时；并列排名、后四名排名和逐人左轮均正确。分别淘汰/断线第5至8号座，其他人继续，剩一人结束。
- 花火五人各四张牌，四名其他玩家手牌可见而自己的未知牌隐藏；普通颜色/数字提示与完全提示奖励均能选择第5至8号实际参与者。关闭后重新打开仍选中正确目标。
- 出包五人各五枚石、四枚秘密石、剩七枚牌库；左右邻座、跨8到1号的轮换、两人同一邻座只受一次闪电暴风雨伤害均正确。中央五人生命、跨局累计分和最终生命显示完整。
- 出包开局先清空快捷栏全部9格：真实五枚咒语石只保存在后台，不发物品牌背。轮到玩家时发1至8号操作牌，选牌按Q施法后返还，第9格黑色染料按Q结束回合，聊天不再提供结束按钮；验证成功、失败、逆序、打空手牌、结算、离线、reload和两桌同时丢牌，不能重复施法或把操作归到邻座。回合结束后原玩家操作牌全部回收，非游戏物品不被覆盖。
- 三款游戏分别在发牌、行动和结算时reload；当前手牌、轮次和存活状态保持，菜单无需重建桌子即可选择新增游戏。
- 四座桌与八座桌同时运行时，发牌、抽牌、施法、计分和清理不得跨桌。

## Fast Card、骷髅牌与谍报风云扩展

- Fast Card四人分别坐1、3、6、8号：17张正确送达，按实际座位顺时针传牌，排名显示真实座号；3人或5人不能开始。
- 骷髅牌最多6人：高号座发牌、扣牌、叫号至24、翻牌、弃牌和淘汰轮换正确；7人不能开始。
- 谍报风云5、6、7、8人分别为3＋2、3＋3、4＋3、4＋4；队内每人循环获得各个职责，三人队没有轮空，四人队每轮恰一人轮空。
- 首轮不拦截；两队完成各自密码后才轮换角色。轮空者及其他职责不能通过旧按钮或紫色染料越权提交。
- 在每种职责、每种输入阶段重载：角色、队伍、书稿、已输入数字、词条及电报记录不变。两桌同时进行时，姓名、广播和操作入口只属于本桌。
- 自动检查：`node tools/check_more_games8.mjs`、`node tools/check_skull.mjs`、`node tools/check_decrypto_prompt.mjs`。

## 临界点六人验收

- 八座桌可切换到临界点，任意3至6座可开局；2人、7人和8人拒绝。
- 5人安全线17点、6人20点；每局仅一名狼人，每人仍持1至5点牌，最多五轮。
- 用1、3、4、6、7、8号座开六人局：所有人投票按钮只显示其余五人的真实名字；可投7或8号座，无空位及自己。
- 狼人在高号座时仍能正确处决；投村民或最高票平票仍为狼人获胜。结果按本桌实际玩家姓名公布票数。
- 安全轮和危机轮的公开信息、黑白染料清除、紫色染料重开、重载进度与双桌隔离保持正常；任一玩家离线中止本桌。
- 自动检查：`node tools/check_critical_point_input.mjs`、`node tools/check_critical_point_six.mjs`。
