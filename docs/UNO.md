# UNO

2～8 人轮流出牌，匹配弃牌堆顶的颜色、数字或功能符号，争取先出完手牌。普通玩家无需 OP；四座桌最多 4 人，5～8 人使用八座桌，座位可以不连续。

游戏编号 `11`，命名空间 `uno`。安装与建桌见[项目 README](../README.md)。

## 开局与操作

所有玩家腾空快捷栏**第 1 格（`hotbar.0`）**。在大厅选择 UNO，按需调整“游戏设置”，再开始游戏。仅在本人正常出牌回合，第 1 格出现“UNO 手牌”操作物，选中后按 **Q** 打开选牌面板；回合结束后收起。自己的手牌始终显示在 **BetterTitle HUD**，所需库已内置，查看规则不会暂停牌局。

- 点击牌面选中，以金黄色亮框显示；再次点击同一牌型取消，点击另一牌型则把亮框转移过去，HUD 同步选中状态。再点“出牌”或“出牌并喊 UNO”才实际出牌，成功后立即关闭面板。重复牌按牌型聚合并标注数量，一次只打出一张。
- 点击“摸一张”主动摸牌；摸后可以打出刚摸到的那张合法牌，或选择不出。不能改出原手牌。
- 变色牌先选择红、黄、绿、蓝之一，再提交出牌；选色前尚未扣除手牌。
- 被 `+4` 命中时自动打开“接受／质疑”响应框；漏喊窗口自动打开“补喊 UNO／抓 UNO”响应框。这些阶段无需手牌操作物，关闭后可点击聊天中的入口重开。

后台保存真实手牌，操作物不是真牌。HUD 和选牌面板都只向本人显示完整手牌。HUD 按牌型排序，数量独立显示在牌面下方，随发牌、摸牌、出牌和选牌更新；常规牌面与斗地主接近，避开物品名称，牌型较多时自动压紧或向上分行。面板显示当前颜色、顶牌、方向和阶段。旧回合或旧桌子的窗口无法继续提交。

每位玩家最近打出的牌，会以**正面朝上的物品展示实体**放在桌面靠自己座椅的位置；四座桌每边一张，八座桌每边两张。该玩家再出牌时替换自己的上一张，最新出牌用轮廓标出。其他座位的旧牌仅供回顾，不能作为跟牌依据。起始数字牌先在牌盒旁展示，第一次出牌后移除。

桌面上方按座号显示玩家名字、剩余张数、累计积分和当前行动箭头。每次出牌都会向本桌玩家发送聊天消息，列出出牌者与牌面；变色牌另标明选定颜色。

**牌盒从开局起一直放在桌子中央**，发牌完成、轮换或进入下一小局时不移除。起手发牌、主动摸牌、`+2`／`+4`、质疑罚牌和漏喊 UNO 的罚牌，都从牌盒飞向实际接收者：每两游戏刻一张，只显示牌背，不会泄露牌面或产生可拾取的额外手牌。后台先完成牌权和张数更新，动画仅作表现；服务器卡顿会使动画变慢。

## 牌组与基本规则

采用经典 108 张牌，不含换手或自定义扩展牌：

| 牌 | 数量 |
| --- | ---: |
| 红、黄、绿、蓝数字牌 | 每色 `0` 一张，`1～9` 各两张，共 76 张 |
| 跳过、反转、`+2` | 每种每色两张，共 24 张 |
| 变色、变色 `+4` | 各 4 张，共 8 张 |

每人起手 7 张，随机先手，默认顺时针。起始牌只取数字牌。轮到自己时，每次只能打出一张与当前颜色、数字或功能符号至少一项相同的牌；普通变色牌随时可出并选色。

没有可出牌时摸一张；即使有可出牌，也允许主动摸一张。刚摸到的牌合法时可立即打出，也可保留并结束回合，不能持续摸到能出为止。

| 功能牌 | 效果 |
| --- | --- |
| 跳过 | 下一家失去回合 |
| 反转 | 顺、逆时针交换 |
| `+2` | 下一家摸两张并失去回合 |
| 变色 | 出牌者指定接下来使用的颜色，可保持原色 |
| 变色 `+4` | 指定颜色，下一家接受摸四张并失去回合，或质疑 |

二人局中，反转等同跳过；打出跳过或反转后自己继续。对手接受 `+2`、`+4` 罚牌后也回到自己行动。禁止罚牌叠加、抢出、7-0 换手、一次打多张等房规。

摸牌堆耗尽时，保留弃牌堆顶牌，其余弃牌重新洗成摸牌堆。若所有可摸牌都在玩家手中，实际有几张便摸几张，不凭空生成牌。

## 变色 +4 与质疑

只有手中没有当前颜色的牌时，才能合法打出 `+4`。同数字或同功能、但颜色不同的牌不影响合法性；普通变色牌不算当前颜色牌。

默认开启质疑，出牌者可以尝试诈唬。只有受到本次 `+4` 的玩家可以质疑；系统按打出该牌前的手牌快照判定，只公布结果，不公开整手牌：

- **接受**：被罚者摸四张，失去回合。
- **质疑成功**：出牌者当时有当前颜色牌，改由出牌者摸四张，质疑者正常行动。
- **质疑失败**：出牌合法，质疑者摸六张并失去回合。

关闭质疑后，系统直接拒绝手持当前颜色牌时打出 `+4`。

## 喊 UNO 与胜负

打出倒数第二张、手中剩一张时须喊 UNO。“出牌并喊 UNO”会同时完成声明；开启自动喊 UNO 时也会自动声明。

手动模式下，未声明便出到只剩一张，会暂停普通回合，进入默认 **3 秒**的抓 UNO 窗口。本人先补喊则安全；其他玩家先抓到，漏喊者摸两张；无人抓到则不罚。服务器先收到的有效操作优先；关闭界面不暂停倒计时，实际时长随服务器 TPS 变化。

先出完手牌赢得本轮。末张允许为功能牌；最后一张是 `+2` 或 `+4` 时，先处理罚牌、接受或质疑，再结算。如果末张 `+4` 被质疑成功，原出牌者摸四张，本轮继续。

每轮胜者获得其他玩家剩余手牌的总分：数字按面值，跳过／反转／`+2` 每张 20 分，变色／`+4` 每张 50 分。默认单局获胜后返回大厅；固定局数累计总分，目标分赛则由先达到目标分者获胜。

确认本轮胜者后，在胜者真实座椅上方发射 **SK Firework 四色烟花**。末张 `+4` 尚待接受或质疑时不提前庆祝；重复提交也不会重复计分或放烟花。库已内置，无需另装；末张导致的罚摸动画播放完成后，才开始局间结算倒计时。

## 游戏设置

在大厅“游戏设置”的同一窗口修改全部选项，每次点击立即生效，无需保存。数值使用加减按钮调整，设置只属于当前牌桌，开局后锁定。切桌、切游戏或重载后的旧窗口不能覆盖本桌设置。

| 设置 | 范围与默认值 |
| --- | --- |
| 胜负方式 | 单局（默认）、固定局数、目标分 |
| 固定局数 | 1～32 局，默认 3；仅固定局数模式生效 |
| 目标分 | 100～1000 分，每档 100，默认 500；仅目标分模式生效 |
| 自动喊 UNO | 默认关闭；开启后出到一张自动声明 |
| `+4` 质疑 | 默认开启；关闭时禁止非法 `+4` |
| 抓 UNO 窗口 | 1～5 秒，默认 3；仅手动喊 UNO 生效 |

起手固定七张、禁止叠加、数字起手及两人特例属于本版固定规则，不在局中变更。设置中也可打开通用牌桌皮肤选择。

## 恢复与管理命令

玩家离线会中止本场、清理牌局并返回大厅；游戏中下马保留参与身份。`/reload` 保留真实手牌、回合、分数、倒计时及尚未播放完的摸牌动画队列，原位恢复桌心牌盒和本人 HUD，刷新操作物并使旧窗口失效。结束或中止时清空 UNO 自己的 HUD 面板，恢复原先的 BetterTitle 面板。普通玩家可通过桌边“结束游戏”投票中止。

管理员站在同维度目标桌 8 格内执行，无需填写桌号：

```mcfunction
# 中止最近一场 UNO，保留牌桌
/function uno:admin/abort

# 查看最近一场 UNO 的阶段：1发牌、2回合、3抓UNO、4质疑、5局间结算
/scoreboard players get @e[type=minecraft:marker,tag=un.controller,distance=..8,sort=nearest,limit=1] un_state

# 查看行动座号、所在轮次
/scoreboard players get @e[type=minecraft:marker,tag=un.controller,distance=..8,sort=nearest,limit=1] un_turn
/scoreboard players get @e[type=minecraft:marker,tag=un.controller,distance=..8,sort=nearest,limit=1] un_round

# 查看尚未播放的发牌／摸牌动画
/data get entity @e[type=minecraft:marker,tag=un.controller,distance=..8,sort=nearest,limit=1] data.uno.deal_queue

# 开启／关闭自己的调试日志
/tag @s add ct.debug
/tag @s remove ct.debug
```

局内 `/trigger un_action` 使用带窗口版本的提交值。请通过面板按钮操作，不要把某次窗口的数值写成固定命令；过期或越权提交会被拒绝。

## 制作与维护

- **真实牌组**：108 个带 `un.card` 标签的 marker，使用 `ct_id` 隔离牌桌；`un_card` 为 0～53 牌型，`un_owner` 为 0 牌库、-1 弃牌、1～8 真实座号。显示、物品和按钮不拥有牌权。
- **状态与入口**：`data/uno/function` 的 `game/` 管生命周期，`round/` 管发牌、轮换、功能牌及结算，`action/` 复核玩家与合法性，`input/`、`ui/`、`settings/`、`rules/` 管普通玩家界面。临时状态、设置与清理均绑定桌号。
- **多人桌**：按实际座号和方向寻找下一个有人座位，跳过空座。游戏不创建或删除通用座位，使用公共发牌动画和通用结束投票。
- **发牌与摸牌动画**：所有成功的 `deck/take` 都向本桌控制器 `data.uno.deal_queue` 追加 `{seat,idx}`；`animation/tick` 以 `un_anim_wait` 持久冷却每两刻播放一张。继续复用 `cardtable:animation/deal/spawn_card`、`sound`、`launch` 和公共飞行维护，飞牌标记 `ct.visual_only` 并绑定真实牌号，防止拾取和合并；抽牌失败不排队。重载不会重发真实手牌，中止清掉本桌队列和飞牌。
- **常驻盒与烟花**：`visual/ensure_box` 按桌号补回或迁移唯一 `un.box`，使用 `none` 上下文并补偿几何中心，置于桌心上方 1.095 格；`visual/clear_cards` 仅清牌面和文字，整场结束才清盒。`firework/winner` 按本桌 `ct_id` 和胜者座号定位真实 `ct.seat`，通过 `fimel_sklibs:skfirework/fx/firework` 发射烟花；火箭带 `un.firework`、桌号和胜者座号，不修改上游库。
- **桌面几何**：复用 `card:item/fake_card`；展示上下文为 `none`。保留座位偏航和 X 轴 +90°，另以 `right_rotation` 绕模型 Y 轴 180° 抵消客户端自带的 Y 轴 180°，让 north 正面朝上；高度补偿为 0.040625，保留牌心及数字朝向。四座牌心距桌心 0.94 格，八座为边距 1.42 格、横偏 0.85 格，底面略高于桌面防止闪烁；只调整 `un.face`，不改牌盒、手持或飞牌。`visual/repair_faces` 在重载时按桌号迁移旧牌；tick 仅补迁移后来加载且无 `un.face_up_v2` 的旧实体，无需重开牌局。
- **HUD 与公开名单**：`hud/` 使用内置 `fimel_title`，`un_panel` 保存可重用的私有面板，`un_prev_panel` 记录进入前的面板；退出时仅清本游戏槽并恢复原绑定。`system/advance` 刷新 HUD 与公开名单，UI 选牌单独更新本人 HUD；`deck/take` 置 `un_hud_dirty`，刻末由 `system/flush` 集中刷新，避免一次罚摸重复构建多遍。`visual/update_status` 在桌心上方 1.90 格原位更新本桌唯一的 `un.status`，无需每次重建实体。
- **玩家名字**：`name/resolve` 与 `loot_table/player_name.json` 沿用花火的 `minecraft:set_name` 解析方式，生成静态名字组件并移除交互事件，供公开名单使用。名字整体嵌入文本，不把玩家名拼进命令字符串。
- **资源命名**：颜色前缀为 `r` 红、`y` 黄、`g` 绿、`b` 蓝；后接 `0～9` 数字、`skip` 跳过、`reverse` 反转或 `plus2` 加二，例如红 7 为 `card:uno/r7`、蓝跳过为 `card:uno/bskip`。变色为 `card:uno/wild`，变色加四为 `card:uno/wild_plus4`；牌背为 `back`，牌盒为 `box`。纹理、模型、物品定义及字体图片使用同名文件。
- **纹理与字体**：正面、牌背、牌盒纹理均为 48×48；`card:uno/dialog` 和 `dialog_selected` 使用 U+E600～U+E635，高度 54、ascent 50，选中版本仅添加外沿亮框。HUD 普通／选中牌分别使用 U+E600／U+E700 起的字形，8 种以内使用 `hud`（高度 56），9～18 种使用 `hud_dense`（56），19～36 种使用 `hud_medium`（40、两行），37～54 种使用 `hud_small`（32、三行）；各有对应的 `_neg` 负宽字体。卡片和牌盒复用原有几何，第三人称手持卡片使用牌背；`back_flipped` 专用于补偿原模型背面反向 U 坐标，保证两侧 UNO 字样方向正确。后台 `un_card` 的 0～53 数值编号仅用于规则运算，由 `visual/resolve_model` 映射到资源名。
- **牌面识别**：Skip 使用细圆环和斜杠，Reverse 的两支反向箭头保留独立留白；中心与角标分别按目标像素尺寸绘制，不把粗符号直接缩小。所有四色 6／9 的中心和双角数字均加下划线，便于旋转后区分。
- **源图与导出**：资源包 `.source/uno/` 保存 imagegen 生成的像素图集、提示词说明、导出器及联系表。导出器按既有 UV 裁切并补上可准确识别的数字、功能符号和四色牌面；详见该目录的 `README.md`。
- **重建**：数据包运行 `python tools/build_uno_engine.py`、`python tools/build_uno_ui.py`、`python tools/build_uno_visual.py`、`python tools/build_uno_firework.py`、`python tools/build_uno_hud.py`；UI 生成器会同时调用 `build_uno_settings.py` 更新单页设置。资源包运行 `python .source/uno/export_assets.py`。修改生成函数时应同步相应生成器，避免重建覆盖。

本版以 Mattel [经典说明书](https://service.mattel.com/instruction_sheets/10020-SN70_G1_4XN_IS_Uno.pdf)为规则参考；2～8 人上限、数字起手、固定时长抓 UNO 窗口、系统私密判定质疑为本项目的数字化约定。

## 验收

规则、界面、HUD、桌面展示、即时设置和真实重载已有原版 26.2 自动验收；回合道具、漏喊与 +4 独立响应也已覆盖。入口为 `tools/test_uno*.py`、`test_turn_tools.py`。

客户端仍需检查 Q 开窗、亮框选牌、数量字距、多人抢喊、私有 HUD、飞牌和烟花。脚本分类与记录见[统一验收清单](验收清单.md)。
