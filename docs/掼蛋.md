# 掼蛋

四人两两组队的升级扑克游戏，对家为搭档。两副扑克牌共 **108 张**，每人 **27 张**，争取先出完手牌，帮助本队升级并过 A。

游戏编号 **18**，命名空间 `guandan`；四人桌、八人桌均支持 **1～4 名真人**，空位自动补测试人机。正常操作无需 OP。

## 开始与操作

1. 腾空快捷栏**第 1 格和最后一格**，入座选择「掼蛋」。默认随机分队并调整到四个方向；选择「按座位自选」时，每个方向最多一名真人，空位补人机，相对而坐的两人为搭档。八人桌每侧两座可任选其一。
2. 轮到自己出牌、进贡或还牌时，第 1 格出现「掼蛋手牌」，按 **Q** 打开。HUD 和对话框使用斗地主式叠牌：从大到小排列，同点数上下叠放；点击露出的实卡选中，再点取消，金边表示选中。所有级牌在牌面内显示金色五角星，红桃级牌仍为逢人配。
3. 选牌后点「出牌」或「不出」，也可「取消所选」；关闭窗口保留选择。百搭可构成多种牌型时，再明确选择这手牌的解释；出牌成功立即退出窗口，失败不消耗牌。
4. 最后一格 **Q** 打开常驻对局菜单，可查看手牌、贡还牌和规则；贡还时选中一张合法牌并确认。提前结束使用桌边投票。

### HUD 与桌面

BetterTitle 下方显示自己的手牌；左上是上家、右上是队友，左侧第二行是自己、右侧第二行是下家。各区显示姓名、行动标记、受设置控制的余牌数，以及本轮最近一次公开出牌。位置按逆时针行动关系计算，兼容不同座位与人机。

桌边放置各方公开牌，玩家姓名和牌型说明集中在 HUD，不重复铺满桌沿。桌心信息平放，显示当前副数、级牌、两队级数和行动座位，牌盒位于旁边。聊天记录出牌、不出与结算；发牌、出牌、收牌和贡还牌有动画，整场胜者使用 SK Firework 烟花。

顺子、同花顺、三连对和钢板按牌型点数排列，同一点数先列自然牌、再列补位的实卡逢人配；公开说明会写出“红桃2作5”等替代信息。其他牌型按实际牌点排列。桌面和 HUD 共用公开记录，不展示他人的在手牌面。

## 本包规则

采用竞技掼蛋的两副牌、逆时针轮转与升级框架；以下列出本包实际执行的条款，避免与其他地方玩法混用。

- 首副随机首出；其后由贡牌结果决定首出。领出必须出牌，其余人可跟牌或不出。已出完者跳过；一圈无人压过时由最后出牌者重新领出，若其已出完则由搭档接风。
- 普通单张／同点数牌组：**大王 > 小王 > 级牌 > A > K > … > 2**。同点不同花色不分大小。级牌在顺子、三连对、钢板中按原点数参与，不插入额外位置。
- 两张红桃级牌为逢人配，可补普通点数和同花顺所需花色，不能代替大小王；作为单张打出时仍是级牌。不能把两张百搭任意声明成王。
- 顺子固定 5 张，三连对固定 3 对，钢板固定连续 2 组三张。A 可在低端参与 A2345、AA2233、AAA222，也可在高端参与 10JQKA、QQKKAA、KKKAAA，不能绕接 JQKA2。

| 牌型 | 组成与比较 |
| --- | --- |
| 单张／对子／三张 | 1／2／3 张同点牌；同牌型比较点数 |
| 三带二 | 三张同点带另一点数的一对，比较三张部分 |
| 三连对 | 连续三对，共 6 张，比较最高点数 |
| 钢板 | 连续两组三张，共 6 张，比较最高点数 |
| 顺子 | 连续 5 张；普通顺子之间比较最高点数 |
| 炸弹 | 4～10 张同点；张数优先，同张数比较点数 |
| 同花顺 | 同花色连续 5 张，比较最高点数 |
| 四王 | 两张大王与两张小王，最大牌型 |

普通牌型只能压相同牌型与张数。**四王 > 10～6 张炸弹 > 同花顺 > 5 张炸弹 > 4 张炸弹 > 普通牌型**。五张天然同花连牌按同花顺处理；有逢人配且存在不同合法解释时，由玩家明确选择。

### 贡还牌、抗贡

- 首副不进贡。上一副单下：末游向头游进贡一张；双下：第三、第四名各进贡一张，较大的一张给头游，另一张给二游。同大时按头游的顺时针邻座向头游进贡。
- 贡牌须为手中最大牌，**红桃级牌除外**。接贡者还一张原点数不超过 10 的牌；若全手牌都大于 10，必须还最小牌。低点级牌仍可还。
- 单下者持两张大王，或双下方合计持两张大王，抗贡成立，免贡还，由上一副头游首出。
- 未抗贡时由进贡较大者首出，同大按上述分配确定。进贡、还牌分别确认，双方尚未选齐时不提前公开未确认的交换结果。

### 升级与结束

头游所在队获胜：搭档为二游升 **3 级**，三游升 **2 级**，末游升 **1 级**。双方各记自己的级数，下副打胜方的新级数。

完整升级赛必须打 A；在打 A 的一副中取得头游，且搭档不是末游，才能过 A 获胜。未过则停在 A，不采用“三次不过退回 2”。固定副数达到设定后比较双方级数，相同为平局；期间成功过 A 则提前结束。每副结算后自动继续，整场结束后返回大厅。

## 游戏设置

大厅内集中在同一对话框，点击立即生效，开局后锁定。

| 设置 | 选项／默认 |
| --- | --- |
| 搭档分配 | 按座位自选／**随机分队** |
| 起始级牌 | **2**～A |
| 比赛模式 | **完整升级赛**／固定副数 |
| 固定副数 | 1、2、3、5、**8**、10、16、32 副 |
| 显示他人余牌数 | **开启**／关闭 |
| 每步操作时限 | **无限制**、30、60、90、120 秒 |

设置时限后，超时跟牌自动不出，超时领出自动出最小单张；贡还阶段自动选择合法牌。动画期间暂停操作计时。任一参与者掉线或失去本桌身份时中止本场，清理本桌手牌与操作物。

## 测试人机

不足四人时自动补齐，单人补三名。人机与真人使用同一套发牌、压牌、贡还、排名和升级流程；人机只处理自己应进贡或还牌的操作，不会替真人抢先选牌。掉线检测只统计本局真人，`/reload` 保留真人、人机已发手牌和贡还状态。

人机分刻检查单张、对子、三张、三带二、连牌、炸弹、四王及逢人配补缺，每刻最多处理三个候选；通常保留炸弹、优先整手出完，搭档领牌时让牌。它不穷举所有实卡组合，可能漏掉更优配牌或同花顺，适合补位测试。人机思考不占用真人操作时限，也不接收私人 HUD 或道具。

## 管理命令

在桌旁由有命令权限的玩家中止同维度 8 格内最近一场掼蛋：

```mcfunction
/function guandan:admin/abort
```

指定桌号（将 `12` 换成目标桌号）：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=12,ct_game=18,ct_state=1},limit=1] at @s run function guandan:game/abort
```

建桌、删桌与 Debug 见[根 README](../README.md)。

## 来源与维护

规则资料：[国家体育总局规则介绍](https://www.sport.gov.cn/n20001280/n20745751/n20767274/c22011669/content.html)、[中国企业体育协会竞赛规程](https://www.cesa.org.cn/xhxm/gdjbs/Content_5123.shtml)、[协会郑州站通知及补充规则](https://cesa.org.cn/res/file/关于举办恒源祥2023中国职工竞技掼蛋锦标赛郑州站比赛的通知.pdf)。复用本包已有扑克牌模型和斗地主的叠牌交互方式；九段短音效由本项目合成，源文件与哈希在资源包 `.source/guandan/`，无新增前置。

叠牌与四方 HUD 由 `tools/build_guandan_ui.py`、`build_guandan_hud.py` 和 `build_guandan_layout.py` 生成，接缝由 `fix_card_stack_seams.py` 处理。更换牌图时须一起调整字形宽度和回退，保持逐张点击对应；最终显示的叶文本组件不要保留空 `extra:[]`，否则可能使整块 HUD 解析失败。公开排序只修改展示顺序和百搭说明，不改变实卡编号或牌面。

`/reload` 重建本桌公开文字和 HUD，保留手牌、计时、贡还选择与发牌进度；旧窗口失效后通过当前操作物或对局菜单重开。更新字体、牌图或音频后，客户端须更新配套资源包并按 **F3+T**。
