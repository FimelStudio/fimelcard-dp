# 骷髅牌

2～6 人的诈唬与记忆游戏。每人有三张花牌和一张骷髅牌，秘密扣牌，再竞标自己能连续翻出多少张花牌。累计挑战成功两次，或成为唯一还有牌的玩家，即获胜。四座桌最多 4 人，5～6 人使用八座桌。

游戏编号 `9`，命名空间 `skull`。普通玩家无需 OP；开局清空九格快捷栏，座位可不连续。安装和建桌见[README](../README.md)。

## 玩法与操作

手中的花牌与糖骷髅牌使用专用牌面；选择手牌按 Q 扣下。叫号、翻牌和自选弃牌通过对话框操作，紫色染料按 Q 可重开窗口。首轮起始玩家随机产生。

1. **首次扣牌**：每人同时秘密扣下一张，只能扣一次。
2. **加牌或叫号**：从起始玩家顺时针行动，跳过空座。轮到自己时可以再扣一张，或叫出愿意翻开的数量；没有手牌时必须叫号。叫号不得低于自己的扣牌数，也不能超过桌上总牌数。
3. **竞标**：第一次叫号后，全桌不再加牌，只能提高叫号或放弃。新叫号至少为“自己扣牌数”和“当前最高叫号加一”两者的较大值，上限为桌上总数，六人最多 24 张。放弃后不能重新竞标，但扣下的牌仍参与挑战。仅剩一人或有人叫到桌上总数时，该玩家成为挑战者。
4. **翻牌**：挑战者先从顶到底自动翻自己的全部牌，再逐次选择其他人的堆顶。翻够叫号数量且全为花牌，挑战成功；翻到任意骷髅立即失败。
5. **下一轮**：剩余牌收回，结算后 2 秒自动继续。挑战者先行动；若其淘汰，顺延到下一名存活玩家。

## 失败与淘汰

- 翻到**别人的骷髅**：从挑战者全部剩余牌中等概率随机永久弃一张。
- 翻到**自己的骷髅**：挑战者秘密选择一张永久弃掉，可选本轮已扣下的牌。
- 弃牌内容仅本人可见，永久弃掉的牌不再补回；失去最后一张牌的玩家离座淘汰。

桌心显示每位玩家本轮扣牌数量，翻开后该数量仍表示本轮曾扣下的总数；各玩家前方摆放已扣下的牌，未翻开时只显示牌背，翻开后显示对应花牌或骷髅。游戏采用固定规则，“游戏设置”提供通用牌桌皮肤与椅子数量。

八套主题牌面按实际座号 1～8 固定分配，同一座位的三张花牌和一张骷髅属于同套；后续轮次沿用原牌面。第一人称手持及物品栏显示正面，第三人称手持显示牌背，不向其他人公开手中牌型。

## 管理与中断

以下命令需要命令权限，操作同维度 8 格内最近一场本游戏，无需填写桌号；指定桌号和 Debug 见[主说明](../README.md)。

```mcfunction
# 查看本桌当前叫号
/scoreboard players get @e[type=minecraft:marker,tag=sk.controller,distance=..8,sort=nearest,limit=1] sk_bid

# 中止附近最近一场骷髅牌并返回大厅
/function skull:admin/abort
```

`/reload` 保留手牌、扣牌顺序、永久弃牌、叫号及胜利次数。参与者离线时整桌暂停，原参与者全部重连后继续；正常淘汰不影响其他人继续。桌边“结束游戏”投票、中止或移除牌桌都会清理专属物品、文字和发牌动画。

维护入口：[牌库与拥有牌](../data/skull/function/deck/)、[游戏流程](../data/skull/function/game/)、[交互输入](../data/skull/function/input/)、[桌面展示](../data/skull/function/visual/)。专用模型为 `card:skull/set<座号>/flower`、`skull` 与牌背；牌的身份、扣牌顺序和永久弃牌以本桌控制器为准，桌面展示只读取已扣牌记录和已公开的翻牌结果。开局公共飞牌只作动画。

八套主题源图、预览、生成提示和来源保留在 [skull-art](skull-art/README.md) 与[主题清单](skull-art/sets.json)，由 `tools/build_skull_sets.py` 重建资源，`fix_skull_card_display.py` 维护牌面显示。替换牌图时不修改扑克或掼蛋资源。

## 验收

运行 `node tools/check_skull.mjs`。人工复测同时首次扣牌、无手牌叫号、竞标后不能加牌或重新加入、先翻自己再翻他人堆顶、两类秘密弃牌、永久失牌与挑战者淘汰顺延；六人高号座的 20～24 叫号应正常。客户端另查八套牌面、未翻牌保密、手持正背、四／八座桌面朝向和翻牌展示。重复 Q、重载及两桌隔离见[验收清单](验收清单.md)。
