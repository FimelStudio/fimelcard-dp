# 骷髅牌

2～6 人的诈唬与记忆游戏。每人有三张花牌和一张骷髅牌，秘密扣牌，再竞标自己能连续翻出多少张花牌。累计挑战成功两次，或成为唯一还有牌的玩家，即获胜。四座桌最多 4 人，5～6 人使用八座桌。

游戏编号 `9`，命名空间 `skull`。普通玩家无需 OP；开局清空九格快捷栏，座位可不连续。安装和建桌见[README](../README.md)。

## 玩法与操作

手中的黑桃 A 表示花牌，小丑牌表示骷髅；选择手牌按 Q 扣下。叫号、翻牌和自选弃牌通过对话框操作，紫色染料按 Q 可重开窗口。首轮起始玩家随机产生。

1. **首次扣牌**：每人同时秘密扣下一张，只能扣一次。
2. **加牌或叫号**：从起始玩家顺时针行动，跳过空座。轮到自己时可以再扣一张，或叫出愿意翻开的数量；没有手牌时必须叫号。叫号不得低于自己的扣牌数，也不能超过桌上总牌数。
3. **竞标**：第一次叫号后，全桌不再加牌，只能提高叫号或放弃。新叫号至少为“自己扣牌数”和“当前最高叫号加一”两者的较大值，上限为桌上总数，六人最多 24 张。放弃后不能重新竞标，但扣下的牌仍参与挑战。仅剩一人或有人叫到桌上总数时，该玩家成为挑战者。
4. **翻牌**：挑战者先从顶到底自动翻自己的全部牌，再逐次选择其他人的堆顶。翻够叫号数量且全为花牌，挑战成功；翻到任意骷髅立即失败。
5. **下一轮**：剩余牌收回，结算后 2 秒自动继续。挑战者先行动；若其淘汰，顺延到下一名存活玩家。

## 失败与淘汰

- 翻到**别人的骷髅**：从挑战者全部剩余牌中等概率随机永久弃一张。
- 翻到**自己的骷髅**：挑战者秘密选择一张永久弃掉，可选本轮已扣下的牌。
- 弃牌内容仅本人可见，永久弃掉的牌不再补回；失去最后一张牌的玩家离座淘汰。

桌心仅显示每位玩家本轮扣牌数量，翻开后该数量仍表示本轮曾扣下的总数；不显示牌堆模型或未翻开的牌型。游戏采用固定规则，“游戏设置”仅提供通用牌桌皮肤入口。

## 管理与中断

以下命令需要命令权限，操作同维度 8 格内最近一场本游戏，无需填写桌号；指定桌号和 Debug 见[主说明](../README.md)。

```mcfunction
# 查看本桌当前叫号
/scoreboard players get @e[type=minecraft:marker,tag=sk.controller,distance=..8,sort=nearest,limit=1] sk_bid

# 中止附近最近一场骷髅牌并返回大厅
/function skull:admin/abort
```

`/reload` 保留手牌、扣牌顺序、永久弃牌、叫号及胜利次数。参与者离线会中止本局；正常淘汰不影响其他人继续。桌边“结束游戏”投票、中止或移除牌桌都会清理专属物品、文字和发牌动画。

维护入口：[牌库与拥有牌](../data/skull/function/deck/)、[游戏流程](../data/skull/function/game/)、[交互输入](../data/skull/function/input/)。花牌、骷髅牌复用 `card:poker/c_a`、`card:poker/joker`；开局公共发牌只作动画，不新增长期桌面牌堆。牌的身份、扣牌顺序和永久弃牌以本桌控制器为准。

## 验收

运行 `node tools/check_skull.mjs`。人工复测同时首次扣牌、无手牌叫号、竞标后不能加牌或重新加入、先翻自己再翻他人堆顶、两类秘密弃牌、永久失牌与挑战者淘汰顺延；六人高号座的 20～24 叫号应正常。重复 Q、重载及两桌隔离见[验收清单](验收清单.md)。
