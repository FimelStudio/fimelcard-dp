# 卡坦岛

游戏编号 **21**，命名空间 `catan`。Minecraft Java 26.2，**2～4 名真人**，四人桌、八人桌均可游玩，普通玩家无需 OP。采集资源、交易、修路建村，在自己的回合率先达到 **10 分**。

首版采用 [CATAN 官方第六版基础规则](https://www.catan.com/sites/default/files/2025-03/CN3081%20CATAN%E2%80%93The%20Game%20Rulebook%20secure%20%281%29.pdf)，不包含人机和扩展玩法。19 号为同伴的命悬一线，编号不变。

双人局沿用相同地图、资源库存与建造规则，初始布置顺序为甲→乙→乙→甲，不增加人机或中立玩家。

港口的 `2:1` 下方显示对应资源：红色砖堆是砖块港，浅色毛线团是羊毛港，分别配红色、绿色边框，与资源牌图案一致。港口只改变所属玩家兑换该资源的比例；沿岸相邻交点有自己的村庄或城市才享受优惠。图示见[完整规则的港口图鉴](releases/rules/21-卡坦岛.md#9-个港口的全部类型)。

## 开始与操作

安装配套资源包，入座后选择「卡坦岛」。大厅立即显示岛屿预览；先调整设置，再由2～4人开始。请腾空**快捷栏九格**，主物品栏留出资源牌和发展卡空间。

| 入口 | 操作 |
| --- | --- |
| 第1／2／3格：村庄／道路／城市 | 手持瞄准位置，右键或Q预览，再次操作确认；名称显示成本，不足时灰显 |
| 第4格：购买发展卡 | 按Q一次购买，也可右键桌面牌堆购买 |
| 第5格：银行／港口兑换 | 按Q后先选支付资源，再选换取资源，确认兑换按Q一次 |
| 第6格：玩家交易／查看报价 | 瞄准玩家后按Q，或选择姓名；报价在单页编辑器中完成，接收方主动查看接受／拒绝 |
| 第7格：结束回合 | 按Q一次；免费修路阶段改为放弃剩余道路 |
| 第8格：投骰 | 按Q；强盗偷取阶段可瞄准对手按Q一次偷取 |
| 第9格：取消 | 按Q取消预选；桌面左键也可取消 |
| 物品栏资源和发展卡 | 按Q选择弃牌、银行支付资源或使用旧发展卡；新牌本回合不可用 |

八人桌的远端可能超出客户端右键距离，手持对应建筑按Q可从座位选择远处目标。不能在海面、边框空角或格子中心误建道路、村庄。几何拾取随四／八座桌和棋盘方向变化。

### 第一次玩时看这里

BetterTitle左右分列名字、分数、资源、发展卡总数、道路和骑士，行动者名字右侧显示黄色 ▶。本人显示五种资源图标及数量和含隐藏胜利点的实际分数，其他玩家只显示资源总数及公开分数。四人时左右各两人；公开信息放在屏幕角落，棋盘留给建造与目标提示。屏幕中间显示阶段和行动者，操作失败的具体原因保留四秒。未用发展卡仅本人可见，第三人称和掉落显示背面。常规流程不打开对话框。

资源的种类与各类数量属于隐藏手牌，资源总张数公开，依据 [CATAN 官方 FAQ](https://www.catan.com/faq/basegame) 的 Resource Cards 条目。HUD 不公开其他玩家的资源分类或秘密胜利点。

1. **村庄选交点，道路选边。**手持对应建筑，右键或Q预览，再次确认。村庄须与其他建筑至少隔一个空交点；初始道路紧邻刚放村庄。开局顺序、逆序各放一组，只有第二个村庄领取起始资源。
2. **正式回合先投骰。**第8格骰子按Q，之后建造、交易或使用旧发展卡。结束回合使用第7格按Q一次。动画和最长道路计算期间等待即可。
3. **七点弃牌。**资源超过七张的玩家各弃一半，资源按Q加入待弃列表，撤销物品可退回一张；选满规定数量后自动统一扣除，不会提前逐张支付。其他人完成不会清空你的待弃选择。
4. **移动强盗。**直接瞄准另一地块，右键或Q两次确认；仅一名相邻对手时自动偷取，多人时瞄准玩家按Q或右键一次，也可对姓名物品按Q一次。
5. **发展卡。**旧卡按Q一次使用；骑士转入强盗操作，修路直接放道路，垄断用临时资源选项选择一种，丰收先选两张资源再确认，可以同种。垄断／丰收的确认物品按Q一次提交。胜利点自动计分。

初始布置和免费修路不扣普通建造费用。目标不合法、费用不足、银行缺货、发展卡不可用等情况直接在actionbar说明，不执行半次操作。资源物品仅镜像服务器库存，丢出后回收并恢复；不会因摆放、丢弃或移动显示物改变资产。

第一次 Q 或右键建造就检查材料，城市升级会分别列出缺少的粮食、矿石及现有数量；发展卡购买前检查费用。银行选择支付资源时即按本人港口显示比例与持有量，材料不足、银行库存为空、兑换同种资源、未投骰或非本人回合均立即提示。银行缺货后可直接改选换取资源。购牌和结束回合按Q一次执行，建筑落点仍先预览再确认。

界面标注姓名与建筑颜色：1红、2蓝、3白、4橙；实际座号可不连续。资源、发展卡和交易报价同时显示数量与中文名称。木材、砖块、羊毛、粮食、矿石的卡面与生产动画使用同一套图案；金色胜利点不计作第六种资源。随机首位会随机分配行动顺序，按座位则按已入座的座号排序，不要求玩家换座。

交易窗口绑定本桌、局面版本和一次性窗口编号；旧报价和上一步确认不能重复提交。报价详情仅双方可见，成交前重新检查双方库存。

## 设置

大厅设置为同一页，点击后立即生效，不需保存。开局后固定布局、方向与首位；音乐在开局前设置。

已有公开终局时，重载和修改布局设置都保留该局棋面；新的岛屿布局在下一局开始时生成。

| 设置 | 选项／默认 |
| --- | --- |
| 岛屿布局 | 推荐（默认）／随机；随机地形按标准顺序放数字，沙漠跳过 |
| 棋盘方向 | 默认／旋转 90°；两种桌型自动缩放 |
| 首位行动 | 随机（默认）／按座位 |
| 背景音乐 | 开启（默认）／关闭；音量受「唱片机／音符盒」控制 |
| 牌桌皮肤 | 使用公共皮肤选择入口 |

基础目标固定 10 分、回合不限时。地形为森林／牧场／麦田各 4，丘陵／矿山各 3，沙漠 1；9 个港口位置固定，包括四个 3:1 港与五种资源各一个 2:1 港。

## 一局怎样进行

**初始布置：**按行动顺序每人放一个村庄及相邻道路，再逆序各放第二组。仅第二个村庄领取相邻地形的起始资源。村庄之间必须至少隔一个空交点。

**正式回合：**掷两枚骰子 → 生产资源或处理7 → 自由交易、建造、使用旧发展卡 → 第7格Q一次结束回合。掷骰前也可以使用旧发展卡，每回合仍限一张行动发展卡。骰值先保存，再播放翻滚动画；重载不会重新投骰或重复发资源。

除 7 外，数字匹配的地块向**所有相邻建筑**生产：村庄 1 张、城市 2 张，强盗所在格停产。银行按资源分别结算：多人应领而库存不足时该资源不发；只有一名应领者时可领剩余库存，其他资源正常发放。

### 建造与得分

| 行动 | 费用 | 效果 |
| --- | --- | --- |
| 修道路 | 木材＋砖，各 1 | 连接己方道路或建筑，最多 15 段 |
| 建村庄 | 木材＋砖＋羊毛＋粮食，各 1 | 1 分，最多 5 个；连接己方道路并满足间距 |
| 升级城市 | 粮食 2＋矿石 3 | 村庄升为总计 2 分，最多 4 个；归还村庄库存 |
| 购买开发牌 | 羊毛＋粮食＋矿石，各 1 | 秘密抽牌，进入自己的新牌区 |

道路不能穿过对手村庄／城市继续延伸；升级城市只能选择己方村庄。建造先预选再确认，实际提交时重新核对轮次、位置、费用与棋子库存。

最长道路至少 **5 段**，同一路段只能经过一次，允许绕环或重复经过交点；对手建筑阻断穿行，但路线可以在此结束。最大军队至少 **3 张已使用骑士**；两项奖励各 2 分。并列时原持有者保留；原持有者失格且其他人并列时，奖励暂归银行。

只有在**本人回合**达到 10 分才获胜，隐藏胜利点计入本人总分。胜者位置播放内置 SK Firework，结算后返回大厅并保留公开终局；重新开始、切换游戏或移除牌桌时清理旧棋面。

### 交易

- 银行默认4:1；拥有通用港口为3:1，对应资源港为2:1。选好两种资源后actionbar显示实际兑换比；每次兑换一张，可重复操作。新建港口当回合即可使用，道路经过港口不算拥有。
- 任何玩家可发起包含当前行动者的交易。选择对方姓名，再设置「你给予」与「你索取」的五种资源数量；只能交换资源，不能赠送、同资源互换或交易开发牌。
- 同桌保留一项当前报价，只有交易双方能看详细价格。对方在回合外也能按第 9 格 Q 查看并接受／拒绝，发起者可以撤销。接受时再次核对报价编号、版本及双方库存，成功才交换。
- 回合结束、重载失效或中止后的旧报价不能接受；掷 7 等待弃牌时不能交易。

### 7、强盗与开发牌

掷出7时，**资源总数超过7**的每名玩家分别弃一半，向下取整；发展卡不计入。对资源按Q选择弃牌，所有人完成后，当前玩家移动强盗到另一个地块，再选择相邻对手偷一张随机资源。偷取按实际资源卡张数抽取；没有目标直接继续，唯一目标自动偷取。强盗不封锁港口、道路或建造。

发展卡共25张：骑士14、胜利点5，修路／垄断／丰收各2。物品栏分别显示自己的旧牌与本回合买到的新牌，物品说明标明使用限制。

| 开发牌 | 效果 |
| --- | --- |
| 骑士 | 移动强盗并偷牌；不触发弃半，计入最大军队 |
| 修路 | 免费建最多两路，仍须合法且有道路库存；可放弃剩余机会 |
| 垄断 | 收取所有对手所选种类的全部资源 |
| 发明 | 从银行领取任意两张资源，可选同一种 |
| 胜利点 | 保密计分，不作为主动使用的行动牌 |

每回合最多使用一张非胜利点开发牌，且不能使用本回合买到的新牌。购买胜利点牌可立即满足本人回合的获胜条件。

## 显示、音效与恢复

棋盘使用立体树木、黏土丘陵、羊群、麦穗、矿山／矿洞与仙人掌；港口带栈桥、木桩、货箱和帆船。装饰避开中心数字及道路、村庄交点，不改变原本的建造位置与规则。地块数字和港口兑换标记为朝上的 `vertical` 物品展示实体，每位玩家从自己的方位看到自动转向的标记，位置固定在对应区域。发展牌堆放在棋盘海域之外的桌角，随桌型与棋盘方向同步调整；牌堆有独立厚度与高度，右键点击区域跟随牌堆。

桌面公开建筑、道路、强盗与骰面，BetterTitle公开资源总数、发展卡总数和公开分数；**手中各类资源数量、未使用的发展卡和隐藏胜利点仅本人可见**。生产所得可从公开棋面推算，动画显示资源图标；交易价格只向双方显示，公开动画使用中性袋／牌背。物品栏只是服务器库存的镜像，移动或复制显示物不会转移资产。

双骰翻滚停稳，建造升起，强盗移动，资源从生产地块飞向接收者，交易和开发牌播放对应动画与粒子。所有结果先提交，再按保存的事件逐项播放；结束或重载会清理未完成的动画，不重新执行扣费、抽牌、交易或发资源。投骰、建路、建村、升级、交易、强盗、开发牌和胜负各有音效；背景音乐低音量循环，只发给本桌参与者，关闭、离座、结束或重载会停止旧音乐。

音效使用 [Kenney Casino Audio](https://kenney.nl/assets/casino-audio) 与 [Impact Sounds](https://kenney.nl/assets/impact-sounds)；音乐为 [RandomMind《Medieval: The Old Tower Inn》](https://opengameart.org/content/medieval-the-old-tower-inn)，均为 CC0。地形基于 Kenney CC0 素材，立体建筑与棋盘适配为本项目制作；原文件、来源、许可、哈希及制作脚本保留在资源包 `.source/catan/`。

重载保留已提交棋面、资源、开发牌、骰值及道路搜索进度，重建展示并令旧操作窗口失效；大厅中的公开终局也会保留。本局有人离线时整桌暂停，冻结计时、输入和动画队列，原参与者全部重连后继续，不再设置 200 刻中止时限；等待期间可投票或管理员中止，结束后重连自动清理旧局状态。两桌的状态、窗口、声音与清理分别隔离。

## 管理命令

以下需要命令权限；玩家正常游玩使用物品按Q和右键，无需管理员权限。

```mcfunction
# 中止同维度 8 格内最近一场卡坦岛，保留牌桌并返回大厅
/function catan:admin/abort

# 查询自己所属桌号
/scoreboard players get @s ct_id

# 将 1 换成实际桌号，精确中止
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=21,ct_state=1},limit=1] at @s run function catan:game/abort

# 查询该桌阶段、当前行动者与胜者（编号 1～4）
/data get entity @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=21},limit=1] data.catan.phase
/data get entity @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=21},limit=1] data.catan.turn
/data get entity @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=21},limit=1] data.catan.winner

# 接收／停止接收公共 Debug 日志
/tag @s add ct.debug
/tag @s remove ct.debug
```

阶段：1 初始村庄、2 初始道路、3 待投骰、4 主行动、5 弃牌、6 移动强盗、7 偷取对象、8 免费修路、10 道路计算、11 终局。建筑或道路变化后按刻计算最长道路，期间暂停提交和胜负判断；当前每桌每刻处理最多 64 个搜索状态，不提高默认 65536 命令上限。

### 行动提示与手持显示

聊天记录轮到谁、初始放置、建造、骰值、弃牌、强盗、发展卡和交易；资源产出明细只通知资源获得者。需要本人接手、弃牌、回应报价、被偷取或获胜时显示 subtitle。actionbar 保留操作指引和失败原因，bettertitle 持续显示公开分数、资源／发展卡总量、道路和骑士军情况；需要弃牌和收到报价的人会看到自己的下一步提示。

桌面骰子在待投骰时出现少量粒子，强盗在待移动时发光；位置选中后沿用桌面发光预览。建筑、道路、城市与骰子调整了独立的第一／第三人称大小、位置和朝向，第一人称道具移近镜头并避免静止时裁边。卡坦岛操作骰与飞行棋共用模型，两个游戏一并生效。
