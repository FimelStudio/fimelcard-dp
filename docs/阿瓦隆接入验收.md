# 阿瓦隆接入与验收

存档与 Git 工作区均接入。游戏编号16，命名空间avalon，前缀av。

## 操作

- 八人桌选择阿瓦隆，实际入座5～8人；所有玩家清空快捷栏第8、9格。
- 开局随机身份、随机初始队长。自己的身份卡放在第8格，物品名称标明角色与阵营；不再持续显示actionbar。
- 紫色染料按Q打开身份、互认信息与当前阶段操作窗口。关闭后可再次打开。
- 队长点击玩家姓名切换队员；人数正确且讨论结束后点击开始投票。讨论顺序由玩家自行组织。
- 全员秘密选择同意或反对，全部提交后公开每人结果；严格过半通过。
- n人局连续否决n－1次后，第n次队伍直接通过。通过后清零连续否决次数。
- 队员秘密提交任务，好人只有成功按钮，坏人可选成功或失败。公开汇总票数，不暴露提交者。
- 仅7、8人第四轮需2张失败票，其他轮次1张即失败。
- 坏人累计3分直接获胜。好人累计3分强制进入刺杀。
- 刺客可提前翻牌（二次确认），随后选定好人目标并确认刺杀。刺中梅林坏人胜，否则好人胜。
- 中央显示队长、队员、所需人数、否决次数、阵营得分和已完成任务记录。
- 玩家离线或结束投票通过后清理本场并恢复大厅。reload保留状态与秘密票，旧窗口作废，Q可重新打开。

## 已执行检查

`python tools/check_avalon.py`：函数引用、记分项、括号、对话框静态姓名、窗口nonce/阶段校验、任务人数表、投票边界、稀疏座位轮换和生命周期分派。

这些是静态检查与规则枚举，不等同真实多人客户端测试。
