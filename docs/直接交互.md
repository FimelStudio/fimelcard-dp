# 三款新游戏的直接交互

璀璨宝石：完全使用桌面交互。右键宝石选择三色，或只选一色后再次右键拿两颗同色，左键取消；发展卡第一次右键选中、第二次购买，不足时第三次预定；牌堆右键两次盲预定。超限退珠右键选择、左键撤销，恰好退至十颗时自动确认。手持快捷栏后三格预定牌按两次Q购买。棋盘朝向当前玩家，全员资产分列左右上角，四人局每侧两人；宝石与已购卡防丢，预定牌第三人称显示牌背。贵族满足要求自动来访，多位符合时右键选择一位。详见[璀璨宝石](璀璨宝石.md)。

卡坦岛：快捷栏1/2/3格为村庄、道路、城市，手持后右键或Q瞄准位置预览，再次确认才建造；资源不足显示灰色建筑。4格购买发展卡，5格银行兑换，6格玩家交易，7格结束回合，8格投骰，9格取消。资源与发展卡在物品栏按Q操作并防丢。弃牌选满规定数量自动统一提交；银行、垄断和丰收使用临时资源选项。只有玩家间多项报价及查看报价保留单页对话框。详见[卡坦岛](卡坦岛.md)。

胡闹运动会：右键桌面角色两次招募，左键取消；角色物品按Q两次秘密出场，全员提交后揭晓。技能以临时物品或目标棋子完成，第7格翻页、第8格骰子Q、第9格取消。角色牌第三人称显示背面。双胞胎等大量候选能力可主动打开单页窗口，其余流程不弹窗；小场结算后自动进入下一场。详见[胡闹运动会](胡闹运动会.md)。

退出会清理游戏物品。开始前应腾空提示要求的快捷栏，并留出资源物品空间。界面资源是服务器状态的显示，不以玩家移动或丢弃物品作为交易。

生成入口 `python tools/build_direct_interactions.py --game <namespace>`；游戏总生成脚本在最后应用此层。璀璨宝石使用 `build_splendor_direct.py`、`build_splendor_inventory.py`、`build_splendor_hud.py`；卡坦岛与胡闹运动会分别使用 `build_catan_direct.py`、`build_magical_athlete_direct.py`，并共用 `build_table_direct_hud.py`。旧模板仅提供兼容基础，新流程由Python生成源覆盖；重建只更新目标游戏的暂停护栏。
