# 命悬一线

2～8 人的合作排序游戏。每关抽取一个主题，用主题描述自己的数字，讨论后争取从小到大出牌，不能直接透露具体数字。

游戏编号 **19**，命名空间 `ito`。四人桌支持 2～4 人，八人桌支持 2～8 人；当前仍在开发验证中。

## 开局与操作

开局前腾空快捷栏**第 1～6 格和第 9 格**，在大厅选择输入方式并保存。默认使用书本，普通玩家可提交；自由文本对话框提交需要 **OP 权限**。设置仅能在原牌桌大厅保存，开局和换关不自动弹出对话框。

- **描述书**：前三格用于每张手牌的描述书，书的 lore 和私密窗口可查看自己的数字。第一页填写 1～48 字后按 **Q** 提交，可再次修改。
- **对话框**：此模式不发描述书。拿第 9 格紫色染料按 **Q**，再手动选择修改描述；对话框只负责修改描述。
- **出牌**：每张手牌对应一张显示数字的纸牌，拿对应数字牌按 **Q** 出牌。全桌所有未出手牌的描述必须先交齐，否则数字牌会返还。

## 关卡与胜负

初始 **3 点生命**，三关分别给每人 **1、2、3 张牌**。每关从 [80 道欢乐主题](命悬一线题库.json)中随机抽取一题，直接进入描述阶段；第三关额外公开一张参照牌。

跳过较小的牌时，系统自动揭示并移除被跳过的牌，**每张扣 1 点生命**。过关恢复 1 点生命，上限为 3；两人局不回血。通过第三关全员获胜，生命归零失败；结算 5 秒后返回大厅。

## 管理与维护

在同维度牌桌 8 格内，由有命令权限的玩家中止最近一场命悬一线，保留牌桌并返回大厅：

```mcfunction
/function ito:admin/abort
```

建桌、删桌、指定桌号及 Debug 见[根 README](../README.md)。也可使用桌边“结束游戏”投票中止。`/reload` 恢复本局 HUD 和公开展示并关闭旧界面，不重新开局；需要时通过当前操作物重新打开窗口。

题库与显示分别由 `tools/build_ito_themes.py`、`build_ito_display.py` 维护；输入、数字牌、对话框和设置生成入口见 `build_ito*.py`。题库 JSON 保留为独立数据文件，完整玩法和命令集中在本页。

## 验收

当前实现仍在开发验证中：HUD 长文本分页、公共参照提示、出牌确认、发牌动画和完整运行验收尚待完成。需复测两种输入、描述修改、未交齐返牌、各关发牌与跳牌扣血、两人不回血、旧窗口、重载和双桌隔离。不要视为最终验收版本，通用场景见[验收清单](验收清单.md)。
