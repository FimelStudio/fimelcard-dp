# 命悬一线 · 蛛丝
游戏编号19，命名空间ito，2–8人。四人桌2–4人，八人桌2–8人。
初始3生命，三关分别每人1、2、3张牌；过关恢复1生命，上限3，两人局不回血。第三关额外公开一张参照牌。
每关从80道欢乐主题中随机抽取一题，直接进入描述阶段。
前三格用于描述书，第九格用于紫色染料入口。书的lore和私密窗口可查看自己的数字；书第一页1–48字，完成后Q提交，可修改。自由文本对话框沿用现有项目方案，提交需要OP，普通玩家使用书本。
必须先为所有未出手牌提交描述，才能主动出牌。跳过较小牌会自动揭示移除，每张扣1生命。通过第三关胜利，生命归零失败。结算5秒后返回大厅。
当前实现仍在开发验证中：HUD长文本分页、公共参照提示、出牌确认、发牌动画和完整运行验收尚待完成。不要视为最终验收版本。


输入方式由开局前的游戏设置选择，默认书本。对话框模式不发描述书，按Q使用紫色染料后手动选择修改描述，提交需要OP权限。开局和换轮不自动弹出对话框。设置仅能在原牌桌大厅保存。

出牌操作：每张手牌对应一张显示数字的纸牌，拿牌按Q出牌；对话框仅用于修改描述。描述未交齐时返还数字牌。开局需腾空快捷栏第1至6格及第9格。
