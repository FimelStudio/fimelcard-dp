# 命悬一线（编号19）

2–8人。开局前在游戏设置选择蛛丝或红线；每轮随机主题。只能描述数字大小，不可说出具体数字。

输入可选书本或单页对话框；数字牌按Q操作。

蛛丝：共享3点生命，三关每人1/2/3张。必须从小到大出牌，跳过每张牌扣1生命；归零失败，第三关完成胜利。过关回1生命，上限3，两人局不回血。

红线：每轮每人1张。全部描述提交后，数字牌按Q选择搭档；双方互选才同时亮牌。可以修改尚未确认的邀请，也可单飞亮牌得0分。已亮牌不能重新配对。

合计恰好100：该搭档立即获胜，覆盖此前登船者。否则全员亮牌后结算，不超过100的组合按总和从大到小排名；第一名每人2分，第二名每人1分，超100或单飞0分。并列同分占名次：两组并列第一均得2分，后续为第三名。

个人累计达到5分视为登船；一人登船时继续，至少两人登船时游戏结束，累计分最高两人获胜。同分争夺最后席位时按座位号从小到大确定。

不会自动打开窗口。原有数字牌、题库和输入方式保留。

题库共140题，新增动物、饮食、旅行、日常物品、Minecraft、魔法等60题。蛛丝和红线共用，每题包含1与100的参考描述。
