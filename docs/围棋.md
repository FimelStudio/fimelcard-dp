# 围棋

落子围地、连接做活，提走没有气的敌方棋子。支持 **13×13、15×15、19×19** 棋盘，四人桌和八人桌均适配，经典、木色两种棋盘，黑白圆形棋子复用五子棋资源。

游戏编号 **20**，命名空间 `weiqi`，状态前缀 `go_`。支持 **1～2 名真人**：单人自动匹配基础人机，双人对弈正常操作无需 OP。19 号保留。

## 开始与操作

1. 腾空快捷栏**最后一格**，入座后选择「围棋」。默认按座位选黑白，黑先；棋盘方向为黑方南侧时，四人桌黑 3／白 1，八人桌黑 5～6／白 1～2。调整为黑方西侧时，四人桌黑 4／白 2，八人桌黑 7～8／白 3～4。
2. 轮到自己时右键空交点落子，可开启「同点两次确认」。19 路点击不准时，手持最后一格菜单按 **Q**，用「坐标落子」选择交点。
3. 棋盘坐标跳过 **I**：13 路 A～N、15 路 A～P、19 路 A～T，数字从黑方近侧的 1 向对面递增。落子在聊天记录中公开，棋盘可显示最后一手标记。
4. **Q 菜单**提供停一手、查看／关闭占地、悔棋、认输、规则与计分操作。双人悔棋须对方同意；人机悔棋撤回到真人上一手之前，已回复时一起收回电脑的一手。

随机分边会自动调整座位；按座位模式下双人需两侧各坐一人，单人可坐任一侧，电脑执另一方。开局后设置锁定。

## 占地、计分与复盘

**中局查看占地**是局部影响的保守估算：显示邻近且明显更接近某方的区域，双方影响接近或较远的点保留为未定，不自动判断死活。菜单显示估算面积与白方贴目；标记同步显示在本桌棋盘，下一手后自动清除。估算可在设置中关闭。

**双方连续停一手**进入终局计分，暂停棋钟：

1. 右键棋子，整组标记为死子，再点取消。红色标记只用于计分，不提前删除实际棋子。
2. 计分时把已标死的棋子视为空点，按棋子与围空面积重新计算；每次修改死子都会清除双方之前的确认。
3. 双方在菜单中确认结果后结束；单人局由真人确认。若有争议，可点「继续下棋」，取消死子标记并恢复原棋形、回合和棋钟。

终局计分与中局估算采用不同算法。**正式面积 = 盘上活子 + 只与己方颜色相邻的连通空域**；两色共同接触的空域为中立。白方另加贴目，提子数量仅作记录，不再加一次分。无需自行移子填空数目。

结束五秒后返回大厅，保留终局。原参与者仍可通过最后一格 **Q** 菜单打开复盘，查看首手、上一手、下一手、末手或自动播放；关闭后恢复末帧。复盘保留原棋谱，新开局、切换游戏或更换棋盘大小后清除。

## 本包规则

- 黑方先行，双方轮流落在空交点，或选择停一手。
- 横竖相连的同色棋子组成一组，邻接空点为气。落子后先提走邻接的无气敌组，再检查己组是否有气；无气且未因提子获得气的落子非法。
- 采用**位置超级劫**：落子后的完整棋形不得重复本局当前分支之前出现过的棋形；停一手不受这项限制。悔棋会一起回退历史，复盘不会改写棋谱。
- 连续停一手后由双方确认死活与面积结果；确认前可继续对弈。默认白贴 **7½ 目**，可调整或不贴目。
- 超时或认输判对方获胜。玩家离线、桌边结束投票通过或管理员中止时提前结束并保留当前棋面，不追加胜负。

本包使用面积计分、禁自杀与位置超级劫的组合。规则背景可参阅[英国围棋协会规则比较](https://www.britgo.org/rules/compare.html)、[面积计分与超级劫说明](https://tromp.github.io/go.html)及[英国围棋协会面积计分赛事说明](https://www.britgo.org/mso19x19)；具体操作和终局确认以本页所列实现为准。

## 设置

设置集中在同一页，点击立即生效；默认项加粗。

| 设置 | 选项 |
| --- | --- |
| 棋盘大小 | 13／15／**19** 路 |
| 配色 | **经典**／木色，棋子固定黑白 |
| 方向 | **黑方南侧**／黑方西侧 |
| 黑白分配 | **按座位**／随机 |
| 每人计时 | 无限制、5、**10**、15、20、25、30 分钟 |
| 白方贴目 | 0、5½、6½、**7½**、8½ 目 |
| 基础人机 | 简单、**普通**、困难 |
| 坐标／最后一手 | 默认开启，可分别关闭 |
| 落子确认 | 默认一次落子，可改同点两次确认 |
| 查看占地 | 默认允许，可关闭中局估算 |

基础人机使用合法落子、提子、气与局部形状等规则策略，适合练习。思考计入它自己的时间；落子动画、终局计分与复盘期间暂停棋钟。真人获胜时使用内置 SK Firework 烟花，落子、提子、停手等配有原创短音效。

## 管理命令

在桌旁由有命令权限的玩家中止同维度 8 格内最近一场围棋：

```mcfunction
/function weiqi:admin/abort
```

指定桌号（将 `12` 换成目标桌号）：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=12,ct_game=20,ct_state=1},limit=1] at @s run function weiqi:game/abort
```

建桌、删桌及 Debug 见[根 README](../README.md)。`/reload` 保留棋形、回合、棋钟、死子标记与终局确认，恢复座位和显示，旧窗口按 Q 重开。

## 资源与性能

棋盘仅 **1 个客户端交互实体**，只在点击时定位交点；逻辑交点使用仅服务端存在的 marker，空盘不生成棋子展示。占地按需计算，同一行相邻同色空点合并为一条色带，关闭或落子后回收。复用现有几何，无新增运行时前置；资源和八段原创音效来源见资源包 `.source/weiqi/`。
