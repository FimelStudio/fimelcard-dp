# 赌命德州扑克

2～8 人的德州扑克牌淘汰游戏。用两张手牌和五张公共牌组成最佳五张牌，以左轮子弹代替筹码：弃牌立即开枪，摊牌失败者也要开枪，最后一名存活玩家获得整场胜利。

游戏编号 `2`，命名空间 `liars_holdem`。普通玩家无需 OP；5～8 人使用八座桌，座位可不连续。安装和建桌见 [README](../README.md)。

## 开局与局内操作

所有玩家清空九格快捷栏后开局。每局重建不含大小王的标准 52 张牌库，每名存活玩家发两张手牌，桌面生成五张背面朝上的公共牌；每人初始 1 发子弹、一次换牌机会。

轮到自己时，快捷栏第 8、9 格出现 Call 和 Fold 操作物品：

| 操作 | 按键 | 效果 |
| --- | --- | --- |
| 跟注 | 选中 **Call 按 Q** | 普通阶段增加 1 发；最终抉择或全押响应阶段跟随 ALL IN |
| 全押 | 主手选中 **Call 按 F** | 子弹直接变为 8 发，触发全押响应 |
| 弃牌 | 选中 **Fold 按 Q** | 退出当前牌局，立即按当前子弹数接受左轮判定 |
| 换牌 | 选中一张手牌按 **Q** | 合法时打开三选一换牌窗口，每局限一次 |

本游戏没有筹码、盲注、奖池或经济系统。

## 一局流程

| 阶段 | 普通跟注后子弹数 | 本阶段完成后 |
| --- | --- | --- |
| 第一次行动 | 1 → 2 | 翻开前三张公共牌 |
| 第二次行动 | 2 → 3 | 翻开第四张公共牌 |
| 第三次行动 | 3 → 4 | 翻开第五张公共牌 |
| 最终抉择 | 只能 ALL IN 或 FOLD | 有多人参与则摊牌 |

每阶段每人只能行动一次，不能自由增加子弹。行动按实际座位轮换，跳过已弃牌、死亡和空座；翻牌和开枪动画期间暂停操作。

任意玩家提前 ALL IN 后，全桌立即禁止换牌和普通加弹；其余未弃牌玩家只能跟随 ALL IN 或 FOLD。响应结束后仍有多人参与，则自动翻完公共牌并摊牌；若只剩一人未弃牌，该玩家直接赢得本局，无需继续翻牌或开枪。

## 三选一换牌

只能在前三个普通阶段轮到自己时使用，且全桌尚未有人 ALL IN。窗口显示三张真实候选牌，点击一张替换所选手牌；底部退出按钮默认选择第一张。

三张候选在窗口打开前即移出剩余牌库。未选两张和原手牌进入本局弃牌区，选中的牌成为新手牌；它们都不能被再次抽取。公共牌及其他人的手牌也不会成为候选。换牌不算本阶段行动，完成后仍要跟注、全押或弃牌。

## 摊牌与左轮

牌型从大到小：**皇家同花顺、同花顺、四条、葫芦、同花、顺子、三条、两对、一对、高牌**。同型按点数和踢脚牌比较，花色不分大小，完全相同则并列获胜。**A 固定为 14，不能作 1，A、2、3、4、5 不构成顺子。**

摊牌按座位顺序展示每人的真实最佳五张牌和排名；胜者免开枪，其他摊牌玩家按座位顺序以 8 发子弹判定。亮牌保留至全部开枪结束。

左轮有 8 个弹槽，每次只扣动一次扳机：

| 子弹数 | 判定 |
| --- | --- |
| 1～7 | 死亡概率为子弹数 ÷ 8 |
| 8 | 95% 击发死亡，5% 卡弹存活 |

结果在动画前由服务端锁定。FOLD 后空枪或卡弹者保留整场资格，等待下一局；死亡或离线者淘汰并释放座位。本局结束后，剩余玩家重新洗牌、恢复换牌机会并从 1 发开始；整场只剩一名存活者时返回大厅。

## 设置、命令与维护

游戏设置当前仅提供牌桌皮肤入口，没有玩法参数。一般行动通过 Q、F 完成；以下 trigger 仅在对应窗口已经打开时有效：

```mcfunction
# 换牌窗口选择第 1～3 张候选
/trigger lh_swap_pick set 1
# 规则窗口打开详细牌型说明
/trigger lh_help set 1
# 查看事件日志；关闭时将 add 改为 remove
/tag @s add ct.debug
# 中止距离自己 8 格内最近一张正在运行的德州牌桌并返回大厅
/function liars_holdem:admin/abort
```

需要精确指定牌桌时，先在入座状态用 `/scoreboard players get @s ct_id` 查询桌号，将下面的 `ct_id=1` 替换为实际桌号：

```mcfunction
/execute as @e[type=minecraft:marker,tag=ct.controller,scores={ct_id=1,ct_game=2,ct_state=1},limit=1] at @s run function liars_holdem:game/abort
/scoreboard players get @e[type=minecraft:marker,tag=lh.controller,scores={ct_id=1},limit=1] lh_state
```

`/reload` 保留当前牌局并修复摊牌布局，不会重新抽取已经锁定的开枪结果。玩家离线按淘汰处理，其余玩家继续；桌边结束投票会中止整场。

维护入口：[牌型判定](../data/liars_holdem/function/hand/evaluate.mcfunction)、[牌型说明](../data/liars_holdem/function/rules/hand_types.mcfunction)。卡牌复用资源包 `card:poker/*`。开枪表现入口为 `liars_holdem:gun/animation/start`，只能使用已锁定的 `lh_gun_result`，不能在动画中再次随机。

## 验收

重点复测三选一换牌不重复、提前全押与最终抉择、单人未弃牌直接胜出、完整平局、高号座淘汰和开枪阶段重载。公共牌初始朝下，按 3／1／1 翻开；两桌动画与清理应独立。[通用验收](验收清单.md)列出检查入口与多人场景。
