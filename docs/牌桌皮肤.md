# 牌桌皮肤

入座后点击“游戏设置”，直接显示当前游戏参数；页面顶部“牌桌皮肤 · 点击选择”打开皮肤子界面，选择默认或典雅后返回游戏设置。离开设置页不会保留尚未提交的参数。普通玩家通过 trigger 操作，无需 OP。仅大厅可切换，皮肤按桌保存，游戏开始、结束、重载均保留。

典雅采用用户提供的喵工坊 r2.2 模型：
- 中央：单腿去皮红树木原木桌，四人桌3×3、八人桌4×4。
- 四边：双扶手沙发，固定红色 #B02E26，朝向桌心，与原座位中心一致。
- 四角：现代天鹅绒小桌，对角分别放向日葵与夹竹桃花瓶。

仅复制所需模型与非原版纹理至card命名空间，无需额外启用喵工坊资源包或调用其放置逻辑。家具属于ct.part和本桌ct_id，移除牌桌时统一清理，不会被发牌动画清理误删。

切换皮肤更换中央桌面方块与座椅外观，保留座位交互实体和乘坐玩家。典雅桌面使用隐形碰撞方块；恢复默认、移除牌桌时恢复默认木桌，避免留下隐形障碍。自定义桌面在主动选择典雅后也会改成标准桌面，切回默认恢复标准木桌。

客户端更新card资源包并F3+T，服务端/reload。未实机检查的项目：模型视觉朝向、花瓶遮挡、不同光影下效果；建议分别在四人桌和八人桌测试默认→典雅→默认，以及已入座玩家保持、切换游戏、结束游戏和重载。
