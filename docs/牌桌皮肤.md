# 牌桌皮肤

入座后点击“游戏设置”，直接显示当前游戏参数；页面顶部“牌桌皮肤 · 点击选择”打开皮肤子界面，选择七种皮肤之一后返回游戏设置。离开设置页不会保留尚未提交的参数。普通玩家通过 trigger 操作，无需 OP。仅大厅可切换，皮肤按桌保存，游戏开始、结束、重载均保留。

典雅采用用户提供的喵工坊 r2.2 模型：
- 中央：单腿去皮红树木原木桌，四人桌3×3、八人桌4×4。
- 四边：双扶手沙发，固定红色 #B02E26，朝向桌心，与原座位中心一致。
- 四角：现代天鹅绒小桌，对角分别放向日葵与夹竹桃花瓶。

仅复制所需模型与非原版纹理至card命名空间，无需额外启用喵工坊资源包或调用其放置逻辑。家具属于ct.part和本桌ct_id，移除牌桌时统一清理，不会被发牌动画清理误删。

切换皮肤更换中央桌面方块与座椅外观，保留座位交互实体和乘坐玩家。典雅桌面使用隐形碰撞方块；恢复默认、移除牌桌时恢复默认木桌，避免留下隐形障碍。自定义桌面在主动选择典雅后也会改成标准桌面，切回默认恢复标准木桌。

客户端更新card资源包并F3+T，服务端/reload。未实机检查的项目：模型视觉朝向、花瓶遮挡、不同光影下效果；建议分别在四人桌和八人桌测试默认→典雅→默认，以及已入座玩家保持、切换游戏、结束游戏和重载。

## 新增五套皮肤

- **电子音乐**：磨制黑石桌面、青蓝沙发，四角分别为调音台、舞台音箱、抹茶芭菲和效果器。
- **玩偶乐园**：樱花木木板桌面、粉色沙发，四角卡比与Fumo玩偶。
- **欧式复古**：深色橡木木板桌面、棕色沙发，欧式茶几配台灯与留声机。
- **竹影茶室**：竹马赛克桌面、竹木扶手椅，四角竹盆栽与团状多肉盆栽。
- **春日花园**：去皮白桦原木桌面、薄荷绿扶手椅，四角雏菊与向日葵。

五套均沿用四人桌3×3、八人桌4×4桌面与原座位中心。四角模型按真实旋转后的边界缩放，不新增家具交互实体；模型、纹理和两个图集均已加入card资源包。
皮肤编号2至6；旧默认0、典雅1保持不变。切回默认及移除牌桌恢复碰撞方块，座椅补全逻辑不会再生成默认椅覆盖新皮肤。
资源清单见《牌桌新增皮肤资源.json》，可用tools/build_table_themes.mjs重新生成家具资源及布局。

默认：原木色桌面与桦木椅。皮肤选择窗口仅显示当前皮肤名称及选择按钮，搭配介绍仅保留在本文档中。

五套新增桌面均取消羊毛桌布，分别使用黑石、樱花木板、深色橡木板、竹马赛克、去皮白桦原木纹理。春日花园和竹影茶室座椅修正180度；旧展示实体在重载或区块加载后自动修正一次，不重建座位交互。

抹茶芭菲保留玻璃透明贴图与内部不透明甜品，导入时将玻璃元素排在甜品之后，避免杯壁先写入深度遮挡内容物；需实机确认透明排序效果。

抹茶芭菲模型整体上移0.05格，避免杯底与角桌表面重叠；F3+T可更新现有展示实体。
