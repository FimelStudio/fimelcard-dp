# 牌桌结束恢复排查

检查十款游戏的结束投票、正常结束、清理和延时返回路径。

- 出包魔法师：已修复重复投票重置120刻结算计时；状态3拒绝再次结算。
- 赌命德州扑克、花火：发现 cleanup 在 ct_state 仍为1时调用 recount_players，后者复查已通过票数，再次进入 cleanup；修复为清理完成后先设 ct_state=0，再统计人数并恢复菜单。正常结算分别已有状态17、3的防重复保护。
- Fast Card、瞎掰王、谍报风云、临界点、问非所答、骷髅牌：投票走同步清理并返回大厅，未发现同类循环或计时重置。
- 斗地主：投票直接 abort 返回大厅；正常结算先锁定状态4，100刻后续局或整场结束，未发现同类问题。

验证：check_table_end_reentry.cjs 基于实际函数中的状态与调用顺序，复现德州扑克/花火旧路径递归，并确认新路径一次清理和一次返回；check_abraca_finish.cjs 验证重复投票不重置结算计时。此为代码路径检查，未进行十款游戏的完整联机实测，不代表排除所有卡桌原因。
