# 问非所答接入说明与验收

游戏编号8，命名空间wenfei，前缀wq。支持现有四座牌桌的2至4人，不新增资源模型。

## 默认规则与操作
- 2人局每人猜3次，共6轮；3人局每人猜2次，共6轮；4人局每人猜2次，共8轮。
- 本桌设置可调整两类人数下的每人次数（1至6次），默认值按上述规则。
- 六类各100道原创题，共600道。类别：玩家、数字、动物、食物、物品、名人。题库维护：data/wenfei/function/deck/catalog.mcfunction。
- 每轮从所选类别的100道题中随机抽出5道不重复候选题，顺序和正确题随机；不同轮允许重复抽题。
- 第一位猜题者随机，此后按实际入座的座位顺序轮换，跳过空座。
- 猜题者在对话框选择类别，关闭后可手持紫色染料按Q重开；仅此阶段发放，选定后立即按桌号回收库存和地面上的工具；其他玩家秘密看题，在书与笔第一页填写答案，完成后按Q，不签名。
- 全员答案锁定后在聊天栏统一公开。猜题者在聊天栏依次查看5道候选题，手持评分染料按Q给每题分配唯一的0至4分位置。白色0分、浅蓝1分、黄绿2分、黄色3分、红色4分。
- 每放一题即锁定并揭示下一题，不能提前看完整候选表，也不能修改已放位置。
- 正确题所在位置即得分。结算后自动进入下一轮；最后一轮结算后直接公布最终名次。最高分并列获胜。
- 全部回答提交后，在猜题者左上角显示玩家名和回答，每个回答每页两行、每行36字符，长答案每5秒翻页；下一轮清空。桌面显示轮数、阶段、座位累计分数。
- 每张候选题只播放公共牌背动画，不向其他人显示私有题目。
- 左上角复用谍报风云的BetterTitle文字库，每人独立面板，结束时恢复进入游戏前的面板；类别选择、规则与设置使用对话框。

## 生命周期和隔离
阶段1选类别、2秘密回答、3逐张评分、4结算（立即自动进入下一轮）。题目、正确题、答案和排列保存在本桌控制器的data.wenfei中。
题库为共享只读数据，界面与抽题storage仅供同步调用暂存。
每次阶段或候选题变化都会更新交互序号；旧聊天按钮、旧题目染料、非猜题者评分、重复位置和已锁定答案不能重复提交。
工具带wenfei自定义数据与桌号；处理时检查丢出者、桌号、身份和阶段。
重载仅安装与载入题库，不中止、重抽或重置活跃对局。
掉线或离开会在低频维护中结束本桌；重新上线的旧玩家由通用离线清理移除残留状态。
正常结束、投票结束、管理员移除都清理专属物品、掉落物、计分板和公共动画后返回大厅，不删除方块牌桌。

## 自动检查
运行：node tools/check_wenfei.mjs
包含函数引用及结构、600题唯一性、600种计分排列、所有2至4人座位组合与起始座位、设置编码、权限与交互序号检查、隐私展示入口和全量注册检查。
自动检查不替代真实Minecraft命令解析与联机实测。左上角沿用现有BetterTitle数据包及配套字体资源。

## 游戏内验收清单
- [ ] 2人、3人、4人分别完成默认局数，每人次数相等；不连续座位也能正确轮换。
- [ ] 1人拒绝开始；未清空快捷栏时拒绝开始，原物品不受影响。
- [ ] 六个类别均可选，每次五题不重复，每个0至4分位置仅可用一次。
- [ ] 猜题者看不到秘密题和尚未揭示的候选题；答题者提交齐全前不公开任何答案。
- [ ] 空书、额外页面和误签名处理正确；提交后重复按Q不能更改答案。
- [ ] 只有选类别使用对话框，关闭后紫色染料按Q重开；其他游戏阶段使用聊天栏。旧类别按钮和旧染料不能跨阶段使用。
- [ ] 评分阶段获得五种带分数名称的染料；Q丢出后立即锁定并换下一题，已用分数不再发放；连续丢两种染料不能跳过两题。
- [ ] 旧题目染料、转交他人和跨桌丢出均不能评分；评分结束及中止清除评分染料。
- [ ] 每轮结算后无需准备立即轮换；最后一轮直接公布总排名，旧准备按钮无效。
- [ ] 正确题分别放入0至4分，得到对应分数；累计和终局并列名次正确。
- [ ] 设置保存、取消、非法值、离桌与切换游戏后的旧设置提交正确处理。
- [ ] 在四个阶段分别执行/reload，题目、顺序、分数、答案和进度保持不变。
- [ ] 每个阶段测试掉线、结束投票及管理员移除，返回大厅且不残留专属物品或计分板。
- [ ] 两桌相邻同时答题、评分、结算，一桌中止或改设置不会影响另一桌。
- [ ] 左上角仅在全部答案公开后向猜题者显示；长回答含换行、引号和中文时分行及翻页正常，连续评分不清空回答。
- [ ] 下一轮、终局、中止、离线后清除回答面板并恢复此前面板；两桌回答不串桌。
- [ ] 重载清理旧提示工具，选类别阶段只给猜题者补发紫色染料并打开对话框；其他阶段不发紫色染料，恢复聊天提示及剩余评分染料。
- [ ] 公共牌背动画不被拾取，结束后不残留；桌面计分板仅显示公开信息。
