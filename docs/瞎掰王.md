# 瞎掰王

3～8 人的冷知识与身份猜测游戏。每轮一名“大聪明”通过提问寻找知道真相的“老实人”，其余“瞎掰人”编出可信解释争取被选中。每人担任一次大聪明后，累计分数最高者获胜。四座桌最多 4 人，5～8 人使用八座桌。

游戏编号 `5`，命名空间 `bullshit`。普通玩家无需 OP；开始前腾空快捷栏第 8、9 格，供阅读、质疑和指认道具使用。座位可不连续，安装和建桌见[README](../README.md)。

## 玩法与操作

1. **阅读 20 秒**：系统随机抽取题目，所有人查看词语与关键词，仅老实人立即知道身份并能查看私密答案。紫色染料按 Q 可重开阅读窗口；计时结束后回收工具、公布大聪明，并私下通知其他身份。
2. **自由问答**：通过聊天或语音交流。老实人依据真相解释，瞎掰人依据关键词编造；大聪明通过追问作判断。
3. **可选质疑**：大聪明手持“净他喵扯淡！”纸张按 Q 选择目标，每轮最多使用一次。目标身份到结算时揭晓。
4. **指认**：大聪明使用绿色染料“结束问答并指认”，按 Q 选择认为是老实人的玩家，随后公开身份并计分。
5. **轮换**：第一名大聪明随机产生，之后按座位顺序轮换、跳过空座。每人完成一次后公布总分。

私密答案不会写入聊天记录，阅读阶段结束后不能重新查看。当前没有可调整的游戏参数，“游戏设置”仅提供通用牌桌皮肤入口。

## 计分

| 结果 | 分数变化 |
| --- | --- |
| 指认老实人 | 大聪明、老实人各 +1 |
| 指认瞎掰人 | 被指认的瞎掰人 +1 |
| 质疑打中瞎掰人 | 大聪明 +1，目标 −1 |
| 质疑误打老实人 | 大聪明 −3，老实人 −1 |

指认与质疑的分数分别结算，可以叠加。题目与身份在每轮重新产生；已用题目没有整场去重限制。

## 管理与中断

以下命令需要命令权限，操作同维度 8 格内最近一场本游戏，无需填写桌号；指定桌号和 Debug 见[主说明](../README.md)。

```mcfunction
# 查看本桌轮数
/scoreboard players get @e[type=minecraft:marker,tag=bw.controller,distance=..8,sort=nearest,limit=1] bw_round

# 中止附近最近一场瞎掰王并返回大厅
/function bullshit:admin/abort
```

`/reload` 保留对局并恢复当前阶段。参与者离线会中止本局，也可使用桌边“结束游戏”投票。

维护题目时同步[题目与关键词](../data/bullshit/function/question/show.mcfunction)、[等待窗口](../data/bullshit/function/question/waiting_dialog.mcfunction)及[私密答案](../data/bullshit/function/question/answer_dialog.mcfunction)。角色和功能牌使用资源包 `card:bullshit/*`；阅读窗口只允许在阅读阶段重开。

## 验收

运行 `node tools/check_bullshit_reading.mjs`。人工检查只有老实人可读答案、阅读到期后无法重看、每轮质疑仅一次、四项计分叠加，以及 3～8 人和稀疏座位完整轮换。重载不得重抽当前题目、重开阅读计时或补回已用质疑；两桌答案应独立。[通用验收](验收清单.md)另列中止与清理场景。
