# Fimel Cards v1.1 更新日志

整理日期：2026-11-12。本稿对应 **Minecraft Java 26.2**，数据包与配套资源包需要同步更新。

相较 v1.0 的十款游戏，本次新增 **13 款游戏，总数增至 23 款**。揭棋属于中国象棋的玩法变体，蛛丝与红线属于命悬一线的两种模式，不另外计数。

## 新增

### 13 款游戏

| 游戏 | 真人数量 | 主要内容 |
| --- | --- | --- |
| UNO | 2～8 人 | 经典 108 张牌，支持喊 UNO、抓漏喊、变色选色、+4 质疑，以及单局、固定局数或目标积分赛。 |
| 国际象棋 | 1～2 人 | 单人三档人机或双人对弈，支持合法走格提示、计时、升变、王车易位、吃过路兵、悔棋、和棋与认输。 |
| 中国象棋 | 1～2 人 | 标准象棋与揭棋，支持三档人机、合法走格提示、计时、悔棋、和棋与认输。 |
| 五子棋 | 1～2 人 | 13×13、15×15、19×19 三种棋盘，自由五子棋、暂无禁手，支持三档人机、计时与悔棋。 |
| 飞行棋 | 1～4 人 | 四色四机，支持投骰翻滚、逐格飞行、跳格、飞跃、撞机、排名及电脑补位开关。 |
| 阿瓦隆 | 5～8 人 | 隐藏身份、队长组队、秘密表决、任务执行与刺杀梅林，仅支持八人桌。 |
| 情书 | 2～6 人 | 21 张角色牌，摸一出一，通过猜测、比较、保护、交换与淘汰累计好感。 |
| 掼蛋 | 1～4 人 | 双副牌对家合作，支持级牌、逢人配、炸弹、贡还、抗贡、接风和升级过 A；空位可由测试人机补齐。 |
| 命悬一线 | 2～8 人 | 140 道主题；蛛丝模式合作排序闯关，红线模式互选搭档配对抢分。 |
| 围棋 | 1～2 人 | 13×13、15×15、19×19 棋盘，支持基础人机、提子、超级劫、占地估算、死子确认、数子和复盘。 |
| 卡坦岛 | 2～4 人 | 六边形岛屿、投骰生产、玩家交易、银行与港口兑换、修路建村、城市、强盗和开发牌。 |
| 璀璨宝石 | 2～4 人 | 收集六类筹码，购买或预定发展卡，积累永久折扣并吸引贵族；15 分触发最后一轮。 |
| 胡闹运动会 | 2～6 人 | 招募 36 名能力各异的选手，在普通／狂野赛道投骰竞速，四场累计积分争夺总冠军。 |

四人桌最多容纳四名真人，五人及以上游戏请使用八人桌。斗地主、掼蛋可用人机补位；国际象棋、中国象棋、五子棋、围棋和飞行棋支持单人开局。飞行棋关闭电脑补位时至少需要两名真人。

### 牌桌与通用系统

- 新增游戏图标选择界面，悬停即可查看名称和人数要求。
- 新增椅子数量设置。四座桌和八座桌可按当前游戏人数减少椅子，并保留已经入座的座位；切换游戏时会自动补足最低人数。
- 全部游戏接入统一的单页设置和规则说明。选项点击立即生效，数字可直接加减。
- 任一本局参与者离线时整桌暂停，冻结规则推进、计时、人机、发牌与动画；原参与者返回后继续。等待期间仍可投票结束或由管理员中止。
- 23 款游戏均支持 `/function <命名空间>:admin/abort`，可中止附近对应游戏并保留牌桌。
- 新增完整卸载入口 `/function cardtable:admin/uninstall`：结束所有已加载牌桌的游戏、回收在线玩家道具与界面，删除已加载功能实体、延迟任务、计分板并清空游戏及内置库的 storage 内容；完成后移除数据包即可，重新放回并 `/reload` 可全新安装。原版命令不能直接处理离线玩家或未加载区块，卸载前请让参与者上线并加载牌桌区块，等待“卸载完成”提示后再移除文件。
- 新增按桌保存的背景音乐开关、操作提示、公开信息 HUD、错误原因提示和重要事件 subtitle；各游戏按信息的重要程度使用聊天栏、actionbar、subtitle 或 BetterTitle。

### 直接桌面交互

- **卡坦岛立体棋盘**：新增立体树木、羊群、麦田、岩层矿洞、仙人掌和带帆船的港口；数字与港口比率保持朝上并按各玩家视角转向，发展牌堆移到海域外桌角，修正与棋盘重合。

- 卡坦岛支持 **2～4 名真人**，同步调整开局校验、选游人数提示和最低椅子数量。双人局沿用现有地图与基础流程。

- **璀璨宝石**不再使用操作窗口。右键宝石选择三色，或再次右键同色拿两颗；右键发展卡两次购买，买不起时第三次确认预定，右键牌堆两次可盲预定。贵族满足条件后自动来访，多个贵族可直接在桌面选择。
- **胡闹运动会**改为桌面招募、角色物品出场、骰子与技能目标直接操作；常用选择按一次 Q 生效，仅大量候选能力保留必要窗口。
- **卡坦岛**使用快捷栏建筑、投骰、银行、交易和开发牌道具。手持村庄、道路或城市后右键／Q 瞄准棋盘位置，预览后确认；弃牌、银行兑换、垄断、丰收和旧开发牌均可直接操作。
- **情书**的手牌直接放入前两格，卡名后附效果概括。需要指定玩家时朝向目标后按 Q 出牌，合法目标会发光，受侍女保护者不可选；王子可低头或不朝向他人时对自己使用。仅侍卫猜牌和大臣留牌打开必要窗口。
- 操作物、卡牌和资产使用服务器状态作为准确信息，丢出、移动或死亡掉落后会恢复；不会因拖动物品复制资产，也不会覆盖普通物品。

### 展示、模型与反馈

- 璀璨宝石重做发展卡、贵族卡、游戏图标和市场布局。棋盘每回合朝向当前玩家；宝石与牌堆库存固定显示，买得起的牌以牌外细小绿光提示。
- 璀璨宝石 BetterTitle 按每位玩家自己的视角排序，本人固定在左上角；显示筹码、永久折扣、分数、发展卡、贵族和预定数量，四人局左右各两人。
- 胡闹运动会 36 名选手全部改为各不相同的立体棋子，招募、比赛和手持使用独立姿态；棋子上方以 vertical 精灵图显示所属玩家的皮肤头像，棋盘上方显示玩家、角色和积分，行动者名字右侧显示箭头。
- 胡闹运动会新增连续移动、技能目标粒子、回合／能力／状态／得分提示，以及包含双方玩家名和角色名的聊天记录。骰子只发给当前能够投骰的玩家。
- 情书新增牌盒剩余牌数、桌面姓名与好感显示、公开弃牌、轮末全员摊牌、角色粒子与音效，以及“谁对谁使用了什么牌”的聊天记录。
- 卡坦岛 BetterTitle 显示公开分数、资源总数、发展卡总数、道路与骑士信息；本人额外看到五类资源明细和含隐藏胜利点的实际分数，其他人的资源种类与隐藏分数保持保密。行动者名字右侧显示箭头。
- 卡坦岛新增建造、投骰、资源生产、交易、强盗、开发牌与胜负反馈；可选目标使用发光或粒子提示。建筑、道路、城市及与飞行棋共用的骰子重做手持大小、角度和第一人称位置。
- 斗地主新增不洗牌模式和桌面出牌展示；骷髅牌新增八套花牌与糖骷髅主题牌面。花火操作调整为 **Q 出牌、F 弃牌**。
- 出包魔法师补充当前行动玩家显示；阿瓦隆、谍报风云等游戏继续完善直接选择、流程提示和隐私展示。

## 修复

- 修复卡坦岛发展牌堆与棋盘海域重合：四人桌、八人桌及两种朝向均改为海域外桌角的立体牌堆，折叠厚度、离桌高度与点击区域同步调整。

### 交互与规则

- 修复情书打出侍卫后牌已消耗，但猜测窗口要到再次 Q 剩余手牌才打开的问题。现在会在出牌回收完成后的下一刻自动打开；大臣的连续选择采用相同处理。
- 修复情书持有女爵与王子／国王时，违规打牌没有明确反馈的问题；无法出牌、没有朝向合法目标或目标受保护时会在 actionbar 说明原因。
- 修复情书结束后大厅仍残留“情书 第几轮”等桌面文字的问题，并完善牌盒余量文字的清理和字号。
- 修复璀璨宝石购买部分发展卡时扣除数量错误的问题，费用现在按每种宝石分别结算，并准确计入永久折扣与黄金。
- 修复璀璨宝石发展卡超过快捷栏空位后的显示问题。宝石固定占前六格，预定牌占后三格，已购发展卡与贵族放入背包；背包满时资产继续保存在服务器中，腾出空间后补回。
- 修复卡坦岛在银行兑换、城市升级、购买开发牌等失败操作中没有立即提示的问题。材料不足、比例不符、银行缺货、未投骰、非本人回合和目标非法均会说明具体原因。
- 修复部分本来只需一次 Q 的开发牌、资源选择和技能仍要求重复确认的问题；购买、结束回合和建筑落点等高影响操作继续保留二次确认。
- 修复离线期间投票结束后牌桌卡住、重连残留旧局身份或操作物的问题。

### 显示、模型与动画

- 修复胡闹运动会部分立体棋子变成黑紫色方块的问题：移除裁剪后没有任何可见面的模型元素，同步修复生成脚本与可编辑源文件。
- 修复胡闹运动会棋子上方标识被错误缩到不可见的问题，玩家头像现在随棋子移动、朝向观察者，同格拥挤时缩小，淘汰时隐藏。
- 璀璨宝石左右 BetterTitle 信息整体下移一行，避免最上方玩家信息贴住屏幕边缘。
- 修复情书牌盒盒盖“LOVE LETTER”文字镜像的问题，按物品展示实体的实际渲染旋转修正朝上面的纹理坐标。
- 修复璀璨宝石 BetterTitle 各行错位、四人信息堆叠、标题占位和不同视角排序不一致的问题。
- 修复璀璨宝石宝石数量、牌堆数量文本漂移或未随棋盘方向变化的问题；标签现在固定在对应物体附近并保持竖直朝向。
- 修复璀璨宝石卡牌手持位置、大小和朝向异常，以及商人／贵族牌人物下方出现纯色长方形的问题。
- 修复胡闹运动会棋子陷入棋盘、移动卡顿、棋盘或棋子刷新时短暂消失的问题。移动改为相邻格心间连续插值，刷新复用现有实体。
- 修复胡闹运动会比赛过程中棋盘中央偶尔闪现旧圆饼棋子的问题；旧事件徽章不再生成，事件文字、粒子、音效和计分继续保留。
- 修复魔术师、浪漫家等立体棋子因模型方块和共面重叠产生闪烁的问题；36 个模型统一清理内部面、重叠体积和共面冲突。
- 修复胡闹运动会角色信息物品、卡坦岛建筑／道路／城市、璀璨宝石发展卡及共用骰子的手持显示异常。
- 修复卡坦岛和胡闹运动会中提示不足、行动者不清楚、目标不明显的问题；补充姓名、行动、技能、移动、弃牌、交易、受击与胜负信息。
- 修复国际象棋、中国象棋随机阵营时玩家可能重叠坐到同一椅子，以及部分棋盘方向、坐标和棋子朝向问题。
- 修复多个游戏旧窗口、跨桌输入、过期选择和重复提交仍可能影响当前局面的问题。

### 更新与验证说明

- 本稿对应 Minecraft Java 26.2。Fabric 与钠已有作者实测记录；Forge、OptiFine、额外光影及覆盖字体或文字着色器的资源包组合仍需单独验证。
- 当前改动已通过各游戏的规则、流程、资源引用、物品组件、模型姿态和多桌隔离自动检查；完整真人联机、客户端画面、按键手感与音效仍应在正式发布前试玩。
- 更新时请同时替换数据包与配套资源包，进入世界执行 `/reload`，资源包更新后按 `F3+T`。安装、快捷栏要求和管理命令见[项目 README](https://github.com/FimelStudio/fimelcard-dp)，完整规则见[文档索引](https://github.com/FimelStudio/fimelcard-dp/blob/main/docs/README.md)。
