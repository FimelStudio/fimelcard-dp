适用 Minecraft Java **1.21.11**。本页汇总 **v1.0 → v1.1** 的主要更新，更新时请同时替换数据包和配套资源包。

## 新增

### 新增 13 款游戏，总数达到 23 款

在 v1.0 十款游戏的基础上，加入卡牌、棋类、推理、竞速和建设玩法。揭棋属于中国象棋的玩法变体，蛛丝与红线属于命悬一线的两种模式，不另外计数。

| 游戏 | 真人数量 | 主要内容 |
| --- | --- | --- |
| UNO | 2～8 人 | 经典 108 张牌，支持喊 UNO、抓漏喊、变色选色、+4 质疑，以及单局、固定局数或目标积分赛。 |
| 国际象棋 | 1～2 人 | 单人三档人机或双人对弈，支持计时、升变、王车易位、吃过路兵、悔棋、和棋与认输。 |
| 中国象棋 | 1～2 人 | 标准象棋与揭棋，支持三档人机、计时、悔棋、和棋与认输。 |
| 五子棋 | 1～2 人 | 13×13、15×15、19×19 三种棋盘，支持三档人机、计时与悔棋；自由五子棋，暂无禁手。 |
| 飞行棋 | 1～4 人 | 四色四机，支持跳格、飞跃、撞机、排名及电脑补位开关。 |
| 阿瓦隆 | 5～8 人 | 隐藏身份、队长组队、秘密表决、任务执行与刺杀梅林，仅支持八人桌。 |
| 情书 | 2～6 人 | 21 张角色牌，摸一出一，通过猜测、比较、保护、交换与淘汰累计好感；支持朝向选人与头颅精准选人。 |
| 掼蛋 | 1～4 人 | 双副牌对家合作，支持级牌、逢人配、炸弹、贡还、抗贡、接风和升级过 A；空位可由测试人机补齐。 |
| 命悬一线 | 2～8 人 | 140 道主题；蛛丝模式合作排序闯关，红线模式互选搭档配对抢分。 |
| 围棋 | 1～2 人 | 13×13、15×15、19×19 棋盘，支持基础人机、提子、超级劫、死子确认、数子和复盘。 |
| 卡坦岛 | 2～4 人 | 立体岛屿与港口，投骰生产、玩家交易、银行兑换、修路建村、城市、强盗和开发牌。 |
| 璀璨宝石 | 2～4 人 | 直接在桌面收集筹码、购买或预定发展卡，积累永久折扣并吸引贵族；15 分触发最后一轮。 |
| 胡闹运动会 | 2～6 人 | 36 名能力各异的立体选手，普通／狂野双赛道与配套音乐，四场竞速累计积分争夺冠军。 |

四人桌最多容纳四名真人，五人及以上游戏请使用八人桌。斗地主、掼蛋可用人机补位；国际象棋、中国象棋、五子棋、围棋和飞行棋支持单人开局。飞行棋关闭电脑补位时至少需要两名真人。

### 既有游戏扩展

- **斗地主**新增组队比赛、不洗牌模式、出牌提示和桌面出牌展示，补充人机与比赛流程。
- **谍报风云**新增可选阶段限时与倒计时，支持超时结算；完善三人局和多人局的流程提示。
- **花火**采用 Q 出牌、F 弃牌的直接操作，完善提示、弃牌查看与手牌信息展示。
- **骷髅牌**新增八套花牌和糖骷髅主题牌面。

### 统一牌桌与操作体验

- 新增游戏图标选择界面，显示各游戏名称与人数要求；游戏设置统一为单页选项，点击即可修改。
- 四座桌与八座桌支持调整椅子数量，并根据当前游戏与已入座玩家保留所需座位。
- **全游戏接入离线暂停**：参与者离线后整桌暂停，原玩家返回后继续；暂停期间仍可投票结束或由管理员中止。
- 情书、卡坦岛、璀璨宝石和胡闹运动会采用快捷栏与桌面直接交互，减少反复打开操作窗口；只有必要的猜测、选择等环节保留窗口。
- 补充回合、目标、费用不足、非法操作与胜负提示；通过聊天栏、actionbar、subtitle、持续信息面板和目标特效帮助玩家了解局面。
- 丰富棋盘、卡牌、立体棋子、动画和音效，并提供按桌保存的背景音乐开关。

### 管理与新手说明

- 23 款游戏均提供管理员中止入口，可结束附近对应牌局并保留牌桌。
- 新增完整卸载入口 `/function cardtable:admin/uninstall`，结束游戏并清理数据包运行数据，支持之后重新安装。
- 新增[23 款游戏的新手说明书与组件图鉴](../rules/README.md)：每游戏一份，详细介绍准备、回合、操作、结算及卡牌／棋子能力，并配有实际资源图片。

## 修复

- 修复离线、重连、投票结束与重载过程中可能卡住牌桌、丢失流程或残留旧局道具和身份的问题，完善牌局恢复与清理。
- 修复部分旧窗口、过期选择、重复提交和跨桌输入可能影响当前牌局的问题。
- 修正部分牌桌点击区域、座位与展示位置，改善文字面板、手持道具和桌面模型的显示。
- 完善操作物的回收与恢复，减少误丢、移动物品或死亡后无法继续操作的问题。
