# 从入座开始：新手共同操作

这些说明书默认你没玩过对应桌游。先完成下面的准备，再打开游戏页阅读目标、回合和图鉴；不需要开局前背会所有能力。

## 1. 准备一张桌子

每位玩家启用相同版本的配套资源包。管理员在空地执行 `/function cardtable:admin/create` 建四座桌，或 `/function cardtable:admin/create8` 建八座桌。桌面带座椅分别占 5×5、6×6；让桌子之间留出通道。安装细节见[主 README](../../../README.md)。

右键空椅子入座，在桌心切换游戏。开始前点“游戏设置”，选项通常点击就生效，不需要额外保存。超过四人的游戏用八座桌；阿瓦隆只能用八座桌。需要人机时先查看该游戏是否支持。

按游戏页要求腾空快捷栏，普通物品放进背包或箱子。比如情书默认需要前两格，卡坦岛和胡闹运动会需要九格。不要把游戏道具存进箱子或用创造模式复制；服务器保存的牌、资源和分数才是实际资产。

## 2. 常用词

| 词语                 | 意思                                                               |
| -------------------- | ------------------------------------------------------------------ |
| 一回合               | 轮到一人完成规定行动，之后轮到别人；能力可能改变顺序               |
| 一轮／一副／一场比赛 | 从发牌或布置开始，直到该次计分结束；具体以游戏页为准               |
| 整场                 | 多个小局或比赛累计的完整游戏，达到目标才返回大厅                   |
| 公开信息             | 所有人可以知道，例如已出牌、建筑、分数；可通过聊天讨论             |
| 秘密信息             | 只有有权查看的人能看，例如身份、暗牌；不得用第三人称或截图绕过限制 |

## 3. 按键速查

| 操作     | 用法                                                         |
| -------- | ------------------------------------------------------------ |
| 右键     | 准星对准桌面的卡、棋子、宝石、交点或按钮使用                 |
| 左键     | 在支持的游戏取消预选；不是把桌子拆掉                         |
| Q        | 默认“丢弃物品”键，持有游戏道具时代表打出、投骰、选择或确认 |
| F        | 默认主副手交换键，花火用来弃牌，德州扑克 Call 用来全押       |
| 潜行右键 | 特定快捷操作，例如璀璨宝石直接预定；其他游戏不要随意套用     |
| 朝向选人 | 看向玩家，确认目标高亮／姓名提示后使用需要目标的牌           |

改过键位时按自己设置的丢弃键、交换键。Q 后道具短暂离手是正常输入，等待系统处理，不要连按。两次确认指第一次选中、第二次执行；只有说明明确要求时才按两次。必要窗口关闭后，用当前游戏操作物重新打开。

## 4. 提示信息

| 位置                 | 什么时候看           | 常见内容                               |
| -------------------- | -------------------- | -------------------------------------- |
| 屏幕角落 BetterTitle | 随时查看             | 本人手牌、公开分数、资源总数、行动箭头 |
| 屏幕下方 actionbar   | 每次选择或失败后     | 已选目标、缺少什么、下一步该点哪里     |
| 中央标题／subtitle   | 轮到自己或重要事件   | 被淘汰、冲线、需要回应、胜负           |
| 聊天栏               | 忘了发生什么时向上翻 | 谁出牌、谁攻击谁、移动方向、骰值、计分 |
| 桌上发光／粒子       | 需要选择对象时       | 合法落点、能买的牌、当前预选、技能目标 |

发光不等于已经付款、已经出牌；仍需按本游戏要求确认。错误消息会暂时覆盖日常指引，看完后稍等就恢复。多人同时做秘密选择时，别人未提交也会阻止阶段推进。

## 5. 完整开局

1. 人数符合，全部入座并整理快捷栏。
2. 阅读游戏页“怎样获胜”和“准备”，在大厅决定可选规则。
3. 开始后先完成初始发牌、身份阅读或布置，不抢操作。
4. 看到自己的行动箭头／提示后，按“你的回合”执行。
5. 游戏要求回应时，即使不是自己的回合也要回应，例如弃牌、交易或投票。
6. 小局结束先看得分和下一局安排；整场结束再收起道具、返回大厅。

## 6. 卡住时按顺序检查

先看 actionbar：是否轮到你、是否还在动画、是否要完成一个必要选择、目标是否受保护、资源是否不足。窗口关了就用当前操作物重开；不要把同一窗口的按钮命令复制到下一回合。

出现紫黑方块、缺字或模型异常时，核对资源包版本和优先级，再按 F3+T。管理员更新数据包后执行 `/reload`。视觉重载不会让你重新抽牌、重新投骰或退回已经支付的资源。

本局有人离线会暂停整桌，原参与者全部上线后继续；下马不等于退赛，右键原座能坐回。想提前结束用桌边“结束游戏”投票。管理员可在目标桌 8 格内执行 `/function 游戏命名空间:admin/abort`；具体名称见各游戏页底部。命令会结束对应游戏并保留牌桌。
