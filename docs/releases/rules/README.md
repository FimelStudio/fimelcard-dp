## 图片怎么看

卡牌图片来自实际资源包正面，动画纹理展示第一帧；同牌面多张用数量说明，不重复画图。立体棋子、建筑、地形、骰子和棋盘由 Java 模型及原纹理直接渲染，属于资源实图，展示光照与 Minecraft 实机略有不同。卡坦岛完整棋盘沿用配套源文件的预览；展示用建筑不代表开局摆法。没有插画牌面的文字题目、动态姓名和私人窗口用操作步骤说明。

图片随文档保存在本目录，不依赖桌面文件。生成与图片来源见[图片说明](images/README.md)；开发维护资料仍在[仓库文档索引](../../README.md)。
