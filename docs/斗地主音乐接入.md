# 斗地主音乐

音频来自桌面“斗地主音乐”中的四个 WAV；资源包使用转换后的 OGG Vorbis，失败音频仅保留前三秒，源 WAV 未修改。
资源路径：assets/card/sounds/doudizhu；声音事件：card:doudizhu.normal、exciting、win、lose。
旧的音符盒曲谱和树形调度函数已删除，数据包仅负责播放、切换、循环及停止。

- 发牌、叫分和普通出牌：normal 循环，约28.97秒。
- 任一玩家（含机器人）剩余1–2张牌：exciting循环，约31.14秒。
- 每局结算：赢家win（约3.80秒）、输家lose（3秒），只播一次。
- 保持5秒结算等待；下一局重新播放normal，中止或离座清理时停止音乐。
- 游戏设置提供音乐开关，默认开启，按牌桌保存；关闭影响全部四首。
- 声音只发给本桌真人玩家，使用“唱片机/音符盒”音量。
- reload重新启动背景音乐；OGG按游戏刻计时循环，服务器卡顿可能增加曲间间隔。

应用：客户端更新资源包并按F3+T重载资源，服务器执行/reload。所有参与玩家都需要更新资源包。
