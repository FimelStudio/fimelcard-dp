# 加密提示的两种输入方式

执行 /reload 后，在牌桌大厅选择谍报风云，打开游戏设置，切换“提示输入方式”，保存后开局。每张牌桌独立保存，默认是书；对话框提交需要加密者具备执行 /function 的 OP 权限。

- 书：原有书与笔流程，三页对应三条提示，点击完成保存后按 Q 提交。原有书的长度规则保持不变。
- 对话框：加密者按 Q 丢出“填写电报提示”紫色染料。顶部显示本轮密码和己方词条，三个输入框的标签按密码顺序显示，例如 3、1、4。每条填写 1—24 个字符，关闭不保留草稿。常用汉字计一个字符；部分表情符号占两个 UTF-16 单位。
- 输入方式只在大厅修改；提交成功后沿用聊天栏、电报 Actionbar、敌方笔记和拦截/解密流程。

游戏内验收：

1. 分别用三人、四人局测试书模式与对话框模式，四人局覆盖白队和黑队加密。
2. 密码为 3、1、4 时，核对三个输入框标签；同队非加密者、另一队不能打开本队加密窗口。
3. 测试空输入、24 个汉字、引号和反斜杠；空项应拒绝，合法提示应原样写入电报。
4. 关闭后用染料重新打开，应为空白；提交旧窗口或已结束阶段的内容，不应再次进入解密。
5. 连续 /reload 后，书模式草稿保留，对话框模式染料可继续打开；已有对局和游戏设置不重置。
6. 普通无 OP 玩家使用书模式；对话框的提交按钮受 Minecraft 命令权限限制，不应以“无法提交”为由给普通玩家自动提升权限。

已提供静态检查：node tools/check_decrypto_prompt.mjs 和 node tools/check_reload.mjs。这些检查不代替 Minecraft 内实际操作验收。
