## 通用联机复测

- 四座、八座各建一桌，确认桌面、座位朝向、菜单、规则和结束按钮可用；安全注册不改方块，移除清理实体并保留桌面。
- 普通无 OP 玩家能切换游戏、保存设置、查看规则和正常操作；取消或重交旧窗口不能修改已切换、开局或离开的桌子。
- 测试各游戏最小、最大人数及越界拒绝。使用 1、8 号等不连续座位，确认发牌、轮换、目标选择、显示和计分均覆盖高号座。
- 结束投票每人只计一次，人数变化后重新统计。四座桌 2/3/4 人需 2/3/3 票；八座桌按严格过半计算。连续点击不能重复清理或重置结算计时，正常结束、中止后均可再次开局。
- 在发牌、输入、行动、投票及结算阶段连续两次 `/reload`：手牌、题目、身份、书稿、已提交操作、分数和原计时保留。离线按游戏规则处理，座位能补回；原玩家重进不产生重复空座或踢下现有乘客。
- 两桌同时发牌、提交、结算和中止，确认物品、按钮、提示、分数和清理不跨桌；旁观者不能代替参与者提交。
- 逐游戏执行 `/function <命名空间>:admin/abort`，确认仅中止同维度 8 格内最近一场对应游戏并返回大厅；无目标时提示，其他桌仍可继续。
- 客户端启用配套资源包，检查隐藏牌面、左侧面板、文字动画、烟花、家具朝向与透明材质。测试七种皮肤切回默认；表情与语音分别限流，语音仅同维度 16 格可听。

## 各游戏关键场景

| 游戏 | 重点 |
| --- | --- |
| Fast Card | 17 张按 5/4/4/4 发放；仅当前玩家可传牌；三种抢按计分、乱按开关、离线中止 |
| 赌命德州扑克 | 3/1/1 翻公共牌；选中 Call 按 F 全押；换牌不重复；弃牌即时左轮；最佳五张、完整平局及 A 不作 1；高号座淘汰后继续 |
| 花火 | 自己真牌始终隐藏；提示取消可重进、奖励必须完成；普通和彩色模式；牌库空后打完手牌；失败及最终烟花 |
| 出包魔法师 | 操作牌与后台真牌分离；施法顺序、伤害及邻座正确；胜者 +3、其余存活者 +1、猫头鹰奖励；跨局累计、同时达标及结束返回 |
| 瞎掰王 | 仅老实人阅读答案，问答阶段不能重看；每轮一次质疑、指认与四项计分；每人轮到一次大聪明 |
| 谍报风云 | 三人模式及 4～8 人分队；轮换、轮空权限；书/对话框输入；词条固定、笔记保密；达到设置轮数结束 |
| 临界点 | 表态后秘密出牌；安全轮公开单牌、危机轮仅公开总数；不可自投，平票狼人胜，五轮安全村民胜 |
| 问非所答 | 六类各 150 题，五候选不重复；答案齐全才公开；两种秘密输入；逐题唯一 0～4 分、长回答翻页及轮次 |
| 骷髅牌 | 首次同时扣牌；叫号可达 24；先翻自己且只翻堆顶；两种弃牌处理、永久失牌、两胜或最后存活 |
| 斗地主 | 1～3 真人补人机；三种叫地主，全不叫重发不耗局；手速时间边界；合法牌型与自动过牌到期复验；记牌器、多局累计、春天和音乐停止 |
