# 斗地主

在游戏设置选择**经典模式（3 席）**、**2v2（4 席）**或**4v4（8 席）**。至少 1 名真人即可开局，空缺自动补人机。4v4 限八座桌。54 张牌，每人 17 张，留 3 张底牌；地主获得底牌并先出牌。地主先出完则地主胜，任一农民先出完则两名农民共同获胜。

游戏编号 `10`，命名空间 `doudizhu`。四人桌、八人桌均可游玩，普通玩家无需管理员权限。

## 开局与操作

入座后在大厅选择“斗地主”，在“游戏设置”选择模式，点击“开始游戏”。开局前须腾空快捷栏第 9 格，用于操作道具。

- 轮到操作时，按 **Q** 丢出紫色染料打开手牌窗口；按钮在牌面下方，可向下滚动查看。
- 点击牌面选中或取消，金色边框表示选中；点击“出牌”“不出”或“清空选择”。关闭窗口保留选牌，轮到自己时可再按 Q 打开。「提示」从最小的合法应牌开始轮选，普通牌优先，炸弹和王炸排在最后；选中后点「出牌」提交。
- 普通跟牌须与上一手同型、同张数，且主牌更大；连续两人不出后，最后出牌者重新领出。
- 真人跟牌时若没有任何合法应牌，等待 100 游戏刻（正常 20 TPS 时为 5 秒）自动不出，也可提前手动不出。领出或有合法应牌时，按游戏设置里的每步时限处理。
- 桌边“规则介绍”可随时查看规则，窗口不会暂停牌局；通过“结束游戏”投票中止，以界面显示的票数为准。本局真人离线时整桌暂停，原参与者全部重连后继续；等待期间可投票中止。游戏中下马仍保留参与身份。

HUD 显示自己的手牌以及各方公开信息；对话框按点数排列，同点数叠放，每张牌可独立选择。叠牌保留灰色接缝，选中牌保留金边。

合法出牌后，牌面朝上放在出牌者的座位前，兼容两种桌型和人机。面向牌面阅读时大牌在左、压在小牌之上；每行最多 10 张，第二行向桌心排列。自己再次出牌或不出时清理原展示，新一轮领出时收清桌面；终局最后一手保留到结算结束。

## 四人组队

橙队和青队各两人，正对座位固定为队友。真人须坐在同两对对座内，剩余席位由人机补齐。轮空玩家可看同桌三人的公开出牌。2v2 确定地主后，轮空者的 HUD 会切到地主视角，显示地主手牌供观战。

首局随机选一人轮空，从其下一座开始，给其余三人各发 17 张牌并依次叫分。每结算一局，叫分轮空者按座位顺序换到下一人。全员不叫时本副流局，记 0 分并进入下一副，叫分轮空者照常轮换。

确定地主后，地主的队友轮空。若该队友已经拿牌，整副手牌交给原先轮空的对手，两名对手成为农民。地主得 3 张底牌并先出牌。出牌照常按座位顺序进行，跳过轮空者。

分数制每副只给胜队加分，得分为叫分乘实际倍数。炸弹、王炸、春天和反春天照常翻倍。赢副制每副胜队得 1 分。两队各自累计，分高的一队获胜，同分为平局。

## 八人双桌赛

八座桌选择 4v4 开局后，按顺时针四边依次为红1／红3、蓝2／蓝4、红2／红4、蓝1／蓝3。奇数座组成甲桌，偶数座组成乙桌。每个分桌都沿用四人组队的地主换人规则。确定地主后，轮空玩家可在 HUD 只读观看所在分桌的地主手牌。

两桌共用发牌动画，各自按相同牌序发牌，动画结束后同时叫分。首副分别由红蓝红、蓝红蓝叫分。每副结算后，两桌各自按座位轮换叫分轮空者。一桌全员不叫时流局，记 0 分，另一桌继续。两桌都流局时直接进入下一副，两队均记 0 分。

每桌胜队按叫分乘实际倍数得分。两桌打完后比较双方在两桌的得分。聊天按桌显示得分队伍及正分。红方领先则红队得分，蓝方领先则蓝队得分。分数制每副最多得12分。赢副制只给分差领先的一队1分，同分各得0分。打完规定副数后若累计同分，则双桌继续加副，直到有分差。

游戏设置可选择只在比赛结束时公布累计比分。该模式在约四分之三的副数结算后暂停发牌，每位真人用一种染料预测己方此时领先或落后的分差。领先和落后各分 0～6、7～12、13～17、18+ 四档。真人全部交齐后，各自私下收到正确或错误的提示，然后继续下一副。背包空位不足时可用私密窗口，关闭后可用 /trigger dd_action set 300 重开。平分时两个 0～6 档都算正确。短赛会把预测安排在末副前，单副赛直接公布最终结果。

## 叫地主

| 模式 | 规则 |
| --- | --- |
| 叫分制（默认） | 随机一人开始，依次选择不叫或叫更高的 1～3 分；最高分者为地主，叫 3 分立即确定。经典局全员不叫则重发，组队局流局。 |
| 叫抢制 | 随机一人开始，首次叫地主成为候选，随后每次抢地主 ×2。第一轮所有人选过后，仅叫过或抢过的人有第二轮资格；从最早叫地主者起按座位顺序询问，首位抢地主者立即成为地主并 ×2。若前面的人均不要，最后一人自动成为地主，不再询问也不翻倍。仅一人有资格时直接确定；第一轮全不叫则重发。 |
| 手速制 | 发牌完成后三人同时可叫，服务器最先处理的有效提交成为地主：前 2 秒 ×4，超过 2 秒至 5 秒 ×2，超过 5 秒至 15 秒 ×1。超过 15 秒无人叫则重发；人机在 3 秒后参与。 |

经典局重发不计分，也不消耗比赛局数。组队局流局照常计入已完成副数。手速制确定地主后会关闭本桌所有叫地主窗口，地主可按 Q 打开出牌面板。

## 合法牌型与计分

牌点从小到大为 `3～10、J、Q、K、A、2、小王、大王`，花色不比较大小。

| 牌型 | 要求 |
| --- | --- |
| 单张、对子、三张 | 同点数的 1、2、3 张牌 |
| 三带一、三带二 | 三张同点数牌带一张单牌或一对 |
| 顺子、连对 | 至少 5 张连续单牌，或至少 3 对连续对子 |
| 飞机 | 至少 2 组连续三张，可不带、带同组数的单牌或对子；单翅可成对，每种点数最多带两张，不能同时带大小王 |
| 四带二 | 四张同点数牌带两张单牌（可以是一对），或两对牌 |
| 炸弹、王炸 | 四张同点数牌、大小王；炸弹压普通牌，王炸最大 |

顺子、连对、飞机主体不含 2 或王。飞机比较主体，三带和四带比较三张、四张的点数。

叫分制底分为叫分，叫抢制和手速制底分为 1。叫抢、手速带来的起始倍数与炸弹、王炸、春天的倍数累计相乘；每次炸弹或王炸 ×2。地主胜且农民均未出牌为春天，农民胜且地主只出一手为反春天，均再 ×2。

经典模式下，每名农民得失为“底分 × 倍数”，地主得失为其两倍，胜方加分、败方扣分。每局结算后等待 5 秒再继续，整场累计得分；完成设定局数后公布总分与优胜者并返回大厅。

## 游戏设置

设置仅在大厅调整，同页点击立即生效，属于当前牌桌，整场比赛沿用。

| 设置 | 可选项与效果 |
| --- | --- |
| 游戏模式 | 经典模式（默认）、2v2、4v4（仅八座桌） |
| 比赛局数 | 1～32 局，默认 1 局 |
| 经典局叫地主模式 | 叫分制、叫抢制、手速制。组队局固定使用叫分制 |
| 每步操作时限 | 无限制（默认）、30、60、90、120 秒。适用于轮流叫地主和出牌，手速制叫地主沿用 15 秒 |
| 计分方式 | 分数制（默认）或赢副制。经典局每位获胜者记1分，四人组队每副的胜队记1分 |
| 8人4v4比分 | 公开比分（默认）或隐藏比分并预测 |
| 洗牌模式 | 默认正常洗牌；可选“不洗牌”，首副同点数成组后随机切牌、连续发牌，后续按出牌组合收牌并切牌，不逐张打散 |
| 游戏音乐 | 默认开启；关闭后停用背景及结算音乐 |
| 显示剩余牌数 | 默认显示；隐藏后同时关闭报单、报双聊天提醒 |
| 记牌器 | 默认关闭；确定地主后，在屏幕顶部按点数显示另外两家手中各点数剩余总数，不含自己、已出牌或其他桌的牌 |

启用时限后，倒计时显示在当前行动者姓名旁。叫地主超时视为不叫，跟牌超时自动不出，领出超时自动打出最小单张。无合法应牌时仍在 5 秒后自动不出，其他玩家只看到正常时限。人机沿用自身行动节奏。

记牌器与总牌数显示相互独立，隐藏总牌数不会关闭记牌器。背景音乐在炸弹、王炸或有人剩 1～2 张牌时切换为紧张音乐。4v4 每个分桌结束时立即按本桌胜负播放音乐，流局没有胜负曲。音乐只发给参与对局的真人，音量由“唱片机／音符盒”控制。

不洗牌模式较容易形成炸弹，但仍使用相同的牌型与计分规则；经典局全员不叫后的重发也沿用当前模式。设置页的文本选项和数值加减点击立即生效，完成按钮只关闭窗口。

## 人机

三种模式均自动补齐，约每秒行动一次。只读取自己的手牌、上一手和公开余牌数，所有出牌仍经过正式牌型校验。

人机优先整手出完，领出时兼顾出牌张数、拆牌代价与剩余散牌，尽量保留 A、2、王和炸弹；农民通常让队友，能直接出完时例外。残局或对手报单、报双时加强拦截并放宽保炸策略。叫分制中，无人叫分时叫 1 分，否则不叫；手速制在 3 秒后参与。

这是用于补位测试的有限候选策略，可能主动不出或漏掉更优组合，不保证最优胜率。真人的合法应牌检测独立于人机的保炸、让牌策略。

## 命令与维护

玩家局内备用命令由本人执行，仍受当前回合、叫地主模式及牌型校验限制：

| 命令 | 操作 |
| --- | --- |
| `/trigger dd_action set 100` | 打出当前已选牌 |
| `/trigger dd_action set 101` | 不出 |
| `/trigger dd_action set 102` | 清空选择 |
| `/trigger dd_action set 200` | 叫分制：不叫 |
| `/trigger dd_action set 201`、`202`、`203` | 叫分制：叫 1、2、3 分 |
| `/trigger dd_action set 204`、`205`、`206` | 叫抢制：叫地主、抢地主、不要 |
| `/trigger dd_action set 207` | 手速制：叫地主 |

管理员在牌桌 8 格内执行：

```mcfunction
# 在大厅选好斗地主后，开始最近一张处于大厅的牌桌
/function fast_card:admin/start

# 中止最近一场斗地主，保留牌桌并返回大厅
/function doudizhu:admin/abort

# 管理员本人恢复自己的手牌窗口
/function doudizhu:dialog/open
```

`/reload` 保留牌局、累计得分、叫地主、每步操作及自动过牌计时，并恢复操作入口与背景音乐。更新音频后，所有玩家须更新资源包并按 F3+T 重载资源。

## 维护

桌面出牌由 `tools/build_doudizhu_table_cards.py` 生成，叠牌接缝由 `tools/fix_card_stack_seams.py` 处理；布局与清理须按桌号隔离。音乐位于资源包 `assets/card/sounds/doudizhu/`，事件为 `card:doudizhu.normal`、`exciting`、`win`、`lose`；按游戏刻循环，服务器卡顿可能增加曲间间隔。

## 验收

现有检查覆盖牌型、人机、三种叫地主模式、自动不出、设置、累计计分、音乐和桌面布局。不洗牌新增项须另测首副成组、后续收牌切牌、全员不叫重发、牌数守恒、重载及两桌隔离；既有检查结果不代表这些新增场景已通过。客户端仍需实测叠牌逐张点击、四／八座朝向、真人与人机混合对局及音量。完整验收记录见[验收清单](验收清单.md)。
