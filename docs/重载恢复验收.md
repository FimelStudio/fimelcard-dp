# 四个游戏的 /reload 恢复

出包魔法师、瞎掰王、谍报风云、临界点重载后保留当前对局；不重新发牌、抽题、抽词或重置回合。已进入结算的游戏仍按原计时正常结束。

建议在游戏内分别验证以下场景，每种场景连续执行两次 `/reload`：

- 出包魔法师：发牌动画中途继续发牌；成功施法后保留当前玩家、上一次咒语限制、生命值与手牌；结算期间保留原倒计时。
- 瞎掰王：阅读阶段保留原题与阅读进度；问答阶段保留身份；已经使用扯淡指认后不补回该机会，仍可结束问答并指认。
- 谍报风云：写到一半并保存关闭的提示册内容保留；密码已选一至两位时从下一位继续；两队词条、得分、电报记录和左上角当前页保留。
- 临界点：已扣下的牌保留；用掉黑白信号染料后不补发；讨论中已准备玩家保持准备；最终投票中已投票玩家保持原票，未投票玩家可以继续提交。
- 同时开两张桌子，确认恢复界面与物品只发给所属桌玩家，不串桌。

静态检查：`node tools/check_reload.mjs`。此检查不代替 Minecraft 内的实际重载测试。
