# 表情包与语音

在牌桌座位按空格打开分类菜单，选择“表情包”或“语音”进入各自发送页面，子页面可返回分类。分类切换不消耗、也不重置冷却。普通玩家通过 trigger 发送，无需 OP。

表情包向所有在线玩家广播：第一行 <玩家名>，下一行开始显示图片。图片高60像素，尾部留空行保护后续聊天。对话框沿用 meme:meme 字体，聊天使用顶部对齐的 meme:chat 字体。

语音以发送者当前位置为原点，同维度16格内的玩家可听见，随距离衰减。

每人表情包、语音分别冷却100游戏刻（正常运行5秒），共用各自类别的冷却；重复打开或切换内容不能绕过。离座与重载不重置冷却，离线期间暂停计时。

## 新增图片

从桌面“表情包-格式未变换”导入68张，原有4张保留，共72张，分3页，每页24张、每行8张。按真实文件格式解码为PNG，最长边不超过256像素，不放大小图；8张动态GIF使用首帧静态图。原图未改动。资源对应关系见“表情包导入清单.json”。

## 新增语音

从桌面“语音-格式未变换”导入34段，视频提取第一条音轨，保留完整长度，统一为44.1kHz单声道OGG Vorbis。原始文件不改动。共36段语音分2页，每行3个按钮、每页6行18段，名称沿用文件名并去除视频序号。所有语音共用每人5秒冷却，播放范围仍为发送者同维度16格内。导入对应关系见“语音导入清单.json”。

选择面板使用独立 preview 字体，缩略图限制在48×40显示像素内，保证每行8张；聊天中发送的图片大小保持不变。
