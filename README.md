# Fimel Cards 26.2

作者：歪浪Ylong、水晶Cesmos。Minecraft Java 26.2 多人牌桌游戏数据包，可加入玩家自己的存档，搭配 `fimelcard-rp` 资源包使用。

## 当前功能与安装

将数据包放入存档的 `datapacks` 文件夹，将配套资源包放入客户端的 `resourcepacks` 文件夹并启用。进入世界执行 `/reload`；更新资源包后按 `F3+T` 重载。创建牌桌需要命令权限，入座后的常规操作通过交互实体、对话框及临时开放的 trigger 完成。

- 四座桌：`/function cardtable:admin/create`；八座桌：`/function cardtable:admin/create8`。建桌间距限制从9格缩小为6格。
- 游戏设置顶部可选择皮肤：**默认、典雅、电音、玩偶、复古、竹影、春日**，四座桌和八座桌均适用；具体家具介绍保留在 `docs` 文档中。
- 德州扑克可以打开游戏设置查看皮肤入口，游戏本身当前没有可用设置。
- 出包魔法师可设置获胜分数 **1～32分**，默认 **8分**。每桌独立保存，跨局累计，结算时达到目标即结束整场；游戏进行中不能修改。
- 斗地主支持叫分制、叫抢制、手速制、人机补位、1～32局累计计分；可开关音乐、剩余牌数与记牌器。手速制前2秒叫地主为4倍、超过2秒至5秒为2倍、超过5秒至15秒为1倍，无人叫则重新发牌。
- 表情包与语音分开选择：72张表情包每行8张，36条语音每行3项；各自5秒冷却。表情包聊天先显示玩家名，下一行显示图片，图片文本组件关闭阴影；语音以发送者为中心16格内播放。



本数据包的主要游戏与牌桌逻辑分为以下命名空间：

- `cardtable`：通用牌桌、结构放置、座椅、菜单、人数、结束投票和公共发牌动画。
- `fast_card`：Fast Card 的牌组、传牌、抢按、回合和计分。
- `liars_holdem`：赌命德州扑克的52张牌库、公共牌、Q键行动、换牌、牌型比较、左轮和淘汰流程。
- `hanabi`：花火的隐藏手牌、提示、出牌、烟花堆、合作计分和终场表演。
- `abraca`：出包魔法师，2至5人；隐藏手牌、八种咒语、Q键施法、生命与累计塔层结算。获胜分数可在本桌设置中调整（默认8分）。
- `bullshit`：瞎掰王的3至8人基础模块；题目、身份与功能牌目前使用聊天文字和原版纸张占位。
- `decrypto`：谍报风云的3至8人提示、解码、拦截和标记流程。设置可选对话框或提示册（书与笔）输入；使用书时，第1至3页各写一条提示，点击完成、不签名，再按Q一次性提交。每局开始从共享词库抽取8个互不重复的词分配给两队（每队4个），整局固定编号与词条，回合间只更换数字密码。三人局合作队的4词同样保持整局不变。左上角累计敌方历轮已结算提示，物品栏“密电记录”查询己方历轮提示；重新开局才重新抽词并清空记录。词库维护入口为 data/decrypto/function/words/pool.mcfunction，当前为239个去重词语。
- `doudizhu`：设置可选1至32局（默认1局），每局得分累计，5秒后自动继续；整场结束公布总分和优胜者。左上角底牌及上下家本轮出牌使用具体花色、点数和大小王牌面图片，每行最多10张。斗地主，固定3人；四人桌和八人桌均可选择，可任坐三个座位。快捷栏第9格留空用于手牌入口，按Q打开叫分和出牌对话框。
- `skull`：骷髅牌，2至6人；三张花牌使用黑桃A，一张骷髅牌使用小丑牌。秘密扣牌、数字叫号、逐张翻牌与秘密弃牌；两次成功或最后存活获胜。中央仅显示各玩家出牌数量，桌面无牌堆模型。紫色染料按Q重开操作对话框。详见 `骷髅牌接入验收.md`。
- `wenfei`：问非所答，支持2至8人；默认2人每人猜3次、3至8人每人猜2次。六类各150道原创题，每轮从所选类别随机抽5道不重复候选题，对话框选择类别（该阶段可用紫色染料按Q重开），设置可选书与笔或对话框秘密回答，聊天栏逐张显示五道候选题，丢出0至4分染料评分，累计计分并列获胜。已公开回答显示在猜题者左上角，长回答自动翻页；桌面显示进度与分数，重载保留牌局。题库见 `data/wenfei/function/deck/catalog.mcfunction`，验收清单见 `问非所答接入验收.md`。
- `critical_point`：临界点的3至6人隐藏身份、秘密同步出牌、危机线与最终投票流程。

本包已合并以下前置所需功能，使用合并包时无需单独安装这些数据包；原作者署名与资料保留在 `docs/vendor`：

- `[前置]文本动画库重制版 V26.0 - 1.21.6+`：世界文字过场；
- `BetterTitle DP 26.1`及资源包内配套的26.2着色器：花火左侧他人手牌；
- `[1.21.1+] SKapi Libs Ver2.1 DP`：SK Form、SK Firework 的数组、数学和玩家数据接口；
- `[1.21+] SK Form 表单输入系统 V1.0`：SK Firework 的自定义烟花配置界面；
- `[1.21.4] SK Firework 烟花 V2.0`：花火成功接牌与最终结算烟花。

后三个SK数据包已在本项目中按26.2数据包格式更新，公开函数名和参数结构保持不变。

## 八人牌桌

执行`/reload`后，在新位置运行`/function cardtable:admin/create8`。新桌的桌面为4×4橡木桌面，每边两张白桦木座椅，共八座，桌椅总占地6×6；椅子使用白桦楼梯外观的方块展示实体，不需要新增资源包模型。每侧两把椅子中心距该边中线各1格，中心间距2格，净空1格。桌心位于方块交界点，所在高度为桌面方块层，与其他牌桌中心至少间隔6格。

规则文字及点击区位于4×4桌面最外侧一格的外立面、靠近桌角。已有八人桌在`/reload`后更新规则位置、移除旧布局的默认白桦楼梯并换成实体椅子，正在入座的玩家会回到移位后的原座。

已有相同布局的4×4桌面时，站在桌面中央四个方块的交界点，使用`/function cardtable:admin/create8_safe`只注册实体。原`create`与`create_safe`仍创建四座桌；旧桌不自动改建。

八人桌菜单开放Fast Card（固定4人）、赌命德州扑克（2至8人）、花火（2至5人）、出包魔法师（2至5人）、瞎掰王（3至8人）、谍报风云（3至8人）、问非所答（2至8人）、临界点（3至6人）、骷髅牌（2至6人）和斗地主（固定3人），默认问非所答。花火和出包魔法师可以使用任意五个座位，不要求坐在1至5号；第六人入座时拒绝开局。原四座桌最多仍只能四人。问非所答多人局默认每人猜两次，八人共16轮；左上角每页最多显示四人的“名字：答案”，每5秒轮换人数页，长答案继续翻页。瞎掰王每人担任一次大聪明，八人共8轮；选人按钮只列本桌其他玩家，身份与计分规则不变。

Fast Card可任坐八座中的四座，发牌与传牌仍按四人顺时针进行。谍报风云设置可选随机组队或固定组队，固定组队按座位阵营分配并检查人数是否合理。支持的队伍人数为：5人3＋2、6人3＋3、7人4＋3、8人4＋4。两人队每轮交换加密和解密兼拦截；三人队依次轮换加密、解密、拦截；四人队依次轮换加密、解密、拦截、轮空。整轮分工固定，下一轮才轮换；轮空者仍可看本队词条和笔记，但不能提交。三人模式保持原规则。骷髅牌六人最多24张牌，支持1至24的具体叫号和全部八座中的翻牌选人。

临界点支持八座中的任意3至6人，仍随机一名狼人。安全线按3×人数+2计算，5人17点、6人20点。投票仅列本桌其他玩家姓名，全部八个座号均可计票；最高票平票仍为狼人胜。

人数显示按实际桌型显示`人数/4`或`人数/8`。结束投票在2人时需2票，3至4人需3票，5至8人需严格过半（八人需5票）。原管理员移除命令也适用于八人桌，并保留方块桌。

德州扑克八人局每人两张手牌，子弹按八个座位分开显示，最佳五张牌在桌心分两列展示；存活、弃牌、全押、排名、左轮和离线淘汰覆盖全部八座。每人一次三选一换牌，即使八人全换牌，52张牌库仍够用。花火4至5人每人4张，2至3人每人5张；普通提示与奖励提示可选择实际入座的第6至8号玩家。花火和出包魔法师的左上角手牌最多显示四名其他玩家，出包中央生命与最终生命面板显示本桌全部参与者。出包魔法师左上角面板最底行显示“你手上有 N 张牌”，只统计自己的真实手牌，并随施法和补牌更新；真实咒语石仅保存在后台，轮到玩家时给予1至8号操作牌，按Q施法并返还；回合结束收回，第9格黑色染料按Q结束回合，开局须清空快捷栏全部9格。

验证与联机验收清单见[八人牌桌验收.md](八人牌桌验收.md)。

## 创建与游玩

```mcfunction
/function cardtable:admin/create
/function cardtable:admin/create_safe
```

普通命令会用`cardtable:table4_display`生成3×3桌面，并生成四张方块展示实体椅子；已生成的四人桌保留原样。`create_safe`用于把已有的3×3桌子注册为牌桌，它完全跳过结构放置，不检查、替换或清除任何方块，只生成牌桌控制器、中央菜单和座位交互实体。执行时玩家应站在桌面的中心方块上，命令会自动把桌心锚点下移1格到桌面方块层。四个座位锚点固定在桌心南、北、东、西各2格，因此现有椅子应与这些位置对齐。玩家右键座位交互区即可入座；大厅中按潜行键下马会自动退出。入座和离座不会发送聊天提示。达到当前游戏要求的人数后，点击中央的“开始游戏”文字开始。

创建命令只属于通用 `cardtable` 模块，不绑定具体游戏。大厅中央只显示游戏名称、当前人数、切换游戏、游戏设置和开始游戏。四人桌和八人桌均可右键“切换游戏”，在对话框中直接选择十个游戏；按钮标注当前桌型可用人数，取消不改变游戏，选择当前游戏保留设置，普通玩家无需OP。点击“游戏设置”后，通用牌桌会让当前游戏打开自己的设置dialog；Fast Card可在其中设置1至999局，以及“无有效牌型乱按时忽略/立即判负”。保存按钮通过仅向当前玩家临时开放的 `fc_settings` trigger提交，因此普通玩家不需要函数权限。每个游戏的设置独立保存在当前牌桌上，切换游戏不会互相覆盖。

Minecraft 26.2 的 `text_display` 在世界中不可被选取，文本组件的 `click_event` 不会响应对展示实体的点击。因此中央菜单仍由文字展示实体显示，并使用同位置的透明 `interaction` 实体接收左右键。

“规则介绍”属于牌桌常驻通用界面，在大厅和游戏中始终显示；点击时会实时按本桌当前选择或正在进行的游戏打开对应规则dialog，未入座的旁观者也可以查看。游戏中，每名玩家右侧另有“结束游戏”文字。每人只能投一次；四座桌通常达到3票后提前结束，若淘汰后牌桌仅剩2名玩家则需要2票；5至8人局需要严格过半，随后牌桌回到大厅。

“结束游戏”文字固定在每名玩家右手侧的桌子外立面；左手侧对应显示常驻的“规则介绍”。两者都使用 `billboard:fixed` 朝向桌外。游戏开始后玩家可以主动下马离开座位；右键自己的原座位可重新坐回，离座不会退出或暂停游戏。玩家离线会释放座位；Fast Card进行中有人离线时，因为四人传牌顺序已经不完整，本场会直接结束并返回大厅。

传牌阶段只有系统提示的当前玩家可以按Q出牌。其他玩家丢出带Fast Card标记的卡牌时，卡牌会立刻回到本人脚下并取消拾取冷却，因此无法提前出牌；普通的同材质物品不受影响。

每小局开始时，牌桌中央会用淡入淡出动画显示两秒“第x局”。随后牌盒放大出现，每隔4刻从牌盒处生成一张真实纸牌并飞向对应玩家，共发17张；发完后牌盒缩小消失，中央抢按按钮才会出现。牌盒、发牌音效、飞行动量和兜底送达由`cardtable:animation/deal/*`公共模块提供，Fast Card只决定牌面、牌数和目标座位。小局结算和下一轮发牌期间按钮都会隐藏，避免遮挡中央动画。

传牌只响应当前出牌者本刻按 Q 产生的物品丢弃统计，并同时校验其丢牌后恰好剩余4张游戏牌。牌会直接进入下一家的空快捷栏，完成收牌后才切换当前出牌者，因此持有5张牌的玩家始终与回合提示一致。

小局结束后，牌桌中央先显示“积分变化”，再按最新分数逐行展示四个座位的排名、总分和本局分差；完整结算过场为5秒，之后自动播放下一小局的“第x局”动画。最终一局结束后仍会输出完整最终排行榜。

## 赌命德州扑克

在大厅点击“切换游戏”选择“赌命德州扑克”。任意2至8名玩家入座且所有玩家九格快捷栏为空即可开局（5至8人使用八座桌）；Fast Card仍独立要求四人。玩家被淘汰后，赌命德州扑克会以剩余玩家继续，直到只剩最后一名幸存者。

每局先从标准52张牌中通过公共牌盒动画给每名存活玩家发两张手牌；牌盒消失后，再从剩余牌库确定并生成五张公共牌。轮到玩家时，快捷栏最右侧会出现“跟注”和“弃牌”物品：

- 选中跟注后按Q：普通阶段增加1发；最终抉择或全押响应时跟随ALL IN。
- 轮到自己时按F：在前三个普通阶段或最终抉择阶段ALL IN。
- 选中弃牌后按Q：退出当前牌局并立即接受左轮判定。
- 轮到自己且仍有换牌机会时，Q丢任意一张手牌：打开三选一换牌Dialog。

换牌Dialog使用资源包`card:card`字体显示三张真实候选。候选在窗口打开前就从本局牌库移除；选中的牌替换原手牌，未选两张和被换掉的牌也全部进入弃牌区。窗口不允许直接用Esc绕过，点击底部退出按钮会按规则默认选择第一张。

牌盒完成玩家手牌发放并消失后，五张公共牌才会重叠生成在桌心，随后用10刻插值展开到`translation.x=-1.0、-0.5、0、0.5、1.0`；翻牌只修改旋转，不会破坏位置。第一次行动后翻开前三张，第二次后翻第四张，第三次后翻第五张。摊牌使用完整七选五比较，支持皇家同花顺至高牌、全部踢脚和多人完全平局；A固定为14，不能作为1，A、2、3、4、5不构成顺子。系统会按座位顺序在桌心以玩家名亮出每人的真实最佳五张牌，然后显示玩家名排名并输出聊天结果；桌面牌图组件固定为白色，聊天只输出牌名。所有亮牌保留到最后一次开枪结束。子弹数量使用沿玩家桌边排列的金粒`item_display`表示，不再用遮挡公共牌的文字。普通左轮死亡率为“子弹数÷8”；8发为95%击发、5%卡弹。当前开枪表现是文字动画、音效和粒子占位，判定会在动画前由服务端锁定，后续可直接替换`liars_holdem:gun/animation/start`及结果表现函数接入Animated Java。

## 管理命令

```mcfunction
# 后备开局入口
/function fast_card:admin/start

# 中止当前Fast Card并回到大厅
/function fast_card:admin/abort

# 中止附近的赌命德州扑克并回到大厅
/function liars_holdem:admin/abort

# 移除牌桌会话和所有交互实体，但保留方块及玩家改装
/function cardtable:admin/remove

# 清除重构前遗留的展示实体牌桌
/function cardtable:admin/remove_legacy
```

## 调试日志

需要查看日志的玩家自行添加 `ct.debug` 标签；入座、离座或创建牌桌都不会自动修改这个标签：

```mcfunction
# 开始查看日志
/tag @s add ct.debug

# 停止查看日志
/tag @s remove ct.debug
```

只要有玩家带有该标签，牌桌通用事件会以 `[牌桌 Debug]` 开头，游戏事件会分别以 `[Fast Card Debug]`、`[赌命德州扑克 Debug]`、`[花火 Debug]` 或 `[出包魔法师 Debug]` 开头。也可以手动调用：

```mcfunction
/function cardtable:log {text:"测试牌桌日志"}
/function fast_card:log {text:"测试游戏日志"}
/function liars_holdem:log {text:"测试赌命德州扑克日志"}
/function abraca:log {text:"测试出包魔法师日志"}
```

动态日志使用 storage 传入宏参数，再由事件宏调用统一日志入口。例如 `cardtable:debug/log_join` 和 `fast_card:debug/log_pass`。

## 扩展其他游戏
